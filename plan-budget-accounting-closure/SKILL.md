# 计划预算核算闭环

## R — 原文 (Reading)

> 计划-预算-核算在公司的三个关键业务环节：中长期战略规划（SP）、年度业务计划（BP）和日常项目计划（PP）中都应该包括。在每个关键业务环节中，都包含计划、预算、核算的闭环管理，从而形成区域/代表处PDCA运作的管理过程。
>
> — 华为管理手册（财务四算）, 第7章

> 预算是承诺，预测是配置资源的基础。资源是要按照预测来配置的，如果年初预测要增加，那么必然要增加资源。
>
> — 华为管理手册（财务四算）, 第7章

> 预测是管理之魂，亦是评价管理水平的最重要指标。
>
> — 华为管理手册（财务四算）, 第7章

> 只有计划做好了，后面的预算才有依据，才可以通过核算来修正、考核计划与预算。
>
> — 任正非, 华为管理手册（财务四算）, 第16章

## I — 方法论骨架 (Interpretation)

计划-预算-核算闭环是华为经营管理的核心机制，它将战略意图转化为可执行、可监控、可考核的经营活动。

**三层计划体系：**

1. **SP（战略规划 Strategy Planning）—— 解决方向问题**
   - 周期：3-5年中长期规划
   - 回答三个问题：现在在哪里？3-5年后去哪里？如何去？
   - 内容：市场洞察、竞争分析、战略意图、业务设计、关键任务
   - 输出：公司级/产品线/区域SP

2. **BP（业务计划 Business Planning）—— 解决落地问题**
   - 周期：年度
   - 基于SP指导下一年度关键措施和资源配置
   - 四步骤：历史经营分析→未来三年市场分析与规划→未来三年经营计划→Deep Dive
   - 十步分解：审视机会→细分目标→建立毛利基线→分配成本费用→人员规划→运营资产目标→综合平衡→汇报评审→确定预算→制定行动计划

3. **PP（项目计划 Project Planning）—— 解决执行问题**
   - 周期：项目全生命周期
   - 华为核心业务以项目为单位，经营计划下沉至代表处表现为日常PP
   - 包含：项目机会→投标→交付→回款→决算

**五个业务循环（以代表处为例）：**

1. **规划预算环**: SP→BP→预算签署PBC→季度/月度管理
2. **预测运营环**: 综合运营会议+销售运营会议(OTO)+交付运营会议(OTC)
3. **计划集成环**: 订货→要货→生产采购→运输发货→到货→工程安装
4. **项目管理环**: 项目机会→投标→交付→回款→决算
5. **绩效基线环**: PBC指标分解落地+基线建设与维护

**滚动预测机制：**
- 第1季度预测：围绕季度目标，解决眼前问题
- 第2季度预测：聚焦重点合同/项目，动态弹性资源配置
- 第3季度预测：关注客户需求和投资变化
- 第4季度预测：关注市场/产业布局，与战略衔接
- 连续4个季度不间断滚动，责任人为各地区部

**预算与KPI的关系：**
- 预算是自下而上、基于一线市场环境和公司战略做出的资源配置
- KPI是自上而下、体现管理层诉求的考核目标
- 双方PK过程是对战略、资源配置和经营目标达成共识的过程

## A1 — 书中的应用 (Past Application)

### 案例 1: 华为代表处计划-预算-核算五循环
- **问题**: 代表处经营管理如何与总部战略对齐，同时保持一线灵活性？
- **方法论的使用**: 建立五循环体系：规划预算环（SP→BP→PBC）→预测运营环（OTO/OTC会议）→计划集成环（端到端供应链计划）→项目管理环（LTC）→绩效基线环（KPI+基线）
- **结论**: 用五循环将战略、预算、运营、项目、绩效全面拉通
- **结果**: 代表处成为独立运作的利润中心，经营管理能力大幅提升

### 案例 2: 华为滚动预测与弹性资源配置
- **问题**: 预算年初确定后，市场环境变化如何应对？
- **方法论的使用**: 四个季度连续滚动预测；根据预测动态调整资源配置；预测是"管理之魂"，评价管理水平的最重要指标
- **结论**: 预算是个承诺，预测是配置资源的基础；用滚动预测替代僵化预算
- **结果**: 实现了资源的动态优化配置，提升了经营稳健性

### 案例 3: 华为SP/BP/PP关系矩阵
- **问题**: 战略规划、年度计划和项目执行三层脱节
- **方法论的使用**: 三层都包含"计划-预算-核算"闭环；SP指导BP，BP指导PP；PP的执行结果反馈到BP和SP的修正
- **结论**: 不是三层独立的计划，而是嵌套闭环的管理体系
- **结果**: 实现了从公司战略到个人执行的完整贯通

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诊断三层计划现状**
   - 完成标准: 识别用户是否有SP/BP/PP三层计划、三层之间是否贯通、计划与预算/核算是否闭环

2. **设计SP/BP/PP嵌套闭环**
   - 完成标准: 明确三层计划的输入输出关系和反馈机制
   - SP输出战略意图和业务设计，作为BP输入
   - BP输出年度目标和资源配置，作为PP输入
   - PP执行结果反馈修正BP和SP

3. **建立滚动预测机制**
   - 完成标准: 设计季度滚动预测流程，明确预测内容（订-发-收-回+财务报表+风险）和责任人

4. **设计经营分析会议体系**
   - 完成标准: 建立综合运营会议+销售运营会议+交付运营会议的频率、参与人和决策机制

5. **拉通计划-预算-核算-考核**
   - 完成标准: 明确计划如何生成预算、预算如何由核算监控、核算结果如何用于考核、考核结果如何反馈到下一周期计划

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯战略制定但无执行需求 — 用BLM或战略分析工具即可
- 单一财务核算问题 — 用财务核算制度即可
- 无战略目标的日常运营 — 先明确战略方向
- 初创公司（<30人）— 三层计划体系过重

### 作者在书中警告的失败模式

- **预算是SP的线性延长**: BP不是SP的简单分解，而是基于机会点的重新设计
- **预测变成"数字游戏"**: 滚动预测不是为了调整数字，而是为了识别风险和机会
- **会议流于形式**: 经营分析会变成汇报会，失去纠偏价值

### 作者的盲点 / 时代局限

- 华为五循环基于大型项目制业务设计，对于持续运营型业务（如SaaS、平台）需要调整循环内容
- 强调会议驱动的运营体系，在远程/异步工作环境中可能需要数字化替代方案

### 容易混淆的邻近方法论

- 与PDCA: 本 skill 是PDCA在企业经营管理中的具体应用
- 与OKR: OKR是目标管理工具，本 skill 覆盖目标+资源+核算+考核的完整闭环
