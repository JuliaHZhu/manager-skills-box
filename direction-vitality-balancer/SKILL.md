# direction-vitality-balancer — 方向大致正确与组织活力平衡

## R (Reading) — 原文引用

> "方向要大致正确，组织必须充满活力。"（Ch13，任正非上海战略会议）

> "这里的方向是指产业方向和技术方向，我们不可能完全看的准，做到大致准确就很了不起；在方向大致准确的情况下，组织充满活力非常重要，是确保战略执行、走向成功的关键。"（Ch13）

> "做事业就像舞龙，龙头要抬起来，这就是方向，大致要正确；更重要的是随后龙身子要舞动起来，要有力，整个龙才能舞起来、活起来。"（Ch13）

> "战术有千百条，头一条就是肯打，离开了肯打，其他的全是白扯。"（Ch13，引林彪）

> "成功最大的敌人，不是没有机会，而是没有立刻行动。"（Ch13）

> "华为不是处处都正确，而是经常犯错误……战略对的时候我们能加快发展，不太对的时候能及时调整。华为总体上靠的是快，学的快、做的快、改的快。"（Ch13）

## I (Interpretation) — 方法论骨架

这是一个**战略哲学的元框架**：在不确定的未来面前，追求"方向绝对正确"是幻觉，而"组织充满活力"是我们可以控制的真实变量。

**核心等式**：
```
战略成功 = 方向大致正确 × 组织充满活力
```

**关键洞察**：
1. **方向不可能绝对正确**：我们都是用"倒视镜"预测未来，大公司（王安、柯达、诺基亚）都倒在"方向大致不正确"的路上
2. **活力可以补偿方向的偏差**：方向偏了，活力足的组织能快速调整（"学的快、做的快、改的快"）
3. **方向对了，活力不足也白搭**：龙头抬起来了，龙身子不动，整条龙还是死的
4. **活力不是"下面干活的人"的事**：决策层本身也必须充满活力——开放、努力、敢于自我批判、亲力亲为

**组织活力的五个维度**：

| 维度 | 健康信号 | 病态信号 |
|------|---------|---------|
| **决策活力** | 快速决策、允许试错、及时调整 | 层层汇报、评审再评审、PPT无数版本 |
| **执行活力** | 立刻行动、前线有授权、敢打 | 等指令、不敢越雷池一步、怕担责 |
| **学习活力** | 从错误中学习、快速迭代 | 摔了跟头才学、同一错误反复犯 |
| **创新活力** | 鼓励异见、容忍失败、新想法有通道 | 一言堂、新想法被秒否、"以前没做过" |
| **人才活力** | 年轻人有机会、专家受尊重、流动畅通 | 论资排辈、专家矮化、部门墙厚重 |

## A1 (Past Application) — 书中案例

**华为无线业务的"熬"**：
- 方向：在"大致正确"与"大致不正确"之间摇摆多年
- 活力：团队持久战斗力，不怕困难，永远充满激情
- 结果：比摩托罗拉、阿尔卡特、北电"多口气"，最终成为"圣无线"

**华为手机业务的"打"**：
- 方向：IDEOS、Ascend品牌失败，D系列消失，Mate意外成功——规划至少1/4不到一年失效
- 活力：余承东带领团队"踏踏实实打好每一场战"
- 结果：消费者业务成功

**华为云计算的困境**：
- 方向：云、AI、平安城市等新方向
- 活力缺失信号：决策组织缺乏活力、效率、担当和弹性
- 风险：面向战略性领域，评审再评审，丧失创业般的灵活

## A2 (Future Trigger) — 何时调用

- 战略规划做完了，但团队执行乏力——"方向定了，人不动"
- 组织层级越来越多，决策越来越慢——"评审、评审、再评审"
- 年轻人才流失，老人占着位置不做事——"之字型发展"变成论资排辈
- 专家被打压，管理者职级虚高——"右金字塔坍塌"
- 新业务需要"创业精神"，但组织用"成熟业务"的管理方式去管

## E (Execution) — 可执行步骤

### Step 1: 诊断"方向 vs 活力"失衡点

**问诊清单**：

| 问题 | 如果回答"是" | 失衡点 |
|------|-------------|--------|
| 战略方向被质疑时，高管能清晰说明调整预案吗？ | 否 | 方向问题 |
| 一线员工有不经审批就做小决策的权限吗？ | 否 | 活力问题 |
| 过去6个月，有因"方向调整"而快速转向的成功案例吗？ | 否 | 活力问题 |
| 中层管理者平均花在汇报/评审上的时间超过50%吗？ | 是 | 活力问题 |
| 公司能吸引行业顶尖年轻人吗？ | 否 | 活力问题 |

### Step 2: 如果方向有问题——增强"大致正确"的概率

**方法**：
- 引入蓝军机制（参见 blue-team-organizer / red-blue-debater）
- 增加外部信息输入：客户访谈、竞争对手分析、行业专家咨询
- 设定"方向校验点"：每季度复盘核心假设，及时发现偏差
- 保持战略弹性：不要All-in单一方向，保留调整空间

### Step 3: 如果活力有问题——激活组织

**A. 决策层活力（最关键）**
- **角色转换**：决策者从"评审者"变成"项目组一员"——深入业务、主动学习、少说No、一起研究Yes
- **资源配置权**：决策层在拍板后，必须积极帮助配置资源、确定政策、鼓励冲锋
- **复盘参与**：出现新变化后，决策层主动参与复盘，一起调整战略

**B. 执行层活力**
- **授权下沉**："呼唤炮火"——让听得见炮声的人做决策
- **减少评审**：PPT版本不超过3版，汇报不超过2轮
- **容错机制**：明确"可接受损失"边界，在边界内允许试错

**C. 人才活力**
- **专家双金字塔**：管理和专家两条晋升通道，专家待遇不低于管理者
- **打破之字型僵化**：海外经验/流动不是晋升的必要条件，产品和市场需要不同的人才画像
- **破格提拔**：对做出最佳贡献的年轻人，不受资历限制快速晋升

**D. 文化活力**
- **自我批判制度化**（参见 self-critique-institutionalizer）
- **反对者有地位**：允许"疯子"存在，肯定反对者的价值
- **结果导向**：战场选干部，杜绝仅凭汇报选干部

### Step 4: 建立"快"的飞轮

华为的成功公式：
```
快 = 学的快 + 做的快 + 改的快
快 ← 勤奋 ← 组织活力
```

**具体动作**：
- **学的快**：建立外部信息雷达，每月1次行业前沿分享
- **做的快**：将决策周期压缩50%，用小步快跑代替大步规划
- **改的快**：建立月度战略假设校验机制，发现偏差立即调整

### Step 5: 警惕"虚假活力"

**虚假活力的信号**：
- 人人都很忙，但产出很低（忙碌 ≠ 活力）
- 会议很多，但决策很少（讨论 ≠ 行动）
- 加班很多，但创新很少（辛苦 ≠ 活力）

**真实活力的检验标准**：
- 能否在1周内完成一个"从想法到小规模验证"的闭环？
- 能否在1个月内调整一个"已被证伪"的战略假设？
- 能否在1个季度内让一个"高绩效年轻人"承担更大责任？

## B (Boundary) — 何时不适用

1. **方向完全错误**：如果方向南辕北辙，活力越强死得越快——需要先停下来重新找方向
2. **纯个人执行力问题**：如果是个别员工的拖延/懒惰，这是管理问题，不是组织活力问题
3. **初创公司尚未确定方向**：初创期需要先找到PMF，"方向大致正确"是 luxury
4. **组织已被掏空的晚期**：如果核心人才已流失、文化已崩坏，需要先做"止血"而非"激活"
5. **外部环境完全锁死**：如政策禁令、垄断打压，活力无法突破结构性约束
