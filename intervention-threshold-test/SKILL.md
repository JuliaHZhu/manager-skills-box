# 干预阈值测试 (Intervention Threshold Test)

## R — 原文 (Reading)

> "医学中的'以不伤害病人为前提'是一个绝妙的理念。在产生医源性损伤的地方，情况是不可观察和不可测量的。总而言之，在任何遭受了天真的干预，或者只是一般干预的地方，都会产生医源性损伤。"
>
> — 塔勒布, 第二卷第7章

---

## I — 方法论骨架 (Interpretation)

干预阈值测试是一个决策前审查协议：在决定"做点什么"之前，系统性地评估该行动是否必要、是否有害、是否有更好的替代方案。

核心洞见：复杂系统中的干预往往带来不可见的副作用，这些副作用的总量可能超过干预的收益。因此，"不行动"应作为默认选项，只有当行动通过严格审查后才能 proceed。

这不是反对所有行动，而是反对"天真的干预"——基于不完整知识、受可见性偏见驱动、由不承担后果的人做出的干预。协议强制你考虑：紧急度、知识边界、副作用可逆性、系统自愈力、历史证据、减法替代。

## A1 — 书中的应用 (Past Application)

### 案例 1: 儿童发热治疗
- **问题**: 孩子发烧，是否应该立即用药物降温？
- **方法论的使用**: 发热是免疫系统的自然反应（自愈机制）。药物降温可能掩盖病情、干扰免疫反应、带来药物副作用（医源性损伤）。
- **结论**: 除非体温达到危险水平或伴有其他严重症状，否则"观察等待"优于立即药物干预。
- **结果**: 循证医学支持"适度发热不需要立即干预"的观点。

### 案例 2: 城市规划中的交通干预
- **问题**: 城市交通拥堵，政府是否应该立即修建更多高架桥？
- **方法论的使用**: 跑干预阈值测试：不建高架不会不可逆恶化；对交通因果了解不充分（诱导需求效应）；高架一旦建成不可撤销；有减法替代（拥堵收费、减少停车位、优化公交）。
- **结论**: 延迟建高架，先尝试减法方案。
- **结果**: 很多城市发现减法方案（如斯德哥尔摩拥堵收费）比加法方案更有效且副作用更小。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确拟议行动**
   - 完成标准: 清晰描述用户想要做什么

2. **阶段1: 必要性审查（2分钟）**
   - 完成标准: 回答:
     - 如果不行动，最坏情况是什么？（轻微→可能不需要行动；灾难→需要行动）
     - 该问题是否已有自然恢复/市场调节机制？（有→优先考虑不干预）

3. **阶段2: 知识边界审查（3分钟）**
   - 完成标准: 回答:
     - 我们对该问题的因果机制了解多少？（>80%→可考虑行动；<50%→高度警惕）
     - 是否有历史证据表明类似干预有效？（无/混合→避免行动）

4. **阶段3: 副作用预判（5分钟）**
   - 完成标准: 列出所有可能的副作用（即使概率低），并判断:
     - 副作用是否可快速观察并逆转？（否→降低优先级）
     - 副作用的承担者是否与行动的受益者一致？（否→存在代理问题/脆弱性转移）

5. **阶段4: 减法替代（3分钟）**
   - 完成标准: 检查是否存在:
     - "减少干预"的选项
     - "撤销旧政策"的选项
     - "降低复杂度"的选项
   - 判停条件: 若存在减法替代 → 建议优先尝试减法

6. **阶段5: 小规模试验（如适用）**
   - 完成标准: 判断能否先在局部/小范围试验
   - 判停条件: 若能试验 → 必须先试验，观察副作用后再推广

7. **输出决策**
   - 完成标准: 给出"通过/延迟/拒绝/改为减法"的明确建议

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 紧急救命场景（如心脏骤停、火灾逃生）——此时不行动的代价明确大于行动
- 已经证明收益明确大于风险的标准操作（如疫苗接种、系安全带）
- 法律强制要求的合规行动——法律合规不因审查而豁免

### 作者在书中警告的失败模式

- **审查形式主义**: 把审查当作"走过场"，内心已经决定行动，审查只是为行动找理由
- **延迟成瘾**: 以"需要更多审查"为借口无限期拖延必要的行动
- **减法困难**: 减法往往比加法更难（需要撤销既得利益），因此减法替代方案容易被忽视

### 作者的盲点 / 时代局限

- 协议的时间成本（15-20分钟）在小决策中 overhead 过高，更适合重大决策
- 在快速迭代的商业环境中（如互联网产品），"先试验再推广"可能与"快速上线"文化冲突

### 容易混淆的邻近方法论

- 与"成本收益分析"的区别: CBA通常假设收益和成本可量化且对称，干预阈值测试强调副作用的隐蔽性和不对称性
- 与"PDCA循环"的区别: PDCA是行动后的迭代框架，干预阈值测试是行动前的审查框架
