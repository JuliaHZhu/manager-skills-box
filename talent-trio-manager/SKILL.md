# talent-trio-manager

## Description
当用户需要对组织内不同类型人才实施差异化管理、解决"机关人员该不该流动""专家要不要当干部""职员能不能一直做同一岗位"等分类管理问题时激活。适用于大型组织的干部/专家/职员分类管理、去官僚化改革、组织精简、人才分类激励、机关与一线人员差异化政策。不适用于：初创期（<100人）尚无明确分工的组织、已全部扁平化的敏捷团队、无需区分管理/专业通道的极简组织。

Trigger: 三类人才 / 主官专家职员 / 去南郭化 / 人才分类 / 机关改革 / 专家路线 / 职员管理 / 干部流动 / 差异化管理 / talent classification / 南郭先生

## I (Interpretation)
组织效率低下的根源之一：用同一套标准管理所有人。华为将人才分为三类，实施**差异化管理策略**：

| 类型 | 核心特征 | 管理策略 | 流动政策 | 考核重点 |
|------|---------|---------|---------|---------|
| **主官** | 承担管理责任，对结果负责 | 大起大落，能上能下 | 强制循环，5年无实践=白丁 | 责任结果、团队产出 |
| **专家** | 专业技术深厚，解决复杂问题 | 待遇可高于主官，专家体系≠行政体系 | 不断循环上战场，真刀真枪 | 专业贡献、实战成果 |
| **职员** | 从事确定性工作，保障运营 | 稳定为上，长期积累 | 不强制流动，胜任则留 | 工作质量、服务满意度 |

**核心原则**:
1. **去南郭化**: 干什么考什么，避免跨领域考核（如非洲考5G）
2. **主官必须有实战经验**: 机关主官需有成功项目实践，近期无实践不能提拔
3. **专家≠管理者**: 专家是待遇体系，不是行政管辖体系，优秀专家待遇可高于主官
4. **职员不流动**: 确定性岗位稳定化，避免"为流动而流动"的形式主义
5. **全科医生路径**: 学理工的新员工→半年交付实践→研发2-3年→分流（专家/管理）

## A1 (Past Application)
- **华为机关干部降级**: 无成功实践经验、三年内未上战场的主官，降为白丁，到内部人才市场找工作
- **李一男案例**: 26岁技术最强但管理能力最弱，被任命为研发负责人，配徐文伟做副职（政委），专家路线与管理路线互补
- **专家待遇高于主官**: 任正非明确提出"将来专家的待遇有可能普遍高于主官"
- **职员稳定化**: 美国副部长以下全是职员，竞选换的是部长（主官），不换副部长（职员）。华为借鉴此模式，稳定职员队伍

- "专家不愿意走管理路线，怎么给他们发展空间？"

- "怎么区分谁是真正的专家，谁是南郭先生？"

## E (Execution)

### Step 1: 岗位分类诊断
将组织内所有岗位按"确定性"和"责任范围"两个维度分类：

| | 高确定性 | 低确定性 |
|---|---|---|
| **大责任范围** | 主官（管理确定性团队） | 主官（管理不确定性业务） |
| **小责任范围** | 职员（执行确定性任务） | 专家（解决不确定性问题） |

判断标准：
- **主官**: 带团队、对结果负责、需要战略判断和人员管理
- **专家**: 需要深厚专业判断、解决复杂技术/业务问题、可独立完成高价值产出
- **职员**: 按标准流程执行、工作内容可标准化、经验积累提升效率

### Step 2: 制定差异化管理政策

**主官管理**:
- [ ] 建立"成功实践经验"档案，记录其负责的成功项目
- [ ] 设定强制循环规则：如机关主官每5年必须有一线实践，否则降级
- [ ] 允许大起大落：升职快，降职也快，降职后内部人才市场重新上岗
- [ ] 选拔标准：品德+责任结果+自我批判+领袖风范

**专家管理**:
- [ ] 建立专家等级体系（如华为七级专家），待遇与行政级别脱钩
- [ ] 强制实战循环：技术专家必须有市场/交付/研发的成功经验
- [ ] 考核标准：解决客户问题的实战成果，而非论文/考试
- [ ] 晋升路径：以"结果"证明能力，每次晋级需一线作战战果

**职员管理**:
- [ ] 梳理确定性岗位清单（如财务核算、行政事务、标准化运维）
- [ ] 实行岗位技能等级制，鼓励纵向深耕而非横向流动
- [ ] 稳定政策：胜任则长期留任，不轻易末位淘汰
- [ ] 服务标准：知晓服务对象需求，保障工作质量

### Step 3: 实施"去南郭化"考核
- **干什么考什么**: 按岗位实际工作内容设计考核指标，禁止一刀切
  - 非洲3G工程师 → 考3G交付能力，不考5G
  - 展厅讲解员 → 考客户体验讲解能力，不考战略洞察
- **禁止形式主义流动**: 炊事班长不需要上航母，确定性岗位不强制轮岗
- **建立体验官/督考机制**: 鼓励一线人员批评机关，敢于批评公司的优先晋职晋级

## B (Boundary)
- 不适用于：初创期组织（人手紧张，无法细分）、创意型/项目制组织（边界模糊，不适合刚性分类）
- 风险：分类过细可能导致官僚化，需定期审视岗位属性是否变化（如曾经的创新业务变成确定性业务）
- 注意："职员"标签在某些文化中可能被理解为"低级"，需明确职员是组织运行的压舱石，非贬义
- 局限：专家等级体系需要大量投入建立标准，中小企业可简化为"技术专家-高级专家-首席专家"三级
