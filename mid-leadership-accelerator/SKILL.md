# mid-leadership-accelerator

## Description
当用户需要快速提升中层管理者能力、解决"培训上了很多课但中层成长慢""中层跨部门协作差""中层不会培养下属"等问题时激活。适用于中层梯队建设、高潜人才培养、管理者从执行到管理的转型、跨部门协同能力提升、继任者准备。不适用于：高层领导力（战略层面）、基层员工技能培训、无直接主管支持的培养项目、无实战场景可提供的纯课堂培训。

Trigger: 中层培养 / 领导力加速 / 管理者培养 / 跨部门沟通 / 培养下属 / 在岗教练 / 实战培养 / 中层梯队 / 管理能力提升 / leadership accelerator / 训战结合

## I (Interpretation)
中层培养失效的普遍原因：培训太多、实战太少、目标太多、无人跟进。华为中层加速培养的核心是**"两项聚焦+实战教练+主管问责"**。

**核心方法论**:
1. **两项聚焦原则**: 每人每次只培养2个最关键的能力项（非全部短板，而是"对未来发展最重要"的项）
2. **实战替代培训**: 不在课堂学，在真实工作中练。主管设计实战场景，被培养者在实战中提升
3. **利益相关者评分**: 跨部门沟通能力 → 让"经常吵架的对方部门长"来打分；人才培养能力 → 让"被培养的下属"来举证
4. **主管是培养责任人**: 直接领导必须担任教练，不能培养接班人的不能晋升
5. **三个月周期+滚动迭代**: 3个月聚焦2项，改善后换新的2项，半年内超过半数人两项明显改善

**四类典型实战方案**:
- **跨部门协同弱**: 主管+对方部门长+被培养者三方定行动计划，对方打分
- **不会培养下属**: 指定一个下属，制定培养计划，三个月后下属举证提升
- **规划/前瞻性不足**: 让被培养者独立做部门规划，主管只提问不修改
- **商务谈判弱**: 主管模拟甲方提问→被培养者主谈、主管旁听→复盘得失

## A1 (Past Application)
- **华为中层加速计划**: 基于HAY领导力模型评估，提取普遍需要的2项关键改善项，培训后指定直接主管为培养责任人
- **跨部门沟通实战**: 被培养者与经常发生冲突的部门长三方制定行动计划，三个月后对方评估改善度
- **人才培养实战**: 被培养者选定最值得培养的下属，制定3个月提升计划，主管评估下属成长以反推培养者能力
- **规划能力实战**: 被培养者独立做信息化/市场/人力资源规划，主管只提问不修改（如"你有没有考虑竞争对手策略？"）
- **57%双项改善率**: 三个月后超半数人两项都明显改善，半年后三分之二双项改善，速度比传统培训快一倍

## E (Execution)

### Step 1: 识别两项关键改善项
对每个中层候选人，评估其能力差距，但**只选2项**（规则：对未来晋升最关键，而非当前最差的短板）

常见中层关键改善项清单：
- 跨部门沟通与协作
- 下属培养与梯队建设
- 业务规划与前膽性思考
- 商务谈判/客户沟通
- 团队激励与氛围建设
- 项目管理与统筹

筛选标准（同时满足）：
1. 当前表现有差距（<80分）
2. 对未来岗位至关重要（如晋升总监必需）

### Step 2: 设计实战培养方案（四种模板）

**模板A: 跨部门协作提升**
- 参与者：被培养者 + 其主管 + "经常发生冲突的对方部门长"
- 动作：
  1. 三方会议：列出主要协作问题（如信息不同步、优先级冲突）
  2. 制定3个月行动计划（如每周同步会、联合OKR）
  3. 执行：被培养者在真实工作中按行动计划协作
  4. 评估：3个月后对方部门长+联络人打分评估改善度

**模板B: 下属培养能力提升**
- 参与者：被培养者 + 其主管 + 被培养的下属
- 动作：
  1. 选定1名最值得培养的下属
  2. 制定该下属的2项提升计划
  3. 被培养者执行培养（辅导、授权、反馈）
  4. 评估：3个月后下属举证能力提升，主管评估培养者贡献

**模板C: 规划/前瞻性提升**
- 参与者：被培养者 + 其主管
- 动作：
  1. 主管将原本自己做的规划工作交给被培养者
  2. 被培养者独立完成业务/部门规划
  3. 主管只提问不修改（如"竞争对手策略考虑了吗？""客户需求变化呢？"）
  4. 评估：规划质量对比前后版本

**模板D: 商务谈判/沟通提升**
- 参与者：被培养者 + 其主管
- 动作：
  1. 主管模拟甲方/客户，提出刁钻问题
  2. 被培养者回答，反复模拟
  3. 真实谈判：被培养者主谈，主管旁听不干预
  4. 复盘：谈判后讨论得失，提出改进点

### Step 3: 建立制度保障
- **晋升挂钩**: 制度明确规定"不能培养接班人的中高层不能晋升"
- **KPI权重**: 人才培养占中高管KPI权重不低于20%
- **接班人数量**: 要求每个高管有2个基本胜任的接班人（参考GE标准）
- **周期管理**: 3个月为一轮，改善后滚动到下一项，不追求十项全能

## B (Boundary)
- 不适用于：无直接主管的人员（如总裁本人）、纯技术专家（不走管理路线）、基层员工（尚未到管理门槛）
- 风险：主管本身能力不足则无法有效教练，需先确保主管合格或引入外部教练
- 注意：此方法是"加速"而非"替代"系统培养，适用于关键中层，不适用于大规模全员培养
- 局限：需要真实的跨部门协作场景和谈判机会，若组织过于稳定缺乏实战机会，效果会打折扣
