# result-oriented-appraiser

责任结果导向的绩效评价：拒绝为学历、工龄、职称、内部公关和「假动作」付酬，按贡献将劳动者分为三类，以「茶壶里的饺子」为隐喻，建立以实际贡献和持续奋斗为核心的分配机制。

## 触发条件

当用户讨论绩效考核、不为假动作付酬、奋斗者、三类劳动者、茶壶里的饺子、责任结果导向、绩效公平、末位淘汰时激活。

**关键词**：绩效考核 / 假动作 / 奋斗者 / 三类劳动者 / 茶壶里的饺子 / 责任结果 / 绩效公平 / 末位淘汰 / 按贡献拿待遇 / 不让雷锋吃亏

## 使用说明

### 核心一：三类劳动者分类与差异化待遇

华为将劳动者明确分为三类（第17章）：

**第一类：普通劳动者（12级及以下）**
- 按法律相关报酬条款保护利益
- 根据公司经营情况给予稍好的报酬
- 这是企业对普通劳动者的关怀

**第二类：一般奋斗者**
- 允许部分人追求小家庭温暖，想按时回家吃饭
- 只要输出贡献大于支付给他们的成本，就可以存在
- 报酬可能比社会稍微高一点

**第三类：有成效的奋斗者**
- 分享公司剩余价值，通过奖金与股票激励
- 事业的中坚，企业渴望越来越多的人走进这个队伍
- 必须具有使命感，拿着高薪冲锋

**STOP检查点**：
- [ ] 是否明确区分了三类劳动者？
- [ ] 是否让第三类人（有成效奋斗者）获得显著更高的回报？
- [ ] 是否防止"在奋斗者层面也产生惰怠者"？

### 核心二：责任结果导向三原则

**原则1：淡化过程，强调结果**
- 过于关注过程会使员工专注于行为本身，忽略价值创造目标
- "正确的行为"与价值创造结果之间，没有明确逻辑关系
- 华为虽以价值观烙印鲜明著称，但考核坚持以结果为导向

**原则2：不考核动机**
- 对动机的考量在评价中是不必要的
- "假积极一辈子就是真积极。我们实行一系列的激励制度，能使得大家假积极一辈子就够了。"
- 不要问员工"是否真心为公司"，只看结果

**原则3：不凭素质付酬**
- 素质优秀、能力强、履历漂亮的员工一旦懈怠，躺在功劳簿上，必须一视同仁
- 素质不是考核关键，只看业绩结果
- 确保员工之间人人平等，客观考核方式把"公平"落到实处

**STOP检查点**：
- [ ] 考核指标中结果权重是否占主导（建议≥70%）？
- [ ] 是否有员工因"态度好但业绩差"而获得优待？
- [ ] 是否有"老资格"员工凭借过去贡献占用资源？

### 核心三：茶壶里的饺子 — 知识必须转化为贡献

**任正非原话**（第17章）：
> "茶壶中的饺子，倒不出来，不产生贡献，就不能得到承认。要通过奋斗，形成结果，才能作为要素。茶壶里的饺子，我们是不承认的。倒不出饺子，还占据一个茶壶就是高成本。"

**应用要点**：
- 知识是劳动的准备过程，是员工自己的投资行为
- 学历、认知能力、工龄、工作中的假动作、内部公关等，不能作为薪酬评价依据
- 员工在华为改变命运的方法只有两个：一是努力奋斗；二是提供优异的贡献

**STOP检查点**：
- [ ] 是否有员工以"我在学习/我在准备"为由长期无产出？
- [ ] 是否有人凭借高学历/名校背景要求更高待遇但无对应贡献？
- [ ] 招聘时是否过度看重学历而忽视实际产出潜力？

### 核心四：不为假动作付酬 — 消灭无效劳动

**任正非要求**（第17章）：
- 不喜欢有人说自己怎么怎么辛苦，要看工作成绩，没有业绩的工作没有意义
- 不要为加班而加班，不要搞形式主义
- 研发功能利用率不到22%，通信功能利用率不到千分之一，减少20%无效工作就是最大节约
- 洗煤炭的例子：任劳任怨把煤炭洗白，但不具有任何价值和意义

**STOP检查点**：
- [ ] 团队中是否有"表演式加班"？
- [ ] 周报/月报是否充满了无价值的过程描述？
- [ ] 是否有人用"辛苦"代替"成果"来争取资源？

### 核心五：钱分好了，管理的一半问题就解决了

**华为分配哲学**（第17章）：
- 建立"不让雷锋吃亏"的机制，让奋斗者得到合理回报
- 减人、增产、涨工资 — 把落后的人挤出去
- 大仁不仁：管理者总给员工讲"吃亏是福"，是在害人害公司
- 企业要让价值创造者幸福，让奋斗者因成就感而快乐

**STOP检查点**：
- [ ] 最高收入者是否确实是最大贡献者？
- [ ] 是否有"懒人占着位子不作为"却同样快乐？
- [ ] 分配规则是否公开透明，让分蛋糕的人最后一个拿？

## Anti-Example Blacklist

❌ **不要按工龄涨工资** — "经常看到调薪的时候有人说'这个人好几年没涨了，要涨一点工资。'为什么？这几年他的劳动质量是否进步了？他的贡献是不是真大了？如果没有，为什么要涨工资？"

❌ **不要把"辛苦"作为评价标准** — 工作描述中不要动不动就写"工作辛苦"，关键是业绩，要强调成效。

❌ **不要考核动机和态度** — "为了公司的利益而努力"和"为个人利益而努力"在华为看来不应有评价差异。

❌ **不要让高素质员工躺在功劳簿上** — 过去优秀不代表现在优秀，素质不是考核关键，当前结果才是。
