# 采购策略设计与选择方法论

基于华为采购管理体系，核心原则：**不同物料，不同策略；没有最好的策略，只有最合适的策略**。

## 核心思想

- **分类施策**：根据物料特性、市场状况、公司需求选择不同策略
- **策略组合**：单一策略往往不够，需要组合使用
- **动态调整**：市场变化、业务发展阶段变化，策略也应调整
- **效率与风险的平衡**：既要提高采购效率，又要控制供应风险

## 三大采购策略

### 策略一：协议供应策略（框架协议）

**适用场景**：
- 采购频次高
- 采购内容及市场价格相对稳定
- 供应商关系成熟

**操作方式**：
- 通过合理采购方式选定供应商
- 签订较长期限（≥1年）的产品采购协议
- 约定产品范围、价格、付款方式
- 有需求时直接下采购订单

**优点**：
- 减少每次询价比较过程，提高执行效率
- 长期合作增加互信，提高供货品质
- 降低采购成本

**缺点与对策**：
- 不适用价格变动快的产品
- 价格确定周期性，不能完全反映市场
- **对策**：建立查价制度，定期/不定期市场调查，依据市场调价

**典型应用**：标准件、通用物料、行政物品

---

### 策略二：有限竞争采购策略

**适用场景**：
- 具有行业特点且市场竞争不充分
- 涉及核心业务系统、需求复杂、技术含量较高
- 需反复论证才能实施

**操作方式**：
- 采购部与使用部门协商确定供应商范围
- 在一定范围内与潜在供应商多轮谈判
- 技术方案逐轮优化，最终确定合作方

**供应商范围筛选标准**：
- 行业认证资质
- 设备代理资质
- 从事相关行业资历
- 进货渠道正规性（厂商正规渠道及分销证明）

**优点**：
- 采购时间由采购部门根据紧急程度掌握
- 技术方案经逐轮谈判更符合实际需求
- 通过有限竞争使价格趋近期望值

**典型应用**：IT系统、专业服务、定制设备

---

### 策略三：拆分与组合策略

**适用场景**：
- 单个项目包含不同类别的采购细目
- 多个项目包含相同类别的采购细目
- 项目内容较复杂

**操作方式**：
- 将项目中不同层次、类别的采购区分开来
- 分别选择行业中较高水平的供应商
- 或整合同类细目形成批量采购优势

**拆分原则**：
- 项目规模及子项目重要程度
- 对生产运行的影响
- 用户需求与技术需要

**优点**：
- 合理规避采购风险
- 充分体现采购优势
- 保证各项采购细目的质量

**典型应用**：工程项目、系统集成项目、大型设备采购

## 采购方式选择矩阵

| 采购方式 | 适用条件 | 供应商数量 |
|---------|---------|-----------|
| 招标采购 | 符合招标条件的都应招标 | ≥3家 |
| 比价 | 需求明确、市场竞争充分、产品成熟 | ≥2家 |
| 竞争性谈判 | 市场竞争不充分，仅2家符合条件 | 2家 |
| 评审 | 50-100万，需求不易描述但竞争充分 | 多家 |
| 直接采购 | 单一来源、后续维修、框架协议、服务续签 | 1家 |

## 直采适用条件（必须满足之一）

1. 只能从特定供应商采购，或供应商拥有专有权，无合适替代
2. 原采购产品的后续维修、零配件供应、更换/补充必须由原供应商提供
3. 服务采购，供应商上一年度评价合格，服务质量/价格获认可，可续签
4. 框架协议中的产品

## 策略组合示例

**场景：新建数据中心**
- 服务器/网络设备 → 有限竞争采购（技术复杂，品牌差异大）
- 线缆/机柜 → 协议供应（标准化，频次高）
- 土建/装修 → 招标采购（金额大，竞争充分）
- 系统集成 → 拆分与组合（多专业交叉）

## 常见陷阱

- **一刀切**：所有物料都用同一种策略，忽视物料差异
- **该招不招**：为省事绕过招标，留下合规风险
- **框架协议变成永久协议**：签了就不再比价，价格逐渐偏离市场
- **拆分过细**：管理成本超过采购收益
- **组合后供应商能力不匹配**：打包给一家做，结果某些子项不擅长
