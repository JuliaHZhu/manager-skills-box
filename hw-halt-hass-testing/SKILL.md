# HALT/HASS 高加速试验方法论

基于华为硬件研发实践，HALT（高加速寿命试验）和HASS（高加速应力筛选）是两种用于**快速暴露产品设计和工艺缺陷**的可靠性试验方法。核心原则：**用比正常使用环境更严酷的应力条件，在更短时间内暴露潜在缺陷**。

## HALT（高加速寿命试验）

### 目的
- 快速暴露产品的设计薄弱环节
- 确定产品的工作极限和破坏极限
- 为改进设计提供依据
- **不是通过/不通过测试，而是发现缺陷的试验**

### 适用阶段
- 产品开发阶段（工程验证阶段）
- 新产品设计验证
- 设计变更后的验证

### 核心方法：步进应力

逐步增加应力强度，直到产品失效或达到设备极限：

1. **低温步进**：从常温开始，逐步降低温度（如每次降10°C），在每个温度点保持并测试功能
2. **高温步进**：从常温开始，逐步升高温度（如每次升10°C），在每个温度点保持并测试功能
3. **温度循环**：在确定的工作极限之间进行快速温度循环
4. **振动步进**：逐步增加振动强度（如每次增5Grms）
5. **综合应力**：温度循环 + 振动同时进行

### 关键概念

| 概念 | 定义 |
|------|------|
| 工作极限 | 产品仍能正常工作但已接近失效的应力水平（软失效） |
| 破坏极限 | 产品发生不可逆损坏的应力水平（硬失效） |
| 软失效 | 应力解除后功能恢复正常 |
| 硬失效 | 应力解除后功能不能恢复 |

### HALT试验流程

1. **准备阶段**
   - 确定试验样品（通常3-5台）
   - 准备功能测试夹具和程序
   - 确定监测参数和失效判据

2. **低温步进**
   - 起始温度：常温
   - 步进：每次降低10°C
   -  dwell时间：每个温度点保持直到热稳定 + 功能测试时间
   - 记录：工作极限、破坏极限、失效模式

3. **高温步进**
   - 起始温度：常温
   - 步进：每次升高10°C
   -  dwell时间同上
   - 记录同上

4. **温度循环**
   - 范围：低温工作极限 ~ 高温工作极限
   - 温变速率：尽可能快（通常≥30°C/min）
   - 循环次数：通常5-10个循环

5. **振动步进**
   - 起始：5Grms
   - 步进：每次增加5Grms
   -  dwell时间：每个振动级别10分钟

6. **综合应力**
   - 温度循环 + 振动同时进行
   - 这是最有效的缺陷暴露组合

7. **分析与改进**
   - 分析所有失效模式和根因
   - 设计改进
   - 重新进行HALT验证改进效果

## HASS（高加速应力筛选）

### 目的
- 在生产阶段快速筛选出存在潜在缺陷的产品
- 替代传统的ESS（环境应力筛选），效率更高
- **是通过/不通过测试**

### 适用阶段
- 生产阶段
- 小批量生产验证
- 批量生产筛选

### HASS与HALT的关系

HALT确定工作极限 → HASS使用工作极限的一定比例（通常60-80%）作为筛选应力

### HASS试验剖面设计

1. **确定筛选应力水平**
   - 低温：高于HALT工作极限（如工作极限-50°C，HASS用-40°C）
   - 高温：低于HALT工作极限
   - 振动：低于HALT工作极限
   - **绝对不能超过破坏极限**

2. **确定循环次数**
   - 通常2-5个温度循环
   - 需通过验证证明不会损坏良品、能有效剔除缺陷品

3. **夹具设计**
   - 必须能同时筛选多个产品
   - 确保每个产品受到的应力一致

### HASA（高加速应力稽核）

- HASS的简化版，用于生产线的定期稽核
- 不是100%筛选，而是抽样筛选
- 用于监控生产过程的稳定性

## HALT/HASS的关键成功要素

1. **功能测试必须在线**：在施加应力的同时监测产品功能，才能发现软失效
2. **温变速率要快**：温变速率越高，缺陷暴露越快（至少30°C/min）
3. **样品必须代表量产状态**：不能用工程样机代替
4. **失效分析必须彻底**：发现失效后必须找到根因并改进，否则试验白做
5. **HASS剖面必须验证**：证明不会损坏良品、能有效剔除缺陷品

## 常见陷阱

- **把HALT当认证测试用**：HALT是发现缺陷的，不是证明产品合格的
- **HASS应力过高**：超过破坏极限，把好产品也筛坏了
- **只看硬失效、忽视软失效**：软失效是工作极限的重要信号
- **不做失效分析**：发现失效但不分析根因、不改进
- **温变速率太慢**：温变速率不够高，缺陷暴露效率低
