# 三视角分析

基于丹尼特《直觉泵》第18章"意向立场"，重构为三种世界观。

## 核心框架

| 立场 | 关注什么 | 典型问题 |
|------|---------|---------|
| 物理立场 | 实际因果、物质约束 | "到底发生了什么？" |
| 制度立场 | 规则、位置、设计意图 | "谁有权决定什么？" |
| 博弈立场 | 信念、收益矩阵、均衡 | "他在赌什么？" |

三个立场是对同一现实的三种焦距。从物理到博弈：信息需求递减，预测风险递增，解释力递增。

## When to use

看到组织现象、理解学术争论、做研究设计、读论文觉得"漏了什么"、做战略分析。

## 三步切换

### Step 1: 锁定当前立场

看语言信号：

| 信号 | 立场 |
|------|------|
| "数据显示"、"因果机制"、"资源配置" | 物理 |
| "按规定"、"有权"、"制度设计" | 制度 |
| "他认为"、"博弈均衡"、"激励相容" | 博弈 |

### Step 2: 切到另两个立场

**物理立场**：硬约束是什么？纯看动作和结果，事实是什么？

**制度立场**：谁在什么位置？规则谁设计的？换套规则同一个事实会变吗？

**博弈立场**：各方相信什么？收益矩阵长什么样？被困在哪个均衡里？

→ **检查点**：列出三立场下的分析结果，问用户"有没有遗漏？"

### Step 3: 找立场错配

最有趣的分析来自错配：
- 你用物理立场解释，但问题是制度设计的
- 双方在对话，但用的不是同一个立场
- 一个立场下的"理性"在另一个立场下是"荒谬"

## 学术应用

**知识共享为什么推不下去**：

| 立场 | 分析 |
|------|------|
| 物理 | 没有共享工具、信息散落、技术壁垒 |
| 制度 | 考核只奖励个人产出、部门墙、汇报线 |
| 博弈 | 员工认为"知识是议价筹码"、分享无回报预期 |

三层同时处理才有效。

**读论文**：作者的理论假设落在哪个立场？如果只用了物理立场，制度和博弈层面的盲区在哪？

**跨学科**：经济学=博弈立场，社会学=制度立场，工程=物理立场。冲突常是立场不同，不是谁对谁错。

## 三立场的隐藏假设

结合 assumption-hunter：
- 物理立场：资源无限、信息免费、技术中性
- 制度立场：规则被遵守、设计意图=实际效果、权力稳定
- 博弈立场：理性人、共同知识、单一均衡

每个立场的"不言而喻"就是另一个立场的猎杀目标。

## 与其他skill配合

- **假设猎手**：在某个立场找到隐藏假设后，切到另两个立场检验
- **归谬法**：把一个立场推到极端
- **故意堆积**：混用三个立场论证时拆开
- **strategic-game-recovery**：四工具流水线第四步——商业战略文本的三视角博弈还原
