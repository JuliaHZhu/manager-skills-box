# ansoff-growth-navigator

当用户需要"规划企业成长路径、选择业务扩张方向、评估多元化风险"时激活。
适用于企业战略路径选择、新业务拓展决策、成长阶段诊断、避免冒进式扩张。
不适用于：初创期尚未找到任何业务方向、纯战术层面的执行细节、已经明确必须收缩的危机期。

Trigger: 安索夫 / Ansoff / 成长路径 / 业务扩张 / 新市场 / 新业务 / 多元化 / 聚焦主航道 / 战略路径 / 企业成长 / 市场选择 / 发展阶段

## 核心方法论

### 一、安索夫矩阵：新旧市场 × 新旧业务

```
              旧业务              新业务
         ┌─────────────┬─────────────┐
  旧市场 │  市场渗透    │  产品开发    │
         │ (深挖存量)   │ (老客新品)   │
         ├─────────────┼─────────────┤
  新市场 │  市场开发    │  多元化      │
         │ (老品新客)   │ (全新领域)   │
         └─────────────┴─────────────┘
```

**四象限定义**：

| 象限 | 名称 | 风险等级 | 核心能力要求 | 华为案例 |
|------|------|----------|--------------|----------|
| **旧市场 + 旧业务** | 市场渗透 | ⭐低 | 运营效率、成本控制 | 中国市场卖交换机→接入网→光传输→智能网（同客户，不同产品） |
| **旧市场 + 新业务** | 产品开发 | ⭐⭐中 | 产品研发、客户洞察 | 围绕中国电信客户，不断推出新产品满足其多样化需求 |
| **新市场 + 旧业务** | 市场开发 | ⭐⭐⭐中高 | 市场拓展、本地化 | 2001年起大举进入国际市场，产品不变，考验市场力 |
| **新市场 + 新业务** | 多元化 | ⭐⭐⭐⭐高 | 全新能力、资源整合 | 手机业务（从B端运营商到C端消费者，全新市场+全新业务） |

### 二、华为三阶段成长路径（安索夫应用）

**第一阶段：旧市场 + 旧业务 → 旧市场 + 新业务**
- 时间：约1987-2001年
- 路径：在中国市场（旧市场）不断推出新产品（交换机→接入网→光传输→智能网）
- 核心能力：产品开发 + 客户关系
- 规模：支撑华为发展到几百亿水平
- 关键：每个客户需要茶碗，就卖茶碗；需要茶杯、茶叶，就不断衍生产品

**第二阶段：新市场 + 旧业务**
- 时间：2001年起
- 路径：产品基本不变，进入全球市场（欧洲、俄罗斯、日本、东南亚等）
- 核心能力：市场拓展、不同区域差异化打法
- 关键洞察：**产品力和市场力不能同时发力**，因为太累了。先搞定产品，再拓展市场。

**第三阶段：新市场 + 新业务**
- 时间：2010年后
- 路径：进入终端C端市场（手机）、企业BG、云计算
- 核心能力：全新商业模式、全新客户群体
- 前提：前两阶段已积累足够的产品能力和市场能力

### 三、主航道定义与价值递进

**主航道的第一层理解**：
- 在一个行业内持续创造更高价值
- 华为：电话网 → 通信网（互联网）→ 智能网（万物互联）
- 价值持续放大：解决打电话 → 传递信息/视频/直播 → 智能世界

**主航道的第二层理解（核心定义）**：
> 主航道 = 企业为客户/用户提供的核心价值，且这个价值可以不断放大

**案例对比**：
- **华为主航道**：像太平洋一样的大数据流量管道（带宽越来越宽、时延越来越短）
- **3M主航道**：100多年做工具（从淘金镐头到不干胶、防晒膜）
- **阿里主航道**：让交易越来越方便（支付宝、菜鸟、盒马都围绕交易）
- **腾讯主航道**：即时通讯（QQ、微信、游戏都需要"即时"）

### 四、成长路径选择决策树

```
当前业务是否已做到行业前列？
├── 否 → 聚焦旧市场旧业务/旧市场新业务（深耕）
└── 是 → 核心产品是否足够成熟？
    ├── 否 → 继续打磨产品，不急于拓新市场
    └── 是 → 是否有新市场机会？
        ├── 否 → 继续深耕，寻找新机会
        └── 是 → 进入新市场 + 旧业务
            └── 新市场是否已站稳？
                ├── 否 → 继续拓展新市场
                └── 是 → 考虑新市场 + 新业务（多元化）
```

**关键原则**：
- 核心能力逐步提升，而不是冒进
- 所有新业务全都在新市场 → 死亡率非常大（反面案例）
- 主航道没变，但价值不断往更高处走

## 使用步骤

1. **定位当前象限**：企业在安索夫矩阵的哪个象限？
2. **评估核心能力**：当前最强的能力是什么？（产品/市场/运营/创新）
3. **选择下一步路径**：
   - 优先"旧市场+新业务"（利用现有客户关系推新品）
   - 其次"新市场+旧业务"（产品成熟后拓展新区域）
   - 最后才考虑"新市场+新业务"（需要全新能力）
4. **定义主航道**：明确企业为客户提供的核心价值，验证价值是否可持续放大
5. **分阶段推进**：不要同时发力产品和市场，分阶段提升核心能力

## 边界与反模式

❌ **不要**：
- 在旧市场旧业务没做扎实时就冒进新市场新业务
- 同时发力产品和市场（"太累了"，资源分散）
- 把多元化当作主航道（主航道必须唯一且清晰）
- 进入"新市场+新业务"时没有足够的能力积累

✅ **要**：
- 服从"核心能力逐步提升"的基本逻辑
- 每进入一个新阶段前，确认前一阶段已站稳脚跟
- 定义清晰的主航道：核心价值 + 可持续放大
