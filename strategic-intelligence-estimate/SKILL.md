# 战略情报评估

## R — 原文 (Reading)

> "没有情报作依据的战略是无用的战略，没有战略作指导的情报是无用的情报。""情报分析人员的职责不仅仅是罗列事实，使政策制定人员对相关情况更为熟悉，而要进行深入分析，把握事物的本质，预测其发展趋势。"
>
> — 高金虎, 第一章第三节 / 第六章第二节

---

## I — 方法论骨架 (Interpretation)

战略情报评估是一种超越简单事实罗列的深度分析活动。它的核心不是"知道了什么"，而是"这意味着什么"和"将会怎样"。

方法论包含三个层次：
1. **战略情报**（为国家最高决策服务）vs **部门情报**（为特定部门服务）vs **战术情报**（为战场指挥服务）
2. **实力与意图分离分析**：不仅评估对手"能做什么"，更要评估对手"想做什么"
3. **敌我对比的动态评估**：将对手的实力与意图放在与自身实力对比的框架中分析，而非孤立地看待

评估的最终目标是产生"国家情报"（National Intelligence）——经过综合分析、具有权威性、能够为最高决策提供依据的情报产品。

## A1 — 书中的应用 (Past Application)

### 案例 1: 艾森豪威尔时期的"司令官估计"
- **问题**: 1950年代美国军方夸大苏联威胁，主张大规模扩军，造成资源浪费和民众恐慌
- **方法论的使用**: 艾森豪威尔要求中央情报局与参谋长联席会议就苏美战争可能结局提供"司令官估计"。中央情报局分析师克莱因通过电子计算机模拟实战演习，发现苏联在远程空军方面不如美国，且从低空轰炸比高空轰炸更有效
- **结论**: 苏联既无采取军事行动的实力，也没有这样的意图；"今后两年将是遭受攻击的最危险时期"的说法被推翻
- **结果**: 为国家节约了大量资金，减少了恐惧情绪，为艾森豪威尔推行防务新观念扫清了障碍

### 案例 2: 越南战争中的兵力评估
- **问题**: 1967年美国军方过低估计越共实力，声称只有27万人，而中央情报局分析师萨姆·亚当斯估计实际可能有65万人
- **方法论的使用**: 国家评估办公室要求就争议问题做出客观报告，但面临政治压力
- **结论**: 中央情报局在正式《国家情报评估》中将敌军兵力总数确定为50万~60万人，同时向国防部表明有生战斗力量不到33.4万人
- **结果**: 情报成了政治的婢女，失去了独立地位；但1968年军方要求增兵20.6万人的事实最终戳穿了谎言，成为越南战争的转折点

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 在做重大战略决策前，需要对对手或环境进行深度分析，而非简单的事实罗列
2. 评估竞争对手的实力与真实意图，判断对方"能做什么"和"想做什么"
3. 面对信息噪音，需要从纷乱的数据中提炼出反映真实趋势的信号
4. 需要超越部门视角，从国家战略全局出发进行情报综合评估

### 语言信号 (用户的话里出现这些就应激活)

- "帮我评估一下...的实力和意图"
- "这个情报怎么分析？"
- "敌我双方的力量对比如何？"
- "不只是事实，我要知道这意味着什么"
- "司令官估计" / "commander's estimate"
- "庙算" / "知彼知己"
- "战略情报" / "strategic intelligence"

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确评估层级**
   - 完成标准: 确定本次评估属于战略情报、部门情报还是战术情报层级
   - 判停条件: 若用户明确只需要战术层面信息，则简化流程，跳到步骤4

2. **搜集与整理多源情报**
   - 完成标准: 获取公开资料、秘密情报、信号情报、人力情报等多渠道信息
   - 关键原则: 80%的战略情报来自公开资料的分析，而非秘密窃取

3. **分离"实力"与"意图"分析**
   - 完成标准: 
     - 实力维度：客观评估对手在军事、经济、科技、外交、心理等方面的能力
     - 意图维度：分析对手的战略目标、决策逻辑、文化背景、国内政治约束
   - 常见陷阱警示: 不要混淆"能做"和"想做"；不要因为对手有实力就假设其有相应意图

4. **进行敌我对比动态评估**
   - 完成标准: 将对手的实力与意图放在与自身实力对比的框架中分析
   - 方法: 模拟实战演习、兵棋推演、情景分析等

5. **形成国家情报评估结论**
   - 完成标准: 产出包含以下要素的评估文件
     - 核心判断（用一句话概括）
     - 关键假设（明确评估基于哪些前提）
     - 不确定性因素（标注哪些信息不确定）
     - 可能的情景发展（最佳/最可能/最坏）
     - 对决策的建议

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯数据采集与整理（只需要事实罗列，不需要分析判断）
- 战术层面的即时情报分析（如战场实时态势）
- 已明确结论的事后验证
- 需要精确数学建模的技术性分析（如密码破译）

### 作者在书中警告的失败模式

- **只见树木不见森林**：麦克纳马拉在越南迷信定量分析，问"围了多少英码铁丝网"，却忽视了战争的战略本质
- **实力与意图混淆**：军事情报机构习惯从最坏处着眼，夸大威胁以争夺军费，导致决策者不能了解实际情况
- **政治化评估**：约翰逊时期因国内政治原因，要求把越共兵力数字说低，情报成了政治的婢女

### 作者的盲点 / 时代局限

- 本书写于2004年，对信息技术革命后的情报分析（如大数据、AI辅助分析）涉及较少
- 对非国家行为体（如恐怖组织、跨国企业）的情报评估方法论覆盖不足

### 容易混淆的邻近方法论

- 与 SWOT 分析的区别: SWOT 是静态的、结构化的；战略情报评估是动态的、情景化的，更强调对意图的研判
- 与风险评估的区别: 风险评估聚焦于"可能损失"；情报评估聚焦于"对手想做什么、能做什么"
