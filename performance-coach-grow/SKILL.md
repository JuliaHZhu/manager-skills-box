# performance-coach-grow

绩效辅导与GROW模型：通过「教练式辅导→GROW四步法→绩效面谈→低绩效员工管理」四环节，把绩效管理从"秋后算账"转变为"持续赋能"，帮助下属达成高绩效。

## 触发条件

当用户需要学习绩效辅导方法、如何进行绩效面谈、管理低绩效员工、使用GROW模型、或讨论管理者如何帮助员工成长时激活。

**关键词**：绩效辅导 / GROW / 绩效面谈 / 教练式辅导 / 低绩效员工 / PIP / 绩效反馈 / 员工成长 / 中期审视 / 关键事件记录

## 使用说明

### 第一步：教练式辅导 — 从告知到使能

**传统管理 vs 教练式辅导**：

| 维度 | 传统管理 | 教练式辅导 |
|------|----------|------------|
| 方式 | 告知下属怎么做 | 询问下属怎么想 |
| 倾听 | 讲述自己的经验 | 倾听下属的问题 |
| 角色 | 指挥官 | 催化剂 |
| 目标 | 完成任务 | 帮助下属成长 |

**核心要点**：
1. **是询问，而非告知**：不要直接给答案，让下属自己思考
2. **是倾听，而非讲述**：先听完下属讲完，了解事情来龙去脉
3. **是使能，而非指挥**：做催化剂，激发下属潜能

**主管的角色 — 一面镜子**：
- 当有人向你请教时，先问自己："我必须回答吗，或者他们自己可以解决吗？"
- 把问题抛给下属："换做是你，你该怎么解决这个问题？"
- 下属交方案后，共同探讨有没有更好的方法

**关键原则**：
1. **提高认知**：辅导不仅仅是教怎么做，更重要的是教思考方法
2. **承担责任**：上级不单交事情给下级，还要让下级承担起应有的责任

**核心技能**：
1. **有效倾听**：听完下属讲的是什么、怎么来的、什么问题
2. **开放式提问**：不问"是明天还是后天"（封闭式），问"什么时候做"（开放式）

**STOP检查点**：
- [ ] 管理者是"给鱼"还是"教渔"？
- [ ] 辅导时是否以开放式提问为主？
- [ ] 是否真正倾听了下属的问题，而非急于给答案？

### 第二步：GROW模型 — 四步绩效辅导法

**G — Goal（建立目标）**：
- 帮助员工确定希望实现的问题
- 典型问题：
  1. 你希望谈些什么？
  2. 在这次讨论中你想达成什么结果？
  3. 最重要的问题是什么？
- **注意**：谈话前做好梳理，聚焦1-2个核心问题，不要泛泛而谈

**R — Reality（了解现状）**：
- 最重要的概念是**挖掘真相**，区分事实与借口
- 典型问题：
  1. 现在出了什么情况？
  2. 对此你有什么感觉？
  3. 事实是什么？
- **注意**：下属常给出很多借口（资源不够、时间太紧、市场不好），管理者要区分哪些是事实、哪些是借口

**O — Option（讨论方案）**：
- 通过提问帮助员工用头脑风暴法思考各类方法
- 典型问题：
  1. 你已经做过哪些尝试了？
  2. 你还可能会尝试什么？
  3. 如果你有更多时间会如何？
- **方法**：让团队每人写10条解决办法，汇总提炼4-5条可行方案

**W — Will（确定意愿）**：
- 阐明行动计划、设立衡量标准、规定分工角色、建立自我责任
- 典型问题：
  1. 下一步计划是什么？
  2. 你需要什么支持？
  3. 实现目标对你有什么意义？

**STOP检查点**：
- [ ] 辅导对话是否走完GROW四个步骤？
- [ ] 是否区分了事实与借口？
- [ ] 最后是否明确了行动计划和支持需求？

### 第三步：绩效辅导的两种形式

**1. 日常辅导**：
- **定义**：在绩效执行过程中，主管针对存在问题，不拘泥于形式对员工进行辅导
- **内容**：技能辅导、资源支持、意愿激发
- **频率**：随时进行，不限定正式场合
- **关键**：问题导向，发现问题→分析问题→解决问题

**示例**：
- 发现培训专员只按量完成培训，不管质量
- 先让他自己提问题 → 分析问题根本原因是质量不高 → 提供资源（话筒、喇叭）→ 激发意愿（他自己也想解决）

**2. 中期审视**：
- **定义**：定期（4月、10月）和员工进行绩效回顾、诊断和辅导
- **内容**：绩效回顾、诊断、辅导、关键事件记录、改进建议、资源支持
- **目的**：帮助员工保持正确的绩效方向
- **流程**：
  1. 发出绩效评估通知（4月2日）
  2. 资料整理（4月5日前）
  3. 部门经理反馈自评（4月5日前）
  4. 提交人力资源部汇总（4月8-10日）
  5. 总监办最终审批
  6. 员工申诉（两天后）
  7. 最终结果提交绩效管理委员会

**关键事件记录**：
- 日常工作中对员工做的好的/差的事情进行记录
- 不是等到季度末才回忆
- 好的经验要通过人力资源体系传播到全公司
- 要求：选择有开放心态的人，知识共享而非独占

**STOP检查点**：
- [ ] 是否有日常辅导和中期审视两种机制？
- [ ] 是否对关键事件进行了日常记录？
- [ ] 中期审视是否有明确的时间表和流程？

### 第四步：绩效面谈 — 结果反馈三步走

**为什么要做绩效面谈**：
1. 强化员工对自身绩效的责任
2. 保证员工对公司绩效评价客观公正的感知
3. 鼓励员工好的绩效行为持续出现
4. 澄清员工需要改进的领域以及改进方向
5. 激励员工持续成长，承担更大责任

**面谈三步走**：

**1. 准备**：
- **评价依据**：分析员工PBC，回顾之前辅导反馈要点
- **评价程序**：确保结果综合了员工各方面表现和相关评价者评价
- **规划沟通**：识别可能与员工不能达成共识的领域，计划如何沟通
- **沟通方式**：预约面谈时间地点，确保过程不被打扰（一对一、小房间、手机关机）

**2. 沟通**：
- 营造良好沟通氛围
- 与员工共同回顾PBC达成过程
- 肯定成绩与表现，指出不足与改进点，传达绩效等级
- 说明评价要点，通过具体事例解释等级原因
- 倾听和理解员工观点，澄清疑问（解释不了的记录下来，确认后回复）
- **注意**：不要瞎承诺（如"我一定给你沟通调到A"），说到做到

**3. 后续**：
- 制定改进计划（低绩效员工纳入PIP）
- 明确下一阶段目标
- 记录面谈内容，双方确认

**STOP检查点**：
- [ ] 面谈前是否做了充分准备（PBC分析、关键事件回顾）？
- [ ] 面谈中是否既有肯定又有指出不足？
- [ ] 是否避免了瞎承诺，解释不了的问题记录下来后续回复？

### 第五步：低绩效员工管理 — PIP与改进

**低绩效员工管理流程**：

1. **识别**：
   - 通过绩效评价确定C/D等级员工
   - 分析原因：能力不足？意愿不足？资源不足？目标不合理？

2. **面谈沟通**：
   - 明确告知绩效事实（用具体事例和数据）
   - 听取员工解释和反馈
   - 说明公司期望和改进要求

3. **制定PIP（Performance Improvement Plan）**：
   - 设定具体、可衡量的改进目标
   - 明确改进期限（通常1-3个月）
   - 提供必要的培训和资源支持
   - 定期检查进度

4. **跟踪评估**：
   - 按PIP约定的节点评估改进情况
   - 改进达标：恢复正常管理
   - 改进不达标：进入淘汰流程（调岗/降职/劝退）

**关键原则**：
- **劳动法合规**：需有两次绩效改进记录才能合法淘汰
- **平时不做，紧急推HR**是不行的
- **不能不作为**：发现问题要及时处理，不能拖延

**STOP检查点**：
- [ ] 低绩效员工是否有明确的PIP和改进期限？
- [ ] 是否提供了必要的培训和资源支持？
- [ ] 改进过程是否有记录，符合劳动法要求？

## 反模式警告

⚠️ **以下做法会导致绩效辅导失效**：
1. 只考核不辅导，秋后算账
2. 给下属"鱼"不给"渔"，只教招式不教方法
3. 辅导变成日常监控，每天汇报进度
4. 面谈时只批评不肯定，打击员工积极性
5. 瞎承诺（"我一定给你调A"），最后兑现不了
6. 低绩效员工不处理，等到想辞退时才推给HR
7. 关键事件不记录，到考核时才凭印象打分

## 绩效辅导周期速查

| 层级 | 日常辅导 | 中期审视 | 正式考核 |
|------|----------|----------|----------|
| 高层管理者 | 持续 | 半年度 | 年度 |
| 中基层管理者/员工 | 持续 | 4月/10月 | 半年度+年度 |
| 基层作业员工 | 持续 | 月度 | 季度 |
