# org-performance-aligner

组织绩效与个人绩效对齐：通过「DSTE+BLM+PBC对接→战略解码→戴帽子与拧麻花→预算与工资包管理」五层联动，确保组织目标层层分解、跨部门协同、资源合理配置。

## 触发条件

当用户需要设计组织绩效管理体系、解决部门墙/各自为政问题、讨论战略如何落地到个人、预算管理与编制管控、工资包设计、或DSTE/BLM/PBC对接时激活。

**关键词**：组织绩效 / 战略解码 / 戴帽子 / 拧麻花 / 个人与组织对齐 / 预算管理 / 工资包 / 部门协同 / 资源争夺 / 战略落地

## 使用说明

### 第一步：战略解码到个人 — DSTE+BLM+PBC对接

**三层对接框架**：

1. **DSTE（Develop Strategy to Execute）**：战略制定到执行的主流程
   - 战略规划（SP）→ 年度业务计划（BP）→ 预算 → 执行监控

2. **BLM（Business Leadership Model）**：业务领先模型
   - 差距分析 → 市场洞察 → 战略意图 → 创新焦点 → 业务设计 → 关键任务/组织/人才/文化

3. **PBC（Personal Business Commitment）**：个人绩效承诺
   - 组织绩效目标 → 个人绩效目标 → 能力提升计划

**对接逻辑**：
- 公司愿景/使命 → 战略目标（客户、质量、服务、成本、商业环境）
- 战略目标 → BSC四维度KPI → 部门工作重点
- 部门目标 → 个人PBC（组织目标+岗位职责+能力提升）

**组织绩效设计原则**：
- 组织绩效必须体现战略导向，不是简单的工作任务罗列
- 每个组织的绩效目标必须对公司整体战略有明确贡献
- 组织绩效与个人绩效通过PBC实现有机联结

**STOP检查点**：
- [ ] 个人PBC是否直接承接组织绩效目标？
- [ ] 战略目标是否通过DSTE流程层层分解到年度BP和预算？
- [ ] 组织绩效指标是否覆盖了财务、客户、内部流程、学习成长四维度？

### 第二步：解决部门墙 — "戴帽子"与"拧麻花"

**问题**：绩效考核后，各部门自扫门前雪，争夺资源，缺乏大局观。

**方法一：戴帽子（利益捆绑）**
- 把公司整体目标作为统一要求，放到每个产品线和每个区域的头上
- 示例：公司今年销售400亿美元，这个目标占每个产品线/区域20%权重
- 弊端：可能吃大锅饭，不努力的人也能搭便车

**方法二：拧麻花（交叉激励）**
- 核心理念：天堂与地狱的故事——自己舀自己吃 vs 互相喂对方吃
- 操作方式：
  1. 产品线向区域设立奖金包，激励区域推广新产品
  2. 区域向产品线设立奖金包，激励产品线按时交付新产品
  3. 虽然考的是同一个指标，但不同部门之间有奖金包作为交叉激励机制
- 效果：产品线愿意推新产品，区域愿意卖新产品，形成合力

**应用场景**：
- 区域 vs 产品线：区域愿意卖成熟产品扩容，产品线愿意推新产品
- 销售 vs 交付：销售签单 vs 交付能力不匹配
- 研发 vs 市场：研发做长期创新 vs 市场做短期销售

**STOP检查点**：
- [ ] 是否存在部门各自为政、争夺资源的现象？
- [ ] 是否设计了"拧麻花"式的交叉激励机制？
- [ ] 公司整体目标是否通过"戴帽子"方式绑定到各部门？

### 第三步：预算管理与编制管控

**预算管理原则**：
- 预算编制与组织绩效挂钩：先定目标，再定预算
- 预算不是简单地按人头分配，而是按战略优先级分配
- 预算调整必须与绩效调整同步

**编制管控原则**：
- 编制不是按部门要人，而是按战略任务定编制
- 控制编制增长，提高人均效益
- 绩效管理要与编制管理联动：绩效好的部门可以增编，绩效差的部门要缩编

**工资包管理**：
- 工资包总额与公司整体效益挂钩
- 部门工资包与部门组织绩效挂钩
- 个人工资与个人绩效挂钩
- 三个层级联动：公司工资包 → 部门工资包 → 个人工资

**STOP检查点**：
- [ ] 预算编制是否基于战略目标而非部门惯性？
- [ ] 编制增长是否与组织绩效挂钩？
- [ ] 工资包是否实现了公司-部门-个人三级联动？

### 第四步：组织绩效与个人绩效的承接关系

**承接逻辑**：

```
公司战略目标
    ↓
组织绩效（部门/团队）
    ↓
个人绩效（PBC）
    ↓
结果应用（薪酬/晋升/发展）
```

**关键原则**：
1. 组织绩效是个人绩效的前提：组织绩效不好，个人绩效再好也要受约束
2. 个人绩效是组织绩效的基础：只有个人业绩达成，才能保证组织绩效实现
3. 两者形成有机整体，不是孤立评价

**组织绩效管理要点**：
- 组织绩效侧重结果导向，关注部门对公司的贡献
- 组织绩效评价要考虑市场环境、竞争态势等外部因素
- 组织绩效结果影响部门资源分配、干部评价、团队激励

**个人绩效对组织绩效的承接**：
- PBC中的"组织绩效目标"部分直接承接部门目标
- 个人岗位职责的履行支撑组织流程运转
- 超越职责的交叉贡献提升组织整体效率

**STOP检查点**：
- [ ] 个人PBC中是否明确包含了组织绩效目标的承接？
- [ ] 组织绩效评价是否考虑了外部市场环境因素？
- [ ] 个人绩效结果是否与组织绩效结果形成联动关系？

### 第五步：绩效管理是为了赚钱还是分钱？

**核心理念**：绩效管理是为了**赚钱**，不是为了**分钱**。

- **赚钱导向**：绩效管理是战略落地的工具，目的是提升组织绩效、实现公司战略目标
- **分钱导向**：把绩效管理当成奖金分配的工具，为分钱而考核

**华为观点**：
- 价值创造 > 价值评价 > 价值分配
- 先创造价值，再评价价值，最后分配价值
- 如果只是为了分钱，不需要复杂的绩效管理，打分统计就够了
- 绩效管理的最终目的是让员工出于意愿也愿意付出超越职责的努力

**STOP检查点**：
- [ ] 绩效管理的出发点是为了提升组织绩效还是为了分配奖金？
- [ ] 是否建立了"价值创造→评价→分配"的完整闭环？
- [ ] 管理者是否把绩效管理当成自己的"家庭作业"而非HR的工作？

## 反模式警告

⚠️ **以下做法会导致组织与个人绩效脱节**：
1. 个人目标与组织目标两张皮，各干各的
2. 部门之间没有交叉目标，只有各自KPI
3. 预算编制按人头平均分配，不与绩效挂钩
4. 工资包固定不变，干好干坏一个样
5. 把绩效管理当成年终分钱大会，忽视过程管理
6. 组织绩效只考结果不考过程，忽视战略投入
