# 灰犀牛识别器 (Gray Rhino Spotter)

## R — 原文 (Reading)

> "灰犀牛是大概率且影响巨大的潜在危机。这个危机有发生变化或改变的可能，是可预测的。"
>
> "不是‘能否发生’而是‘何时发生’。"
>
> "我们只有在犀牛非常靠近而且是冲着我们个人而来时，才会采取行动。但是，它离我们越近，我们的选择机会就越少，我们就要越快地做出决定。"
>
> — 渥克, 第一章

## I — 方法论骨架 (Interpretation)

灰犀牛 ≠ 黑天鹅。

| | 灰犀牛 | 黑天鹅 |
|--|--------|--------|
| 概率 | 高 | 低 |
| 可预测性 | 显而易见 | 不可预测 |
| 核心问题 | 为什么我们不行动 | 为什么我们无法预测 |
| 预警信号 | 大量存在 | 几乎没有 |
| 应对策略 | 打破否认、测量、行动 | 杠铃、反脆弱、冗余 |

灰犀牛的五个特征：
1. **高概率** — 不是"是否"而是"何时"
2. **高影响** — 一旦发生，后果严重
3. **可预测** — 事前有明显的预警信号
4. **人为不作为** — 危机之所以发生是因为我们没有采取行动
5. **渐进性** — 通常是慢慢积累，最后突然爆发

## A — 行动模板 (Action)

### 触发条件
当你听到以下信号时，考虑激活此技能：
- "迟早要出事"
- "大家都知道，就是没人管"
- "这个问题存在很久了"
- "我们一直说要做，但总是推迟"
- "如果X发生，后果会很严重"（且X的概率很高）

### 识别灰犀牛的五个问题

1. **概率检验**：这个事件发生的概率是高还是低？（灰犀牛 = 高概率）
2. **可见性检验**：预警信号是否已经存在？（灰犀牛 = 显而易见）
3. **不作为检验**：人们是否已经在讨论但尚未行动？（灰犀牛 = 明知故犯）
4. **影响检验**：一旦发生，影响是否巨大？（灰犀牛 = 高影响）
5. **紧迫性检验**：是否已经从"远期问题"变成"眼前问题"？（灰犀牛 = 渐进逼近）

### 输出格式

```
灰犀牛识别报告
═══════════════════════════════════════
【事件描述】: [用户描述的问题]
【概率评估】: 高 / 中 / 低
【可见性】: 显而易见 / 部分可见 / 隐藏
【当前状态】: 尚未发生 / 正在发生 / 已经爆发

【五阶段位置】: 
  □ 否认    □ 得过且过    □ 诊断/争吵    □ 恐慌    □ 行动

【关键预警信号】:
  1. [信号1]
  2. [信号2]
  3. [信号3]

【为什么尚未行动】(至少列出3个原因):
  1. [原因1]
  2. [原因2]
  3. [原因3]

【与黑天鹅的区别】:
  [具体分析]

【下一步建议】:
  [建议激活的skills: denial-breaker / rhino-stage-diagnoser / measure-change-scale]
═══════════════════════════════════════
```

## V — 价值锚点 (Value Statement)

> 大多数人把精力花在寻找"黑天鹅"——那些不可预测的罕见灾难。但更多时候，毁灭我们的不是不可预测，而是明知危险却选择视而不见。灰犀牛识别器的价值在于：帮助你在危机还很远、选择还很多的时候，就承认它的存在。

## ++ 边界与禁忌

### 不适用场景
- 纯技术/数学概率计算
- 已经明确且正在处理的风险（不需要"识别"，需要"执行"）
- 低概率、不可预测的事件（请使用黑天鹅/反脆弱框架）

### 常见误用
- ❌ 把每一个问题都标记为"灰犀牛" — 灰犀牛必须同时满足"高概率"+"高影响"+"显而易见"
- ❌ 把个人焦虑等同于系统性危机 — 需要区分主观恐惧和客观威胁
- ❌ 只识别不行动 — 识别的目的是推动进入后续阶段

### 升级路径
识别 → 阶段诊断 (`rhino-stage-diagnoser`) → 打破否认 (`denial-breaker`) → 测量-改变-规模化 (`measure-change-scale`)
