# marketing-battle-planner

当用户需要"制定年度营销规划、管理区域市场格局、平衡短期业绩与长期发展"时激活。
适用于区域业务规划、销售目标管理、市场机会分析与选择、营销资源配置。
不适用于：纯品牌广告投放决策、单一项目销售执行、无区域管理职责的个人销售。

Trigger: 营销规划 / 山头目标 / 份额目标 / 市场格局 / 年度业务规划 / 市场管理 / 圈养模式 / 营销战略 / 区域管理 / 销售目标 / 市场洞察 / 18%预算 / 市场机会

## 核心方法论

### 一、营销规划总体逻辑（自顶向下）

```
市场洞察 → 机会识别 → 机会选择（价值评估+能力评估） → 制定目标 → 策略/计划/预算 → 管控执行 → 业务目标达成
```

与"散养模式"的区别：
- **散养模式**：给一线很大自由发挥空间，以具体项目驱动，只重视短期
- **圈养模式（华为）**：业务设计自顶向下、一竿子插到底。打哪儿、怎么打、打成什么样、打不好什么后果，公司都会告诉你。有自由度，但有一个"圈"，不能出圈。

### 二、年度业务规划三大支柱

#### 支柱1：市场洞察（Market Insight）
- 从年初到年尾持续进行，不断发现机会
- 现实：年初看到的大项目，到年底只有50%真正抓住，另外50%因主客观原因消失
- 因此必须持续洞察，不能"做一次管一年"

#### 支柱2：市场管理（Market Management）
- 本质：针对市场目标差距的管理行为
- 核心动作：当一个机会消失时出现"缺口" → 开动雷达找新机会补上
- **案例（华为2003年SARS）**：中国区要求减任务，但海外市场不受影响 → 从国内抽调资源输送到海外 → 当年海外市场完成230%增长，最高时贡献公司总体70%
- 原则：局部市场不利时，把资源转移到有机会的区域

#### 支柱3：市场格局管理（Market Position）

市场格局 = **山头目标** + **份额目标**

| 目标类型 | 定义 | 性质 | 预算分配 |
|----------|------|------|----------|
| **山头目标** | 新区域、新客户、新产品的拓展 | 投资型（烧钱） | 约18%预算 |
| **份额目标** | 老产品市场占有率的持续提升 | 收割型（产粮） | 约82%预算 |

**任正非比喻**：连农民都知道，开垦一块荒地，要翻3-5年才能成为可耕种的熟地。今年才翻了地，明年就想产粮收获，根本不现实。不注重开荒，未来就无地可种。

### 三、三级销售管理平台

| 层级 | 定位 | 核心职责 |
|------|------|----------|
| **总部** | 战略决策与资源调配 | 审批目标调整、跨区域资源调度、政策制定 |
| **地区部** | 区域协调与支撑 | 区域内资源协调、经验复制、平台支撑 |
| **代表处** | 一线经营单元 | 基于营销规划逻辑完成区域业务规划，是经营责任主体 |

### 四、目标管理与动态调整

**目标原则**：
- 各经营单元目标轻易不能动，改动必须由公司决策批准
- 遇到大目标调整，给相应政策（加人、加钱、提高奖金包）

**两头挤压机制（华为年底操作）**：
1. **逼单（对完成好的区域）**：
   - 问题：区域快完成时有意识控制项目节奏，藏粮食到明年（知道明年目标还要加25%）
   - 对策：总部领导飞一线"威逼利诱"——抢不回来今年不发奖金；抢回来给你多加

2. **底线目标（对完成差的区域）**：
   - 设置底线目标，给最后一次机会
   - 底线都完不成 → 年底就别干了

### 五、考核设计：财务驱动 vs 格局驱动

**常见问题**：纯财务驱动（只看数字）→ 大区总只关心今年完成，不管明年颗粒无收

**华为做法**：
- 区域管理职责 = 保障区域业务发展可持续、有后劲
- 考核兼顾：今年生存 + 未来发展
- 通过预算管控（18%山头投入）强制平衡

## 使用步骤

1. **市场洞察**：持续扫描区域市场机会（全年不间断）
2. **机会选择**：评估机会价值 + 自身能力 → 选择重点突破的机会
3. **制定双目标**：
   - 山头目标（新区域/新客户/新产品）：投入18%资源
   - 份额目标（老产品份额提升）：产出82%资源
4. **策略与预算**：匹配目标制定打法、人员、费用
5. **执行管控**：月度/季度跟踪，动态调整资源
6. **年底两头挤压**：逼单 + 底线目标，确保全年任务完成

## 自检清单

- [ ] 是否持续进行市场洞察（而非年初一次）？
- [ ] 区域管理中是否兼顾了山头目标（未来）和份额目标（现在）？
- [ ] 是否有18%左右的预算投入到新机会突破上？
- [ ] 考核是否只盯着财务数字，忽略了市场格局可持续性？
- [ ] 当局部市场不利时，是否有机制将资源转移到有机会的区域？
- [ ] 大区总是否真正承担区域管理职责，还是只是"大Sales"？

## 边界与反模式

❌ **不要**：
- 目标一定就"干就完了"，不做市场洞察（15亿→50亿时就会暴露问题）
- 把所有资源都投入到产粮区，不烧荒（未来无地可种）
- 以财务数字作为唯一考核指标
- 区域总只做大项目、不做区域管理

✅ **要**：
- 建立"缺口管理"机制：机会消失时主动找新机会补位
- 给山头目标合理的资源投入和耐心（3-5年成熟周期）
- 年底对完成好的区域逼单、对差的区域设底线
