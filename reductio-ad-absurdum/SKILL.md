# 归谬法

## When to use

用户提出主张/论证/假设，想检验逻辑自洽。触发："归谬一下"、"推到极端看看"、"这个论证站得住吗"、"帮我检验一下这个逻辑"。

审稿、研究设计、文献批评时也可用。

## 四步

### Step 1: 提取前提

列出所有前提。编号。问用户："这是我的理解，有没有遗漏或歪曲？"（防稻草人）

```
前提1: ...
前提2: ...
前提3: ...
```

如果论证前提不清晰，要求用户重述后再继续。

### Step 2: 推理到底

接受所有前提为真，一步步推。不满足于第一个有趣结果——最致命矛盾常在几步之后。

```
如果前提1成立 → 
如果前提2也成立 → 
...
最终结论: ...
```

### Step 3: 检查矛盾

a) **内部矛盾** — 结论与原有前提冲突？
b) **外部矛盾** — 与已知事实冲突？
c) **自反矛盾** — 结论自我否定？

### Step 4: 报告

**无矛盾**：归谬检验通过。前提+推理下逻辑自洽。

**有矛盾**：
```
矛盾点: [描述]
追溯到前提N: [该前提导致矛盾]
建议: 修改/放弃前提N，或限制适用范围
```

## 关键规则

- **基于准确理解**：歪曲对手叫"以蠢类推"（parody），不叫归谬
- **区分稻草人**：归谬基于对方真实前提；稻草人基于歪曲版本
- **死不松口**：对方说"荒谬就荒谬，我接受"——不争辩。记录即可
- **学术场景**：文献批评（检验理论极限推论）、假设检验（推到极端看是否导出不可能结果）、方法论审查、论文审稿

## 常见陷阱

### 陷阱1：荒谬结论=论证错误？

有时归谬推到极限后得出的结论看起来很荒谬——但它可能就是现实的均衡。

例：银行CRE贷款的"展期并祈祷"。推到极限：所有银行都在延长不良贷款、不承认损失、合谋推迟市场出清。这听起来像阴谋论。但它在现实中就是银行业正在做的事——因为流动性的买家池只有敞口的1.2%，任何一家银行率先承认损失就会触发自身的资本充足率危机。**个体理性在集体层面制造了"荒谬"但稳定的均衡。**

判断方法：推到极限后别急着宣布论证有矛盾。先问——这个荒谬结论在现实中是否已经在发生？如果是，那就不是论证有问题，是现实本身就是这个结构。

### 陷阱2：归谬找到了矛盾就以为驳倒了论证

归谬暴露的是"前提+推理链条"中最薄弱的环节。但有时候薄弱的是推理（隐藏假设缺失），有时候薄弱的是现实约束（论证缺少了一条关键信息）。找到矛盾后要溯源到前提——不要直接宣布"论证错"。说"前提N在加入现实约束X后不再成立，论证需限制适用范围"。

## 示例

### 检验"所有决策都应基于数据"

前提1: 所有决策都应仅基于数据，不靠直觉。
前提2: "数据"指已被收集和量化的信息。

推到底："是否要收集某项新数据"本身是一个决策——但决定收集什么需要判断哪些数据可能有用，这依赖直觉。结论：该原则无法自我应用——元决策"选择收集什么数据"无法基于数据。

矛盾：内部矛盾。追溯到前提1。建议改为"可基于数据的决策应基于数据；元决策需结合先验判断。"

### 检验"意识就是神经元活动"

前提1: 意识完全等同于特定神经元活动模式。
前提2: 相同神经元活动模式=相同意识体验。

推到底：取出产生红色意识的神经元放培养皿，给相同电刺激，产生相同活动模式。根据前提，培养皿应有"红色感觉"。但培养皿显然没有——只是化学反应。

矛盾：外部矛盾。追溯到前提1。神经元活动是必要条件非充分条件。

## 完成后

1. 记录分析到wiki
2. 对有问题前提给出修改建议
3. 反向检验：否定该前提会怎样？

## 与其他skill的配合

六个直觉泵工具互相独立，可按需组合：

- **故意堆积检测** → 拆开混在一起的主张
- **假设猎手** → 挖隐藏前提
- **旋钮检测** → 不改故事不改人，拧环境设定检验论证
- **归谬法**（本skill）→ 推到极限找矛盾
- **三视角（意向立场）**→ 物理/制度/博弈三个镜头还原选项空间
- **四层转化法** → 模糊问题→可执行规则

以上工具均为独立skill，不需要按固定顺序使用。用户针对具体问题选择合适工具即可。

> **注意**：之前有一个专为大前研一《麦肯锡战略五卷》定制的"四工具流水线"（故意堆积→假设猎手→归谬法→三视角），保存在 strategic-game-recovery skill 中。那套流水线是该书的专用分析框架，与上述六个独立直觉泵skill不同。不要将两者混淆。
