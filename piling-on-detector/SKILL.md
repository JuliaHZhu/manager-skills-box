# 故意堆积检测器

基于丹尼特《直觉泵》第9章。

## 是什么

把多个不同主张混在一起，让读者以为它们是一个整体。驳倒最弱的那个，读者就觉得整个"包裹"倒了。

丹尼特的例子——古尔德：
> "当我们谈论'从单细胞到人类的长途跋涉'时，似乎进化是一条进步的谱系——没有比这个想法更不现实的了。"

堆积了两个主张：(1) 进化有连续谱系（达尔文证实了）；(2) 这谱系代表"进步"（确实可质疑）。说"这个想法"不现实——读者以为两个都驳倒了。

## 三步检测

### Step 1: 拆包

把每个主张单独列出，编号。问：**这段文字到底断言了几件事？**

```
主张1: ...
主张2: ...
主张3: ...
```

→ **检查点**：列出后复述给用户确认理解是否准确。

### Step 2: 逐条检验

每个主张：
- 被论证了吗？还是只被提到？
- 和原文作者的真实观点一致吗？还是被简化/歪曲了？
- 单独看站得住吗？

**技巧**：找"这个""该"等代词——"没有比这个想法更不现实的了"——"这个"到底指主张1还是2还是包裹？

### Step 3: 画堆积图

```
被攻击的"包裹":
  ├─ 主张A: [是否被论证] [是否被歪曲] [单独成立？]
  ├─ 主张B: [否] [是] [部分成立]  ← 实际只驳倒这个
  └─ 主张C: [否] [否] [成立]
```

结论：**"作者驳倒了B，但让读者误以为A和C一起倒了。"**

## 四种变体

| 变体 | 特征 | 检测法 |
|------|------|--------|
| 稻草人堆积 | 先简化对手观点再驳 | 交叉用归谬法检验 |
| 滑坡堆积 | A→B→C→灾难，堆成必然链 | 每步问：必然性是什么？ |
| 共识堆积 | "大多数学者认为X" | 他们各自到底说了什么？ |
| 证据堆积 | 引用大量研究但每篇支持不同版本 | 逐篇核对实际发现 |

## 用法

**读文献时**：拆开，不直接说"他在堆积"。指出哪些论证了，哪些没有。

**自己写作时**：检查——有用"这""该"模糊多个主张吗？主动拆："这里有三个不同问题：第一...第二...第三..."

**审稿时**：回复——"审稿人将三个问题放在一起。关于X我们同意；关于Y回应是；关于Z原文说的是..."

## 与其他skill配合

- **归谬法**：拆包后对某个主张归谬到底
- **假设猎手**：堆积背后常有未检验的共享假设
- **strategic-game-recovery**：四工具流水线第一步——商业战略文本的博弈还原
