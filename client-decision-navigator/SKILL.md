# client-decision-navigator

当用户需要在标前阶段影响客户决策、穿透客户决策链条、或设计差异化竞争方案时激活。

适用于：ToB大项目销售、标前引导、客户决策链分析、价值主张设计、差异化方案制定、客户关系拓展。

不适用于：标书已发出的纯投标阶段、纯价格竞争的标品采购、客户关系已经固化无需拓展的续约项目。

关键 trigger：标前引导 / 客户决策链 / 权力地图 / 鱼骨图 / SPIN / 价值主张 / 差异化方案 / 客户关系 / 拜访策划 / 大项目销售。

## 核心理念：项目成功的80%在标前引导

有经验的销售人员都知道，一个项目标书发出来的时候，80%的结果其实已经基本决定了。"铁三角"销售法的核心之一，就是各个角色在线索开始就不同程度地介入。

标前引导主要包括：公司价值主张的制定和传递、客户关系规划和拓展、解决方案引导。

---

### 一、价值主张设计

客户为什么选择你？关键是你向客户传递了什么样的价值主张。

**价值主张四要素**：
1. **客户需求满足程度**：从客户、竞争对手和自身三大维度进行系统性分析。
2. **公司独特优势**：技术、产品、服务及综合解决方案优势。
3. **方案独特价值**：以客户需求和痛点为出发点，协助客户制定合理的招标规则。
4. **竞争差异价值**：让客户准确把握住核心技术水平、产品质量、供货能力、运作速度、服务水平等差异化价值。

**关键动作**：
- 从客户成功关键要素分析出发，识别权重，结构化制定引导策略。
- 对技术招标规则的引导是项目成功至关重要的因素。
- 将价值货币化：让客户从关注投资成本转向关注综合成本，再到关注投资价值回报和价值分配。

### 二、客户决策链穿透

**核心原则：找对人，说上话，办成事。**

**决策链六类角色**：
1. **批准者**：能在合同上签字的人。
2. **决策者**：对项目做最终决策的人（常与批准者同一人）。
3. **影响者**：决策者征求意见的人（使用者、采购人员等）。
4. **评估者**：使用过产品或与供应商有过接触的人。
5. **隐形角色**：决策者的股东、利益相关方、家人、好友、明日之星等。
6. **竞争对手关系人**：与竞争对手关系密切的客户方人员。

**工具1：客户权力地图（Power Map）**
- 展示客户内部权力结构及对决策的影响力。
- 评分规则：强烈排他性支持=3分，良好业务联系=2分，微弱支持=1分，中立=0分。
- **注意**：每个新项目都要重新分析，不能简单照搬组织结构图。

**工具2：鱼骨图（Fishbone）**
- 从右往左：越靠近目标的决策链角色越重要。
- 从外围向中心轴：越靠近轴线的越重要。
- 用不同颜色标明关系现状，精准到职务和姓名。
- 快速得出下一步工作计划，有针对性地关注和改善客户关系。

### 三、SPIN顾问式销售法

用于帮助客户识别痛点，提出差异化解决方案。

**S（Situation Question）背景问题**
- 发现客户的不满、困难和痛点。
- 例：客户所处国家的宏观环境、客户之间的竞争、投资建设规划及方向。

**P（Problem Question）困难问题**
- 客户对现状的问题、不满或困难（隐性需求）。
- 例：市场战略、盈利痛点、抗风险能力、业务部署痛点、网络性能、项目成本。

**I（Implication Question）暗示问题**
- 不及时解决痛点将带来的更大麻烦、更高成本、更大风险。
- 让隐性需求变成显性需求，让客户意识到必须采取行动。
- 例：网络架构问题不优化，是否无法赢得消费者，继而无法获得财务回报？

**N（Need-payoff Question）需求效益问题**
- 客户参与讨论解决方案及其能够产生的价值。
- 注重解决方案，通过全球应用案例消除担忧，通过技术测试验证可行性。

### 四、拜访策划与复盘

**拜访三原则**：
1. **精心策划，重视细节，提升客户体验**：每次拜访打出5页以上PPT，介绍公司、产品、价值。细节藏着魔鬼（如为客户在酒店浴袍袖口绣名字）。
2. **以终为始，达成拜访目标**：站在目标看策划，站在未来看现在。标前引导阶段围绕客户需求和痛点，重塑客户购买构想。
3. **勤于复盘，预见下一次成功**：倾听和记录客户声音，回到公司反复研究分析，刷新拜访策略。引入美军AAR（After Action Review）方法：结果记录在案，训练后复盘点评。

## 使用流程

1. **绘制权力地图**：针对当前机会点，列出所有决策链角色，评估与本公司和竞争对手的关系分值。
2. **SPIN痛点挖掘**：对关键角色进行一轮SPIN访谈，确认客户的隐性需求和显性需求。
3. **价值主张校准**：基于痛点，重新校准方案的独特价值和竞争差异价值，尝试将其货币化。
4. **拜访策划**：为下一次关键拜访准备材料（5页PPT起），明确拜访目标和预期成果。
5. **AAR复盘**：拜访结束后24小时内完成复盘，记录客户反馈，刷新下一步行动计划。
