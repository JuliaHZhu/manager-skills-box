# BLM业务战略规划框架

## R — 原文 (Reading)

> BLM是华为中高层用于战略制定与执行的工具与框架，它从差距分析、市场洞察、战略意图、创新焦点、业务设计、关键任务、正式组织、人才、氛围与文化、领导力与价值观等各个方面，帮助管理层在制定与执行企业战略的过程中实现系统思考、务实分析、有效资源调配及执行跟踪。
>
> — 华为战略管理实践, 第12章

> 业务战略规划的第一性原理是：通过战略规划，构建起创造客户价值（市场成功）、企业价值（财务成功）且可持续的能力（持续成功）。
>
> — 华为战略管理实践, 第17章

## I — 方法论骨架 (Interpretation)

BLM是一个将"战略"与"执行"熔于一炉的完整框架。它不是一个清单，而是一个**有因果逻辑的循环系统**。

框架分左右两半：

**左半（战略制定）：**
1. **差距分析** — 起点。识别业绩差距（当前vs目标）和机会差距（当前vs未来可能），差距是战略工作的原动力。
2. **市场洞察** — 输入。通过"五看"（看趋势、看客户、看竞争、看自己、看机会）为后续设计提供信息。
3. **战略意图** — 方向。明确愿景、长期目标、短期目标，回答"我们要去哪里"。
4. **创新焦点** — 杠杆。确定在哪些领域进行业务模式创新（而非游离于业务模式外的产品创新）。
5. **业务设计** — 核心输出。针对每个细分市场设计业务模式五要素（客户选择、价值主张、盈利模式、战略控制、业务范围）。

**右半（执行设计）：**
6. **关键任务** — 战略落地的具体行动和里程碑。
7. **正式组织** — 支撑关键任务的组织结构、流程、制度。
8. **人才** — 关键岗位和人才需求。
9. **氛围与文化** — 价值观和行为规范。

**贯穿始终：** 领导力与价值观。

核心逻辑：差距→洞察→意图→创新→设计（新地基）→任务→组织→人才→文化（新房子）→运营→新差距...循环往复。

## A1 — 书中的应用 (Past Application)

### 案例 1: 华为终端业务引入BLM
- **问题**: 2010年华为已很大，但战略解码执行效果不好，需要增强战略落地能力
- **方法论的使用**: 引入BLM（比之前的VDBD更大、更复杂、更强调领导力和执行力），通过差距分析发现终端与运营商业务的本质不同；通过市场洞察识别To C客户需求差异；重新设计终端的业务模式（客户选择、价值主张等）；配套关键任务、组织变革和人才布局
- **结论**: BLM的系统性帮助华为终端从"附属品"转变为独立战略业务
- **结果**: 终端业务成功，成为华为消费者BG的核心

### 案例 2: 华为无线业务的BLM实践
- **问题**: 无线业务需要持续抓住战略机会点（3G→4G→5G）
- **方法论的使用**: 用BLM进行年度战略规划循环：差距分析（与 Ericsson/Nokia 的市场份额差距）→ 市场洞察（5G技术趋势、客户需求变化）→ 战略意图（从跟随到领先）→ 创新焦点（从设备销售到解决方案+服务）→ 业务设计（专利组合+客户关系双轮驱动）→ 执行体系（研发投入、全球组织布局、人才储备）
- **结论**: BLM使无线业务形成了"战略规划-解码-执行-评估"的闭环
- **结果**: 无线成为华为的现金流牛，全球领先

### 案例 3: 某家电企业冰箱产品线的BLM应用（反例/诊断）
- **问题**: 冰箱产品线面临同质化竞争和跨行业颠覆（如盒马鲜生）
- **方法论的使用**: 通过BLM的市场洞察发现"客户买冰箱是为了储存食物并保鲜"，但"客户为什么要储存食物"才是根因——因为要上班没时间每天逛超市。进一步发现"盒马鲜生"提供了不依赖冰箱的替代方案。这促使业务团队重新审视客户选择、价值主张和竞争视野
- **结论**: BLM的市场洞察和业务设计帮助识别跨行业竞争者
- **结果**: （书中为分析案例，引导企业将盒马鲜生纳入竞争视野）

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 业务单元（产品线/事业部/区域）需要做年度或中长期战略规划时
2. 公司发现战略与执行脱节，需要一套框架将两者打通时
3. 新业务线孵化，需要从零设计"战略+执行"完整方案时
4. 战略复盘时，发现差距但找不到根因和改进路径时
5. 中高层管理者需要统一战略语言、提升战略思维能力时

### 语言信号 (用户的话里出现这些就应激活)

- "帮我们做一个战略规划"
- "战略和执行怎么对齐？"
- "BLM / 业务领先模型 / business leadership model"
- "业务设计怎么做？"
- "差距分析 / 市场洞察 / 战略意图 / 创新焦点"
- "strategic planning / strategy execution gap / business design"

### 与相邻 skill 的区分

- 与 `five-looks-market-insight` 的区别: 五看是BLM中"市场洞察"要素的展开，本 skill 覆盖完整的BLM框架
- 与 `business-model-five-elements` 的区别: 本 skill 包含业务设计但远不止于此，还包含差距分析、创新焦点和执行体系
- 与 `strategy-decoding-sp-bp` 的区别: 本 skill 负责"制定战略"，战略解码负责"将战略变成可执行的行动"
- 与 `dste-strategy-execution` 的区别: DSTE是流程管理体系，BLM是战略规划工具；DSTE用BLM作为其战略规划环节的方法

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **差距分析**
   - 完成标准: 清晰识别至少1个业绩差距和1个机会差距，量化差距程度
   - 步骤:
     a. 业绩差距：当前运营结果 vs 既定目标的差距
     b. 机会差距：当前业务 vs 未来战略意图可能达到的差距

2. **市场洞察输入**
   - 完成标准: 用"五看"框架产出市场洞察摘要（若用户已有洞察，直接引用；若无，引导完成）

3. **战略意图与创新焦点**
   - 完成标准: 明确3-5年长期目标、1年短期目标，以及1-2个创新焦点领域

4. **业务设计**
   - 完成标准: 针对每个关键细分市场，用五要素设计业务模式

5. **执行体系设计**
   - 完成标准: 产出关键任务清单、组织调整建议、人才需求、文化举措

6. **输出BLM战略蓝图**
   - 完成标准: 提供一页纸BLM蓝图，包含左右两半的核心结论和关键里程碑

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **公司总体战略**（愿景、使命、投资组合选择）— BLM设计初衷是业务战略规划，不是公司总体战略。虽然可以延伸使用，但分析和设计内容有显著区别
- **纯职能战略**（如仅做HR规划或IT规划）— 职能战略应支撑业务战略，BLM不适合单独用于职能层
- **无业务单元的抽象战略讨论** — BLM要求以"能够独立为特定市场提供产品/解决方案的最小经营单元"为基础
- **日常运营问题解决** — 业绩差距的根因若纯属执行问题，不需要重新走完整BLM流程

### 作者在书中警告的失败模式

- **把BLM当清单勾选**: 许多学员"画虎不成反类犬"，只填表格不理解要素间的逻辑关系。BLM的复杂度在于要素间的因果连接，而非要素本身
- **用线性思考分析战略问题**: 像鱼骨图、5why法、金字塔原理等线性方法不适合分析战略问题，因为战略问题往往涉及系统性的冲突（鱼和熊掌不可兼得）。需要用系统思考
- **业务模式频繁重构**: 小风小雨只需调整业务系统（执行侧），不要动不动拆房子改造地基（业务模式）。业务模式确定后至少坚持3-5年

### 作者的盲点 / 时代局限

- BLM源自IBM，华为2006年引入，框架偏传统B2B/硬件行业。对平台经济、开源生态、创作者经济等新型业务形态的适配性需自行调整
- 强调"领导力"为贯穿要素，但对分布式决策、DAO等去中心化组织形态解释力有限

### 容易混淆的邻近方法论

- 与SWOT/波特五力: 这些是分析工具，BLM是完整的战略制定与执行框架
- 与OKR: OKR是执行目标管理工具，BLM是战略生成框架；OKR应在BLM之后使用
