# 五看市场洞察法

## R — 原文 (Reading)

> 制定战略之前的市场洞察，只有高手才可以做出来。华为做市场洞察有一套方法论，叫做"五看"：看行业/趋势、看客户/市场、看竞争、看自己、看机会。
>
> — 华为战略管理实践, 第21章

> 关注价值转移，首先需要明白市场正在发生什么，以及这些改变对公司来说意味着什么。
>
> — 华为战略管理实践, 第21章

---

## I — 方法论骨架 (Interpretation)

"五看"是华为用于战略前市场洞察的系统方法论，按逻辑顺序扫描五个维度，将零散信息转化为可指导业务设计的结构化输入。

1. **看行业/趋势** — 识别价值转移方向、突破性技术和行业标杆。回答：市场正在发生什么？这些改变对公司意味着什么？
2. **看客户/市场** — 分析客户需求、客户选择和快速迭代能力。回答：谁是我们的目标客户？他们的真实需求是什么？我们是否选择了正确的切入点？
3. **看竞争** — 评估竞争对手的战略意图、产品优势、财务状况和市场覆盖。回答：我们和谁竞争？他们在干什么？
4. **看自己** — 用商业画布分析自身的商业模式、经营状况、运营能力和优劣势。回答：我们的能力边界在哪里？组织方向是否与战略一致？
5. **看机会** — 在细分市场、流程支撑和组织人才三个层面判断机会窗。回答：机会点在哪里？我们能否抓住？

五看不是并列的，而是层层递进：趋势定方向→客户定需求→竞争定差距→自己定边界→机会定行动。

## A1 — 书中的应用 (Past Application)

### 案例 1: 华为智能手机的战略洞察（2007年）
- **问题**: 2007年，华为需要判断终端业务的战略价值，当时终端被视为"低端配套"
- **方法论的使用**: 通过"看趋势"洞察到"未来可能人手一部智能手机"的价值转移信号；通过"看客户"识别出端-管-云三位一体的需求变化；通过"看自己"评估华为在通信技术领域的积累可迁移至终端
- **结论**: 终端不是附属品，而是战略控制点
- **结果**: 蓝军出具1页纸报告阻止出售终端业务，奠定华为手机辉煌

### 案例 2: 传音手机锁定非洲市场
- **问题**: 中国手机市场已是一片红海，新进入者如何找到生存空间？
- **方法论的使用**: "看客户"时发现非洲市场的独特性（深色皮肤拍照优化、多卡多待需求）；"看竞争"时发现主流厂商忽视非洲；"看自己"时发现具备低成本硬件和本地化能力
- **结论**: 非洲是机会窗，可建立绝对优势
- **结果**: 传音在非洲市场占有率达85%

### 案例 3: 深圳机柜上市公司的失败
- **问题**: 机柜需求下滑，公司开发机房和电源新产品但销售失败
- **方法论的使用**: 反例——公司没有做"看客户"和"看自己"的深入分析，误以为原有客户关系可支撑新产品销售
- **结论**: 采购机房的部门与采购柜子的部门不同，原有关系网络失效
- **结果**: 花半年重建关系，产品优势已丧失，陷入价格战

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 创业者要选择进入哪个赛道或细分市场时
2. 产品经理要判断某个需求是否值得投入资源时
3. 投资人要评估一个行业或项目的投资价值时
4. 企业高管要做年度战略规划或业务复盘时
5. 业务团队要分析为什么竞品增长而自己停滞时

### 语言信号 (用户的话里出现这些就应激活)

- "这个行业还有没有前途？"
- "我们要不要进入X市场？"
- "竞争对手在干什么？"
- "我们的优势和劣势是什么？"
- "机会在哪里？"
- "五看 / 市场洞察 / 战略洞察 / 行业分析 / 赛道选择"
- "market insight / strategic insight / industry analysis / competitive landscape"

### 与相邻 skill 的区分

- 与 `blm-strategic-planning` 的区别: 五看是BLM中"市场洞察"要素的展开，只负责输入信息的结构化收集，不负责完整的战略设计和业务模型输出
- 与 `business-model-five-elements` 的区别: 五看是"看"和"判断"，业务模式五要素是"设计"和"构建"
- 与 `strategic-control-point` 的区别: 五看识别机会和威胁，战略控制点评估的是竞争壁垒和利润保护能力

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **明确洞察目标**
   - 完成标准: 确定本次洞察要回答的核心问题（如"是否进入X市场"或"为什么Y业务下滑"）
   - 判停条件: 若用户只是闲聊行业八卦，无具体决策需求，则引导用户明确目标后再继续

2. **执行五看扫描**
   - 完成标准: 按顺序产出五个维度的结构化分析，每个维度至少包含2-3个关键发现
   - 步骤:
     a. 看行业/趋势：价值转移方向、突破性技术、行业标杆
     b. 看客户/市场：需求分析、客户选择、快速迭代能力
     c. 看竞争：竞争对手评估（战略意图、产品、财务、覆盖）
     d. 看自己：商业模式、经营状况、运营能力、优劣势
     e. 看机会：细分市场判断、流程支撑、组织人才

3. **提炼战略启示**
   - 完成标准: 将五看发现归纳为3-5条对决策有直接影响的结论，每条结论附证据

4. **输出洞察报告**
   - 完成标准: 提供一份简洁的结构化报告（≤1页），包含核心结论、关键风险、下一步建议

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯数据查询（如"某家公司去年营收多少"）— 用搜索引擎即可
- 已明确具体执行步骤后的操作细节（如"这个营销文案怎么写"）
- 不需要战略判断的日常运营问题
- 个人职业选择但缺乏任何行业背景信息时 — 先引导用户补充信息

### 作者在书中警告的失败模式

- **机会主义式洞察**：一线销售以"有没有生意"为目的的拜访，会导致不断开发新客户却错过产品技术迭代窗口
- **看趋势不看客户**：报告洋洋洒洒写宏观趋势和竞争对手，但对客户最直接的需求分析只停留在"外观要好看""操作要简单"的肤浅层面
- **只看当下不看远期**："竞争三年以后的事，现在开始已经晚了"

### 作者的盲点 / 时代局限

- 华为每年花8个月做客户洞察，这个周期在AI/互联网等快速迭代行业可能过长，需要结合敏捷迭代压缩
- 书中案例偏硬件/通信行业，对平台经济、SaaS、开源生态的洞察方法覆盖不足

### 容易混淆的邻近方法论

- 与波特五力模型：五力是看行业的工具之一，五看是更完整的战略洞察框架
- 与SWOT分析：SWOT是看自己的简化版，五看包含SWOT但范围更广、逻辑更递进
