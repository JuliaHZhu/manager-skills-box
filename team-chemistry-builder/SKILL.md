# team-chemistry-builder

## Description
当用户需要搭建管理团队、配置正副职、解决"搭班子"问题时激活。适用于高管团队组建、部门正副职搭配、创业合伙人选择、关键岗位班子配置。不适用于：纯执行层人员招聘、已稳定运行无需调整的团队日常管理。

Trigger: 搭班子 / 正副职搭配 / 团队配置 / 领导班子 / 合伙人选择 / 团队搭配 / 优势互补 / 价值趋同 / 狼和狈 / 班子建设 / team chemistry

## I (Interpretation)
班子搭配不是"选最优秀的人"，而是"选最互补的人"。核心方法论：

1. **八字方针**: 价值趋同（方向一致）+ 优势互补（能力互补）
2. **SHL班次模型**: 横轴=领导力（影响他人），纵轴=管理能力（计划组织）。四个象限决定角色定位：
   - 高领导+高管理 = 规范企业领导者
   - 高领导+低管理 = 创业型企业家（需配COO/运营官互补）
   - 低领导+高管理 = 成熟部门领导/首席运营官
   - 低领导+低管理 = 专家（技术/营销/策划带头人，不做管理者）
3. **正副职分工模型**: 正职=狼（进攻、突破、战略、牺牲精神）；副职=狈（管理、精细、执行、守家护院）
4. **冲锋型人才使用法则**: 攻山头能力强但守山头弱的人，用于开疆拓土，限时（如一年），成功后换人守。

## E (Execution)

### Step 1: 诊断现有班子/候选人的SHL定位
对每个人评估两个维度（1-5分）：
- **领导力**（影响他人、感召力、战略方向感）
- **管理能力**（计划、组织、协调、控制、制度建设）

将每个人放入SHL矩阵，识别角色缺口。

### Step 2: 应用八字方针筛选与搭配
- **价值趋同**: 确认候选人对企业核心价值观、战略方向、底层逻辑是否认同。方法：追问其对关键决策的看法，观察其过往行为是否与价值观一致。
- **优势互补**: 根据SHL矩阵缺口，寻找互补者。规则：
  - 创业阶段/新团队：优先选高领导力者当头，配高管理能力者为副
  - 成熟部门/守成阶段：可用高管理能力者为正，高领导力者为副或顾问
  - 绝不用两个同一象限的人搭班子（尤其是两个高领导低管理型）

### Step 3: 正副职职责划分与动态管理
- 正职职责：定战略方向、抓主要矛盾、撕开城墙口子、敢于胜利、承担失败责任
- 副职职责：精细化管理、落实组织意图、守稳已占领地区、提升效率利润
- **冲锋型人才**: 明确其任务为"攻山头"，设定时间边界（如6-12个月），成功后轮换，不长期守城。

## B (Boundary)
- 不适用于：基层执行团队（无需正副职战略分工）、已形成强默契且运转良好的班子（强行套用可能破坏平衡）
- 风险：SHL评估依赖主观判断，建议结合360度评估或关键事件验证，避免"贴标签"偏差
- 局限：模型源自华为强执行文化，在创意型、扁平化组织（如游戏工作室、设计工作室）中需调整权重
