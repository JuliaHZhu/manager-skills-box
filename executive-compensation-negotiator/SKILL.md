# executive-compensation-negotiator

高管猎聘与薪酬谈判：通过5C模型筛选「合适而非仅优秀」的人才，以3P1M原则设计成本可承受、内部公平、外部竞争力的薪酬方案，并用LEADER六维模型完成谈钱不伤感情的闭环。

## 触发条件

当用户需要高管招聘、薪酬谈判、offer设计、人才地图、5C模型、3P1M、LEADER模型、挖人、谈薪不伤感情时激活。

**关键词**：高管招聘 / 薪酬谈判 / offer设计 / 人才地图 / 5C / 3P1M / LEADER / 挖人 / 猎头 / 谈薪 / 高端人才 / 薪酬包

## 使用说明

### 第一阶段：选人 — 5C人才匹配模型

**核心理念**："优秀的人不一定合适，合适的人必将优秀"（第15章，吕昕蔚）。

**5C维度**：
1. **Competence（胜任力）**：经验、知识、技能、资源、能力。使用面试工具和方法精准评估。
2. **Career goal（职业目标）**：候选人的职业目标与公司发展规划、岗位晋升通道的重叠度。重叠度越高，长期共同发展几率越大。
3. **Compensation & Benefits（薪酬福利）**：企业的支付能力。承认现实："人才，是不存在物美价廉的。不要有捡漏的侥幸心理，招人一定是'才财对等'。"
4. **Culture Fit（文化价值观）**：候选人对企业价值观、使命、愿景的认同度。认同度越高，融入成本越低，团队协同越高效。
5. **Confident（事业认同及信心）**：候选人对我们要做的事情、对这个团队是否充满信心和动力？

**华为案例**（第15章）：2012年华为手机想从苹果挖工程师，年薪25万-100万美元，远超当时华为手机的支付能力，最终一个都没挖到。但转而从三星、摩托罗拉、诺基亚、HTC、Sony挖来认可华为文化、相信华为能做成高端智能手机的人，入职后都做出超乎预期的成绩。

**STOP检查点**：
- [ ] 是否在用5C全面评估，而非仅看简历光鲜程度？
- [ ] 是否考虑了企业当前支付能力与候选人期望的差距？
- [ ] 候选人是否对公司和岗位有真实的信心，而非仅仅为了钱？

### 第二阶段：定价 — 3P1M薪酬方案设计

**Position（岗位）**：
- 岗位价值评估及自我认知：以岗定级，以级定薪
- **钱给不到的4招**（第15章）：
  1. **深度挖掘**：找目标公司低1-2个层级的人才；向上下游延展目标企业；围绕业务场景反推人才素质模型（如无人机找消费电子营销人才）。
  2. **提高预算**：固定薪酬给不到 → 设绩效目标奖金；现金给不到 → 给股票期权（做好价值分析、授予/生效/行权规则）。
  3. **拆分职位**：将高端岗位目标拆分到2-3个岗位，先招最紧急的，观察新员工是否具备全盘潜力。
  4. **重新定位**：输出人才地图，与业务部门共同探讨岗位诉求是否合理，是否应降低期望。
- **内部平衡被打破怎么办**：对于绩效好、潜力强的员工，尽快加薪到比新人起薪更高；其他依次递减；末位被倒挂主动离开未必是坏事。

**Person（个人）**：
- **候选人价值评估**：显性价值（业绩增长）+ 隐性价值（价值观、思维方式、眼界格局的提升）。
- **求职动机痛点挖掘**：晋升慢、管理不规范、公司经营问题、内部人际关系等。痛点越多越痛，谈薪余地越大。
- **薪酬现状分析**：问清总包与具体构成。若候选人持有大量公司股票，分析财报预判股价走势，掌握谈判主动权。
- **现任雇主四维洞察**：
  1. 发展势头（营收、人效、估值曲线）
  2. 薪酬福利（比较优势与不足）
  3. 晋升机制（瓶颈层级）
  4. 人员流动（简历刷新率、行业传闻）
- **群体共性研究**：不同年龄段候选人关注点不同（如1990-94后更看重发展空间和周围都是NB的人）。

**Performance（绩效）**：
- 基于绩效的整体薪酬策略：华为底薪（固定现金）并不算高，高收入基于高绩效高产出。
- 影响薪酬接受度的三因素：学习发展（双通道/导师/轮岗）、公司地位（行业前景/雇主品牌）、组织氛围（文化/授权/弹性工作）。

**Market（市场）**：
- 关注招人时的竞争对手薪酬，而非整体市场平均。
- 建立头部企业职位职级对照表，定期刷新。
- 预测人才稀缺度，提前培养潜力人才、保留关键人才。

**STOP检查点**：
- [ ] 是否确定了薪酬总包上下限？
- [ ] 是否设计了3-4套方案（不同现金/股权/奖金组合）？
- [ ] HR是否在底线和上限之间有决策权？
- [ ] 谈崩了是否有Plan B？

### 第三阶段：谈判 — LEADER六维模型

**L — Leader（优秀的人才吸引更优秀的人）**
- 面试官应由最优秀的专家和领导者组成
- 华为干部选拔四标准：核心价值观是基础；品德与作风是资格底线；绩效是必要条件和分水岭；能力是持续取得绩效的关键成功要素
- 宁向东解读好领导七标准：诚实正直、品行端正、精神饱满、努力无憾、坚韧不拔、关心下属、全力保护下属

**E — Experience（良好的面试体验）**
- 谷歌4E标准：Efficient（效率高）、Experience（体验好）、Effective（高效）、Equitable（公平公正）

**A — Assurance（确定性和安全感）**
- 企业的文化价值观和管理机制（案例：从微软来的人才在华为的发展状况）
- 企业所处产业是上升还是收缩，企业在产业竞争中处于什么位置（用PEST模型调研）
- 成长型企业先努力强大自我，公司强大了就能吸引更优秀的人才

**D — Dream（拥有同样伟大愿景的命运共同体）**
- 企业家的胸襟、智慧、理想决定能吸引什么人
- 不仅在于说了什么，更在于怎么做的
- 传递使命愿景到人才内心最深处，引发共鸣和认同

**E — Employer Brand（良好的雇主品牌）**
- 雇主品牌不是宣传和包装，而是如何对待员工
- 员工的工作感知才是最好的雇主品牌
- 研究EVP（Employee Value Proposition）

**R — Risk Management（风险管理）**
- 认清现实：不管多努力，肯定还有谈不下来的候选人
- Plan B立刻补位；没有备选则拿出人才地图和下一步工作方案
- 尽最大的努力，做最坏的打算

**STOP检查点**：
- [ ] 面试官是否足够优秀，能让候选人有"被优秀的人面试"的荣誉感？
- [ ] 是否传递了足够的职业安全感（产业位置+文化案例）？
- [ ] 是否有清晰的Plan B和人才地图？

## Anti-Example Blacklist

❌ **不要有捡漏心理** — "人才，是不存在物美价廉的。"才财不对等迟早会崩。

❌ **不要只谈钱** — 薪酬谈判不是讨价还价，是全方位吸引。"最好的薪酬谈判，不是谈判而是吸引。"

❌ **不要让薪酬谈判从面试结束后才开始** — 准备从面试之前就开始了，包括痛点挖掘、雇主洞察、群体研究。

❌ **不要忽视隐性价值** — 除了业绩，候选人带来的思维方式、眼界格局提升也是价值，但你对人才价值的评估要正确。

❌ **不要在谈崩后没有备份** — 没有Plan B的谈判是赌博。
