# bonus-package-architect

## Description
当用户需要设计企业奖金体系、解决"个人奖金发了很多但公司业绩没完成"的困境、或讨论"怎么让奖金驱动组织合力"时激活。适用于中大型企业的奖金包设计、销售/研发/职能多体系奖金对齐、新业务无利润期的激励、公司级战略项目悬赏。不适用于：初创期无稳定业务数据的企业、纯个人提成制 already 足够的小销售团队、无法核算收入/利润/回款的非营利组织。

Trigger: 奖金包 / 奖金设计 / 获取分享 / 组织奖金 / 奖金层级 / 悬赏制 / 战略性奖金 / 奖金池 / 激励合力 / 利出一孔 / bonus design / gain-sharing

> —— Ch12

## I (Interpretation)
奖金设计的核心矛盾：个人激励 vs 组织合力。四层级奖金包通过"生成-兑换-调节"机制解决这一矛盾。

**四层级架构**:
1. **公司层**: 总奖金包 = ∑各业务BG奖金包（按收入、利润、回款加权生成，不同BG权重不同）
2. **体系层**: 研发/销售/职能/供应链等体系按固定比例切分（保证体系间均衡，防止撕裂）
3. **组织层**: 部门/区域/代表处按自身业绩生成奖金，与体系层"兑换"对齐，上级有10%-30%调节权
4. **个人层**: 主管与员工采用不同分配逻辑（主管与组织业绩强挂钩，员工按贡献分配）

**两种奖金包类型**:
- **经营性奖金包**: 与短期业绩挂钩，多劳多得，适用成熟/成长业务
- **战略性奖金包**: 悬赏制，适用新业务、新技术、公司级山头项目、变革项目、事后突出贡献奖

**关键机制**:
- **生成**: 部门奖金 = f(收入权重, 利润权重, 回款权重)，按业务成熟度调整权重
- **兑换**: 部门生成奖金总和 ≠ 体系奖金包时，同比例缩放
- **调节**: 上级保留10%-30%调节权，处理结构性问题（如印度代表处因政治原因无法交付）

## A1 (Past Application)
- **华为三BG差异化生成**: 运营商BG（成熟）利润权重高；企业BG（成长）收入利润对等；消费者BG收入利润为主，回款不计入
- **印度代表处调节**: 2017年中印对峙，印度代表处签单无法交付，按纯获取分享制奖金会很低，上级用调节机制保留其团队稳定性
- **2019年20亿突击奖金**: 美国断供后，对器件替代做出突出贡献的人员发放事后悬赏奖，属于战略性奖金包
- **云业务早期激励**: 云业务投入期无利润，用战略性奖金包激励几千人团队，而非经营性奖金

## E (Execution)

### Step 1: 诊断现有奖金结构
检查三个层级是否齐全：
- [ ] 是否有公司层总奖金包约束？
- [ ] 是否有体系/部门层奖金包？
- [ ] 个人奖金是否与组织奖金脱钩？

常见问题：
- 只有个人层 → 利不出一孔，个人奖金与公司业绩无关
- 只有个人+部门层 → 部门各自为政，撕裂组织
- 部门奖金与人数强挂钩 → 无减员增效动力

### Step 2: 设计四层级奖金包

**公司层**: 确定总奖金包生成公式
```
总奖金包 = ∑(各业务单元)
每个业务单元 = α×收入 + β×利润 + γ×回款
```
- 成熟业务: β > α > γ（利润优先）
- 成长业务: α ≈ β > γ（规模与利润并重）
- 拓展业务: 可单独用战略性奖金包，不适用此公式

**体系层**: 按固定比例切分总奖金包
- 目的：防止销售/研发/职能奖金差距过大导致组织撕裂
- 参考：根据战略阶段调整（产品驱动期研发略高，市场扩张期销售略高）

**组织层**: 部门奖金生成 + 兑换 + 调节
1. 每个部门按自身业绩生成奖金（同公司层公式，权重可按区域/产品差异化）
2. 兑换：部门生成总和 vs 体系分配额，同比例缩放
3. 调节：上级保留10%-30%调节权，用于：战略投入期保护、突发事件、结构性调整

**个人层**: 
- 主管：与组织奖金包强挂钩（如组织奖金的X%归主管分配）
- 员工：按个人贡献系数分配剩余部分

### Step 3: 设置战略性奖金包（悬赏制）
识别需要悬赏制的场景：
- 新业务/新产品爬坡期（如云业务早期）
- 核心技术攻关（如海思芯片、2012实验室）
- 公司级山头项目（突破新市场/大客户）
- 重大变革项目（IPD/ISC实施）
- 事后突出贡献（如2019年断供应急替代）

操作：
- 年初形成战略清单，明确悬赏项目和奖金预算
- 事前悬赏：明确目标与对应奖金
- 事后悬赏：对未预料到的重大贡献追加奖励

## B (Boundary)
- 不适用于：无法量化收入/利润/回款的岗位（如纯行政、基础研究）、无稳定财务数据的初创企业
- 风险：公式设计不当可能导致短期行为（如只追求收入忽视利润），需配套质量/合规指标
- 复杂性：四层级需要较强的财务和HRIS能力支撑，200人以下企业可简化为公司-个人两层
- 注意：华为奖金远大于工资（奖金600亿 vs 工资包），若企业工资占比高，此模型需调整
