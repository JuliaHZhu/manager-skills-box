## Core Methodology: The Training-Battle Closed Loop

华为训战结合的核心理念：**“用最优秀的人培养更优秀的人，训战结合、以赛代练”**。

### The 4-Phase Cycle

```
选拔 → 训战营赋能 → 上战场实战 → 回炉再充电 → (循环)
Select → Bootcamp → Combat → Recharge → (loop)
```

| Phase | Key Action | Success Criteria |
|---|---|---|
| **选拔** | Business unit nominates high-potentials; not voluntary enrollment | Candidate has proven track record + upward mobility |
| **训战营** | Intensive camp with real cases, simulated combat, and actual project shadows | Output: battle-ready capability, not certificates |
| **上战场** | Deploy to frontline with clear mission; success and failure both acceptable | Performance in real combat determines advancement |
| **回炉** | Top performers return as camp leaders/teachers; others get targeted recharge | Knowledge crystallizes through teaching; loop renews |

### Design Principles

1. **选拔制，非培养制**
   - 不是“谁来都行”，而是业务部门选拔出来的高潜人才才能进入训战体系
   - 能进入训战营本身就是一种荣誉和激励

2. **教战一致**
   - 训练场景必须与真实战场一致：真实案例、真实客户、真实压力
   - 案例必须从实际业务中来，“关起门来编的案例，打起仗来绝不会用到”

3. **以优秀培养更优秀**
   - 讲师必须是当前业务中最优秀的一线专家
   - 强调兼职讲师循环：人在人生最优秀的那段输出经验，然后回去打仗

4. **失败宽容，实战为王**
   - 训战过程中的项目成败不重要，重要的是能力是否形成
   - 表现好的逐步参与更大的项目，形成正向筛选

## Heavy Brigade (重装旅) Operation Model

重装旅是华为训战结合的典型组织形态——**培养“会开航母的人”来教开航母**。

### Organizational Design

| Element | Design Choice |
|---|---|
| **人员来源** | 从全球业务一线选拔的优秀解决方案专家 |
| **训练内容** | 真实项目案例 + 跨领域协同 + 高管引导 |
| **训练方式** | 案例研讨 + 实战影子项目 + BigQ辩论 + 论文答辩 |
| **输出去向** | 派遣到战略要地、新市场、关键客户项目 |
| **回流机制** | 战功卓著者回营担任教官，形成师资循环 |

### Camp Curriculum Structure

1. **文化奠基**：管理纲要研讨（业务/人力资源/财经三大纲要）
2. **案例浸泡**：全部案例来自华为和社会真实案例，拒绝本本主义
3. **对抗演练**：小组研讨 → 案例演讲 → 大辩论 → 高层引导
4. **实战影子**：跟随真实项目，在教官指导下承担实际角色
5. **输出检验**：撰写真实案例 + 论文答辩 + 内部公示接受全员监督

## Implementation Checklist

- [ ] 明确训战营的战略定位（支撑什么业务目标？）
- [ ] 建立选拔机制（谁提名、什么标准、多少人）
- [ ] 设计“教战一致”的课程体系（真实案例库建设）
- [ ] 组建兼职教官队伍（最优秀的业务专家轮值）
- [ ] 建立战场对接机制（训后如何上项目、谁负责安置）
- [ ] 设计回流与再充电机制（优秀学员回营任教）
- [ ] 建立效果评估（不是考试分数，而是实战表现转化率）

## Anti-Patterns

| Anti-Pattern | Why It Fails |
|---|---|
| 把训战营做成普通培训班 | 失去实战压力，学员没有紧迫感 |
| 用专职讲师讲业务课 | 脱离一线，案例过时，学员不信服 |
| 只训不战、只战不训 | 打断闭环，能力无法固化 |
| 追求全员覆盖而非拔尖 | 资源分散，无法形成“种子选手”效应 |
| 考核用笔试而非实战成果 | 导向错误，催生应试行为 |

## Example Interaction

**User**: 我们销售团队新人成长太慢，培训完半年还上不了手，有什么办法？

**Skill Response**:
> 你描述的是典型的“训战分离”问题。建议按以下步骤改造：
>
> 1. **停止大规模通识培训** — 改为选拔制：每个区域提名前20%高潜销售进入“训战营”
> 2. **案例库建设** — 收集你们过去3年真实签单/丢单案例，作为唯一教材
> 3. **教官选拔** — 让本年度TOP 3销售担任兼职教官，脱产2周带营
> 4. **实战影子** — 训战营第3周开始，学员以“影子销售”身份跟随教官参与真实客户拜访
> 5. **战场验收** — 结业标准不是考试，而是独立拿下1个小单
> 6. **回流机制** — 结业后6个月，业绩前30%回营担任下一期助教
>
> 关键指标：从“培训结束”到“独立成单”的时间缩短到多少？建议目标：3个月内。
