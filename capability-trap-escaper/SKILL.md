# capability-trap-escaper — 突破企业能力陷阱

## R (Reading) — 原文引用

> "能力是企业成长与发展的核心基础，但如果该企业过度地局限于该项能力，就会陷入学习的困境，过于强调现有能力的应用而忽略了对新知识的探索。"（Ch2.1）

> "蓝军之难在于运用异质思维，突破企业原有的能力陷阱，是一种根本性、革命性的自我否定（Unlearning）。"（Ch2.2）

> "我们不主动打破自己的优势，别人早晚也会来打破。"（Ch12.1）

> "企业的一项能力在帮助企业具备竞争力的同时，如果该企业过度地局限于该项能力，就会陷入学习的困境……在温水煮青蛙中丧失了对环境变化的敏感。"（Ch19）

> "奇正之变，不可胜穷也。奇正相生，如环之无端。"（Ch2.1，引孙子兵法）

## I (Interpretation) — 方法论骨架

能力陷阱（Capability Trap / Competency Trap）是组织学中的核心悖论：**使你成功的因素，往往也是导致你失败的原因**。

**陷阱的形成机制**：
1. **成功 → 强化** → 资源向成功经验倾斜
2. **强化 → 路径依赖** → 组织能力和文化围绕成功路径优化
3. **路径依赖 → 盲区** → 对环境变化丧失敏感
4. **盲区 → 颠覆** → 新技术/新玩家从边缘崛起，主业务被降维打击

**华为的解法：奇正相生（Ambidexterity）**
- **红军（正）**：开采（Exploitation）——优化现有业务，追求效率和规模
- **蓝军（奇）**：探索（Exploration）——突破现有边界，追求创新和颠覆
- **转化**：蓝军的颠覆性创新验证成功后"转正"为红军，形成生生不息的循环

**关键洞察**：
- 不是"放弃现有能力"，而是"不让自己被现有能力定义"
- 蓝军不是红军的敌人，而是红军未来的自己

## A1 (Past Application) — 书中案例

**华为终端业务：从ODM到自有品牌**：
- 原有能力：为运营商定制设备（B2B）
- 能力陷阱：如果继续只做ODM，品牌价值和利润率永远受限
- 突破：创立荣耀品牌（蓝军），独立运作，互联网模式
- 结果：荣耀+华为双品牌，终端业务占华为总营收近50%

**摩托罗拉的沉没**：
- 原有能力：模拟通信技术、硬件设计
- 能力陷阱：过度依赖模拟技术，忽视数字技术颠覆
- 结果：从通信巨头到被谷歌收购

**柯达的衰落**：
- 原有能力：胶卷技术、渠道网络
- 能力陷阱：发明了数码相机但担心冲击胶卷业务，未能全力转型
- 结果：破产

**微软的Windows Phone失败**：
- 原有能力：PC操作系统付费模式
- 能力陷阱：将Windows的赢利模式复制到移动OS，制造商不愿付费
- 错失：搜索、社交、移动、电商等大风口

**百事的健康转型**：
- 原有能力：碳酸饮料（与可口可乐竞争）
- 能力陷阱：消费者转向健康，传统产品背道而驰
- 突破：蓝军部门在新兴国家测试健康新品，众包推出新薯片

## A2 (Future Trigger) — 何时调用

- 核心业务增长放缓，但组织仍在加倍投入"老方法"
- 看到行业颠覆信号（新技术、新玩家、新消费习惯），但内部讨论总被"我们以前成功过"堵回去
- 想开辟第二曲线，但新业务总被老业务的KPI和文化同化
- 个人职业上，感觉"越资深越容易被定义"，想转型但担心放弃积累
- 投资一个成熟行业，担心行业龙头被颠覆

## E (Execution) — 可执行步骤

### Step 1: 诊断是否已陷入能力陷阱

**自评问卷**（5题中≥3题"是"即为高风险）：
1. 过去3年，公司的核心战略关键词有变化吗？（没有 = 陷阱风险）
2. 新员工提出的"疯狂想法"，通常被怎么对待？（立即否定 = 陷阱风险）
3. 公司的预算分配，新业务占比超过10%吗？（没有 = 陷阱风险）
4. 如果公司最核心的技术/产品明天被禁用了，有替代方案吗？（没有 = 陷阱风险）
5. 高管团队有多少人是从"非核心业务"晋升上来的？（没有 = 陷阱风险）

### Step 2: 识别"优势即枷锁"

**追问清单**：
- 我们最引以为豪的能力是什么？
- 这个能力在什么条件下会从资产变成负债？
- 我们的竞争对手最希望我们在哪个方向上"执迷不悟"？
- 如果我们是颠覆者，会从哪个角度攻击自己？

### Step 3: 设计"奇正相生"结构

**组织架构选项**：

| 模式 | 描述 | 适用 |
|------|------|------|
| **双部门制** | 红军部门（现有业务）+ 蓝军部门（新业务），独立预算、独立文化 | 大企业（>1000人） |
| **体外创新** | 新品牌/新公司独立运作，物理隔离 | 中型企业，品牌转型 |
| **轮岗探索** | 核心人才定期轮岗到边缘业务 | 资源有限但人才密集 |
| **生态投资** | 通过投资/并购获取新能力，保持被投企业独立 | 资本充裕的企业 |

**关键设计原则**：
- **物理隔离**：蓝军不能和红军在同一栋办公楼、同一套KPI体系下
- **资源非对称**：蓝军需要"小而精"，不是"小而全"
- **时间盒**：给蓝军设定明确的探索期限（如2年），到期必须"转正"或"关停"
- **允许失败**：蓝军的考核指标是"学习"而非"收入"

### Step 4: 推动"Unlearning"（反学习）

**什么是Unlearning**：
- 不是"学习新知识"，而是"主动放下旧假设"
- 例如：从"软件必须卖license"到"软件可以订阅制"

**操作方法**：
1. **反向导师**：请年轻人/新员工给高管上课（教他们用抖音、玩新游戏）
2. **边界体验**：让核心团队到完全陌生的行业/市场考察一周
3. **假设清单**：定期列出"我们认为理所当然的事情"，逐条质疑
4. **模拟颠覆**：让内部团队扮演"颠覆者"，设计攻击本公司现有业务的方案

### Step 5: 管理"红蓝转换"

**转换信号**（蓝军该"转正"的迹象）：
- 边缘业务连续两个季度增长超过主业务
- 外部客户主动询问边缘业务的产品
- 边缘业务团队开始抱怨"被总部限制"

**转换风险**：
- 过早转正：边缘业务还未验证，被主业务KPI压垮
- 过晚转正：边缘业务人才流失，被竞争对手抢先

**转换机制**：
- 设定明确的里程碑（用户数、收入、利润率）
- 转换时保留蓝军的独立文化（不能完全同化）
- 原蓝军 leader 晋升为新业务线的红军司令

## B (Boundary) — 何时不适用

1. **初创期**：尚未形成任何核心能力，不存在"陷阱"，需要专注打磨PMF
2. **资源极度受限**：奇正相生需要双份资源，如果一份都养不活，不要分散
3. **需要极致专注的阶段**：如技术攻坚期、上市冲刺期，不宜引入内部冲突
4. **已被验证的衰退行业**：如果行业整体衰退已成定局，不是"突破陷阱"而是"退出"
5. **个人尚无积累**：职业早期的"能力陷阱"是伪命题——你需要先有能力
