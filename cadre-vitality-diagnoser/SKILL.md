# cadre-vitality-diagnoser

## When to Activate

- 用户提到"组织内卷"、"干部活力"、"使命感"、"责任感"
- 企业增长停滞，但找不到明确的外部原因
- 中高层干部安于现状、不敢挑战新目标
- 干部推诿责任、明哲保身、拉帮结派
- 组织变革推不动，怀疑是"人"的问题
- 需要对干部队伍进行系统性体检

## Core Philosophy

> "企业最大的危机，不是来自外部环境，也不是来自竞争对手，而是来自内部——首先是干部。"

组织活力衰减通常表现为三个层面：
1. **使命感衰竭**：干部缺乏理想和激情，组织失去方向感
2. **责任感缺失**：干部不担责、不作为，组织失去执行力
3. **能力建设滞后**：干部不学习、能力老化，组织失去竞争力

本技能同时覆盖**组织层面**的内卷症状（Ch26）和**干部层面**的活力指标（Ch41），形成双向诊断。

## Diagnostic Layer 1: 组织内卷十大表现（Organizational Involution）

当组织不但没有激发活力，反而在泯灭活力时，通常呈现以下十大症状：

### 1. 目标定得太低，依靠单兵作战
- 组织能力弱，本质是因为发展目标不够有挑战
- 目标低→无需重构能力→靠个人而非组织运作→关系绩效无法产生

### 2. 重节约轻投入
- 强调省钱而非投入，试错成本被砍掉
- 不见兔子不撒鹰→能力起来时机会已被抢走

### 3. 业务和组织变革被人的能力制约
- 正确逻辑：变革牵引能力提升，而非能力制约变革
- 漫无边际在家练能力=花冤枉钱，能力必须在真实业务场景中塑造

### 4. 营造虚假的安全感
- 怕员工走，靠哄、靠睁一只眼闭一只眼
- 真正安全感来自：把业务单元建成独立经营单元，让员工对经营结果产生内生不安全感

### 5. 贪图便宜，丧失竞争力
- 集成外部平庸分工→核心能力起不来→客户体验下降
- 尤其在客户界面上不能省钱

### 6. 思想不通，力量分散
- 1000个人有2000个想法，无法形成合力
- 思想高地不去占领，就被乱七八糟的东西占领
- 需要反复做思想政治工作，形成场域，打击无共性的个性

### 7. 错误的个人行为（个人英雄主义）
- 大项目烂在自己手里不愿分享
- 出了问题存侥幸，不让高层提前介入

### 8. 优先级次序混乱
- 利益格局：先保证员工个人利益，再组织利益；但组织目标优先于两者
- 能干的人得不到好处，机制就是失败的

### 9. 眼界封闭
- 每个部门守着自己的一亩三分地，怕被流程集成
- 部门目标必须服从流程目标

### 10. 直接派活，不做机制建设
- 管理者直接派任务，但没有组织能力配套
- 应先思考机制建设、组织能力建设，再思考个人如何去做

**诊断方法**：让高管团队对这10条逐一打分（1-5分），得分最低的3条即为当前组织内卷的核心病灶。

## Diagnostic Layer 2: 干部使命感缺失十大信号

> "干部缺乏使命感是企业最大的危机。"

| 序号 | 信号 | 典型表现 |
|---|---|---|
| 1 | 无理想追求，价值迷茫 | 思考"我是谁、为什么奋斗"后找不到答案，开始求神拜佛 |
| 2 | 事业心衰竭，工作激情衰竭 | 中层"腰"不行，组织"拉稀"；被动工作，不主动想办法 |
| 3 | 安于现状，只图安逸舒适 | 当甩手掌柜，享受生活多于事业 |
| 4 | 缺乏激情，不敢挑战新目标 | 守成而不开拓新业务，希望目标越低越好 |
| 5 | 占着位子、拿着票子、混着日子 | 搭便车，不创造价值，还相互制造工作 |
| 6 | 居功自傲，放纵不自律 | 死守一亩三分地，拉山头，无视组织规则 |
| 7 | 不学习，没有自我批判精神 | 自称"大师"，傲视群雄，失去学习动力 |
| 8 | 个人利益大于组织利益，拉帮结伙 | 矛盾时取舍个人，形成小圈子 |
| 9 | 牢骚遍地，个个是负能量场 | 天天抱怨，成为负能量源 |
| 10 | 漠视外部环境变化 | 自我感觉太好，不把市场放在眼里 |

## Diagnostic Layer 3: 干部责任感缺失十大信号

> "干部责任感的缺失是企业最大的威胁。"

| 序号 | 信号 | 典型表现 |
|---|---|---|
| 1 | 对组织价值观不遵守、不承诺、不践行 | 说一套做一套 |
| 2 | 不拍板、不决策、怕出事、缺担当 | 遇到难题绕开走 |
| 3 | 不敢开拓创新、不敢承担变革风险 | 只愿意做确定性的事 |
| 4 | 不能直面矛盾和问题 | 粉饰问题，避开矛盾 |
| 5 | 遇到分歧不旗帜鲜明，和稀泥当老好人 | 怕得罪人 |
| 6 | 对客户夸海口、欺骗忽悠 | 不以客户为中心 |
| 7 | 不承担人力资源管理责任 | 不关心人、不培养人 |
| 8 | 企业危难关头临阵脱逃 | 关键时刻不见人 |
| 9 | 远离一线，官僚主义、形式主义 | 高高在上 |
| 10 | 不以组织目标为己任，不作贡献 | 只做对自己有利的事 |

## Diagnostic Layer 4: 干部能力建设七大要求

> "责任是价值创造的前提，能力是责任担当的基石。"

| 能力维度 | 核心要求 | 关键行为 |
|---|---|---|
| **1. 洞察力** | 敏锐洞察商业机遇、客户需求、行业趋势 | 定期市场调研，与客户高层对话 |
| **2. 决断力** | 关键时刻敢于拍板，抓住机遇 | 在信息不完备时敢于决策 |
| **3. 文化影响力** | 用愿景和价值观凝聚组织 | 在困难时发出"生命的微光"，引领队伍 |
| **4. 跨界竞合力** | 跳出原领域，既竞争又合作 | 与产业链上下游建立共赢关系 |
| **5. 跨部门协同力** | 打破部门墙，推动项目协同 | 主动牵头跨部门项目，不求全责在自己 |
| **6. 真实领导力** | 言行一致，阳光决策，灰度驾驭 | 机制制度放在阳光下，自我约束 |
| **7. 跨文化领导力** | 理解多元文化，融合全球人才 | 尊重差异，建立全球信任 |

## Practical Playbook

### Step 1: 组织层面扫描（内卷十项）

组织高管独立打分（1-5分），取平均分：
- 得分≤2分的项：核心病灶，需要立即干预
- 得分2-3分的项：预警信号，需要制定改进计划
- 得分≥4分的项：组织优势，继续保持

### Step 2: 干部层面扫描（使命感+责任感+能力）

对关键干部群体进行360度评估或自评：
- **使命感缺失**：10条中命中≥3条 → 需要思想重塑或岗位调整
- **责任感缺失**：10条中命中≥3条 → 需要问责或降级
- **能力短板**：7项中得分≤3分的项 → 进入针对性培养计划

### Step 3: 匹配干预策略

| 诊断结果 | 干预策略 |
|---|---|
| 使命感问题为主 | 愿景重塑、战略共识工作坊、高层以身作则 |
| 责任感问题为主 | 明确权责、建立问责机制、能上能下 |
| 能力问题为主 | 训战结合、轮岗锻炼、导师辅导 |
| 组织内卷为主 | 调高原目标、重构组织分工、打破部门墙 |
| 复合型问题 | 系统性变革：调目标+换干部+改机制+强文化 |

### Step 4: 建立持续监测机制

- 每季度进行一次"组织活力快速体检"（10+10+10+7的简化版）
- 将活力指标纳入干部述职和绩效评价
- 对连续两次体检红灯的干部启动调整程序

## Anti-Patterns

- ❌ 把活力问题简单归因于"激励不够"——可能是使命感/责任感/能力/组织机制的综合问题
- ❌ 只诊断不行动——体检结果束之高阁
- ❌ 把诊断变成"整人工具"——引发干部恐慌和抵触
- ❌ 只关注个体干部，忽视组织机制——人在错误机制下必然表现出错误行为
- ❌ 期望一次培训解决使命感问题——思想转变需要长期、反复、身教

## STOP Checkpoints

- [ ] 诊断结果是否区分了"组织内卷"和"干部个体"两个层面？
- [ ] 是否有至少3个不同层级的人参与打分，避免一把手主观偏见？
- [ ] 干预策略是否匹配了核心病灶（使命感/责任感/能力/组织）？
- [ ] 是否建立了持续监测而非一次性运动式诊断？
- [ ] 诊断结果是否与干部任用、激励、淘汰机制打通了？
