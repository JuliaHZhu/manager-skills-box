# forced-distribution-enforcer

强制分布与绩效结果刚性应用：通过「5等级绝对定义+赛马机制+分层分级评价+10%淘汰」四管齐下，将绩效结果与薪酬/晋升/配股/干部任命全面挂钩，构建高绩效企业文化。

## 触发条件

当用户需要设计绩效考核等级体系、讨论强制分布/末位淘汰、绩效结果如何应用、如何避免人情分/大锅饭、或需要建立高绩效狼性文化时激活。

**关键词**：强制分布 / 末位淘汰 / 绩效等级 / 赛马文化 / 绩效结果应用 / 狼性团队 / 正态分布 / 绩效刚性 / 淘汰机制 / 大锅饭

## 使用说明

### 第一步：5等级绝对定义 — 拒绝相对排名的模糊性

华为绩效管理最大的刷新是：不用简单的前10%就是A，而是对每个等级给出**绝对定义**。

| 等级 | 名称 | 绝对定义 | 比例参考 |
|------|------|----------|----------|
| **A** | 杰出贡献者 | 明显超出组织期望，各方面均超越岗位层级的职责和绩效期望，取得杰出成果，绩效明显高于他人，是部门的绩效标杆 | 10%-15% |
| **B+** | 优秀贡献者 | 达到并经常超出组织期望 | 20% |
| **B** | 扎实贡献者 | 达到组织期望，部分超出组织期望 | 50% |
| **C** | 较低贡献者 | 部分达到期望，未达到部分目标 | 10%-20% |
| **D** | 不可接受 | 明显未达到期望，不可接受 | 5%-10% |

**核心逻辑**：B是分水岭。B以上必须达到期望且有所超出，B以下就是未达标。绩效目标不是越高越好（防止穿小鞋），而是根据岗位层级职责要求设定，**超越岗位职责要求**才能评为优秀。

**STOP检查点**：
- [ ] 每个等级是否有清晰的绝对定义（不是简单的相对排名）？
- [ ] 绩效目标是否基于岗位职责客观设定，防止领导故意拔高/压低？
- [ ] A等级的定义是否要求"明显超出组织期望"而非仅仅是前10%？

### 第二步：赛马机制 — 分层分级相对评价

**"赛马而非相马"**：
- 管理者和员工分开评价
- 不同层级的员工分开评价
- 都在各自的层级内进行相对评价

**分层分类原则**：
- **高层管理者**：年度考核，关注中长期战略目标（大客户突破、大产品开发）
- **中基层管理者/员工**：半年度+年度考核，PBC管理
- **基层作业员工**：月度/季度考核，要素考核表（调试单板数、主机数、质量、漏测数）

**示例**：北京奥运会男子4×100米自由泳接力——五支队伍都打破世界纪录，但只有第一名获金牌。同样，华为要求员工在同层级内竞争，不是跟自己比，而是跟同层级优秀者比。

**STOP检查点**：
- [ ] 是否按层级/类别分开评价，避免不同层级混评？
- [ ] 高层是否适度拉长考核周期，关注中长期而非短期？
- [ ] 基层是否缩短评价周期，实现及时激励？

### 第三步：3级闭环评价流程 — 防止穿小鞋

为确保公正公开，华为设计了复杂的评价流程：

1. **员工自评**：员工基于PBC和绩效事实自评
2. **直接主管初评**：主管依据客观数据和案例打分
3. **上级管理团队集体评议**：横向拉通，确保水平一致性
4. **上上级结果审视**：特别关注高低绩效和特殊人群
5. **流程Owner建议否决权**：全流程评价，防止自扫门前雪

**关键机制**：
- 纵向成长有人管：上级有权行使否决权
- 横向一致性：拉通流程看是否全流程提升公司效率
- 正态分布不管中间，只看特别好和特别不好的

**STOP检查点**：
- [ ] 评价流程是否有集体评议环节，防止个人偏见？
- [ ] 是否有上级审视机制，确保纵向公平？
- [ ] 是否有流程Owner横向拉通，防止部门壁垒？

### 第四步：绩效结果刚性应用 — 与6大领域全面挂钩

**收入挂钩**：

| 考核等级 | 工资调整 | 奖金 | 饱和配股 | 福利 |
|----------|----------|------|----------|------|
| A | 有机会 | 有机会 | 有机会 | 暂不挂钩 |
| B+ | 有机会 | 有机会 | 根据条件 | 暂不挂钩 |
| B | 有机会 | 有机会 | 根据条件 | 暂不挂钩 |
| C | 不涨薪/降薪 | 很少或无 | 无 | 暂不挂钩 |
| D | 不涨薪/降薪 | 无 | 无 | 暂不挂钩 |

**成长挂钩**：

| 考核等级 | 干部任命晋升 | 人岗匹配晋升 | 任职资格晋级 | 不胜任淘汰/干部清理 | 内部调动 | 再入职 |
|----------|-------------|-------------|-------------|---------------------|----------|--------|
| A | 有机会，纳入继任通道 | 有机会，进入成长快通道 | 有机会 | 无 | 有机会 | 有机会 |
| B+/B | 有机会 | 有机会 | 有机会 | 无 | 有机会 | 有机会 |
| C | 无机会或考虑降职 | 无机会 | 无机会 | 进入PIP | 无机会 | 无机会 |
| D | 无机会或降职/劝退 | 无机会 | 无机会 | 不合格干部调整 | 无机会 | 无机会 |

**核心规则**：
- C和D：公司啥好事跟你没关系（一票否决）
- 干部每年10%淘汰率：绩效排名后10%的干部直接免职
- 内部调动：必须是绩效好的人才能调动
- 再入职：绩效不好，再也回不去

**STOP检查点**：
- [ ] 绩效结果是否与薪酬、晋升、配股、干部任命全面挂钩？
- [ ] 是否有低绩效员工改进计划（PIP）和淘汰机制？
- [ ] 结果应用是否有刚性规则，避免干部随意挑战？

### 第五步：绩效文化塑造 — 批判性反思

**华为坚决反对的考核方式**：
1. **不搞360度考核**：人情分太重，德能勤绩抓不住实质
2. **不考核历史绩效**：以前贡献大不代表现在胜任
3. **不看苦劳和加班**：996完不成工作 ≠ 高绩效
4. **不看学历和态度**：博士生不一定比本科生产出高
5. **不让所有人满意**：做绩效管理肯定会得罪人，接受这个现实

**高绩效文化三要素**：
1. **区分贡献**：把A类、B类、C/D类员工清晰区分
2. **激活组织**：通过竞争和压力保持组织活力
3. **导向冲锋**：绩效管理的目的是让员工愿意付出超越职责的努力

**STOP检查点**：
- [ ] 是否去掉了人情分、学历分、苦劳分等无效评价维度？
- [ ] 是否建立了"绩效不好=一切机会关闭"的清晰信号？
- [ ] 管理者是否理解绩效管理是"主管的家庭作业"而非HR的事？

## 反模式警告

⚠️ **以下做法会破坏强制分布的有效性**：
1. 轮流坐庄：今年你A明年我A，搞平均主义
2. 老好人主义：给所有人打B，不敢区分
3. 关系优先：跟谁关系好就给A
4. 学历偏见：认为高学历自然得高分
5. 苦劳导向：看谁加班多就给高分
6. 历史包袱：老员工因为资历深就默认高分
7. 部门保护主义：各自给各自的人高分，不管公司整体

## 关键数字记忆

- **A级**：10%-15%，明显超出期望
- **B+/B**：70%，达到或超出期望
- **C/D**：10%-20%，未达期望
- **干部淘汰率**：每年10%
- **PIP机会**：低绩效员工给一次改进机会
- **考核周期**：高层年度、中基层半年度+年度、基层月度/季度
