# 费用拧毛巾与成本管控

## R — 原文 (Reading)

> 2012年，全球经济不景气，华为公司开年连续5个月亏损，年度收入和净利润目标岌岌可危。集团财经费用管理部通过一套"拧毛巾三招四式"的组合拳，公司上下齐心协力，共同拧出了十亿美元费用，既保住了利润的驾，也护住了战略的航。
>
> — 华为管理手册（财务四算）, 第4章

> 制定平台组织费用预算"高压线"...费用额零增长。按照费用额同比不增长的原则要求，继续"拧"费用的"水分"。
>
> — 华为管理手册（财务四算）, 第4章

> 战略投入预算单列，专款专用，"再穷不能穷战略"。客户界面与内部运营分开，"再省不能省客户"。
>

>

## I — 方法论骨架 (Interpretation)

"拧毛巾"是华为在经营困难时期进行费用压降的系统方法论，核心是在保战略、保客户的前提下，从内部运营中挤出水分。

**三招四式组合拳：**

**第一招：定高压线（平台费用基线）**
- 制定平台组织费用预算基线，如流程IT费用占收入比重不高于X%
- 费用额零增长原则
- 平台费用需区域"买单"，受地区部财务损益约束

**第二招：弹性预算（与经营结果挂钩）**
- 机关职能平台上半年费用只授予全年40%
- 利润中心费用与收入/销毛完成率孰低挂钩弹性授予
- 超预算单位向财委会述职，严重者取消主管费用权签资格

**第三招：管住权签人**
- 刷新费用制度（差旅、外包、交际应酬等）
- 将虚假报销纳入BCG管控
- 对费用权签进行梳理，停止违规主管报销权签权力

**四式：分类管理策略**
- **第一式：战略投入单列** — 预研/变革投入与经营预算分离，专款专用，独立核算，节约不归己
- **第二式：客户界面与内部运营分开** — 内部运营"拧水分"，客户界面"再省不能省客户"，节约不归己
- **第三式：人员费用与业务性费用分类** — 人力费用匹配中长期规划，业务性费用与当年产出挂钩
- **第四式：责任中心与资源部门互相PK** — 建立内部结算机制，通过"价格听证制度"保证公允

**成本管控五重点：**
1. 设计成本（决定后期80%以上成本）
2. 采购成本与外协成本（规模经济+议价能力）
3. 质量成本（质量缺陷的退换货、维修、形象损失）
4. 库存成本（仓储费用+资金占用）
5. 期间费用（不浪费就好，重心后移至利润考核）

## A1 — 书中的应用 (Past Application)

### 案例 1: 华为2012年拧出十亿美元
- **问题**: 全球经济不景气，开年连续5个月亏损
- **方法论的使用**: 三招四式组合拳：定平台费用高压线+砍掉6639万美元；弹性预算授予（收入/销毛完成率孰低）；停止高层领导费用权签；战略投入单列保护；客户界面与内部运营分开
- **结论**: 费用压降必须系统化、分类化，不能一刀切
- **结果**: 年底费用预算控制在90%水平，拧出近十亿美元费用节余，同时保护了战略投入和客户界面

### 案例 2: 华为设计成本控制
- **问题**: 生产制造环节降成本已为时过晚
- **方法论的使用**: 将成本管控着眼点前移到设计环节，让产品设计方案能做到生产最经济；设计成本决定后期80%以上成本
- **结论**: 控制生产成本需要将着眼点前移到设计环节
- **结果**: 产品性价比提升，毛利率保持健康

### 案例 3: 华为内部结算PK机制
- **问题**: 责任中心抱怨资源部门"既贵又慢"，资源部门抱怨"内部客户难伺候"
- **方法论的使用**: 建立公开透明的PK机制：双方签订内部结算协议；责任中心拥有预算权；资源部门按明确需求准备资源；通过"价格听证制度"让结算价格接受第三方评审
- **结论**: 用市场机制替代行政协调，倒逼效率提升
- **结果**: 内部交易成本降低，服务质量改善

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 公司经营困难，需要压降费用、保住利润时
2. 平台组织膨胀，费用增长快于收入增长时
3. 需要区分战略投入和日常经营投入，保护关键领域时
4. 内部资源部门与业务部门矛盾激化，需要建立结算机制时
5. 设计成本过高，需要在研发前端建立成本控制时

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诊断成本费用结构**
   - 完成标准: 识别平台费用/客户界面费用/战略投入/人力费用/业务费用的占比和增长趋势

2. **制定费用高压线**
   - 完成标准: 为各平台组织制定差异化的费用基线（如占收入比重、零增长原则）

3. **设计分类管理策略**
   - 完成标准: 明确四类费用的差异化管控规则
   - 战略投入：单列、专款专用、节约不归己
   - 客户界面：保障投入、节约不归己
   - 人员费用：匹配中长期人力规划
   - 业务性费用：与当年产出挂钩、弹性管控

4. **建立弹性预算机制**
   - 完成标准: 将费用授予与收入/利润完成率挂钩，经营计划完不成则费用减少

5. **推动成本前移**
   - 完成标准: 识别设计成本、质量成本等前端成本管控点，建立目标成本机制

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 正常增长期的扩大投入 — 用投资策略即可
- 无成本数据基础的初创期 — 先建立基础核算
- 纯采购价格谈判 — 用采购策略skill
- 已经极度精简、无水分可拧的组织 — 过度拧毛巾会伤害组织能力

### 作者在书中警告的失败模式

- **一刀切砍费用**: 不分战略投入和经营投入，导致长期竞争力受损
- **省客户界面的钱**: 影响业务拓展和客户感知，得不偿失
- **只拧毛巾不建机制**: 危机时猛砍，危机过后又膨胀，循环往复

### 作者的盲点 / 时代局限

- 华为"拧毛巾"发生在2012年通信设备行业寒冬期，对于轻资产互联网公司（人力成本为主），"拧毛巾"的重点应从物理成本转向人效提升
- 强调"费用额零增长"，但在高通胀环境或快速扩张期可能需要调整

### 容易混淆的邻近方法论

- 与精益管理: 精益管理聚焦流程效率提升，本 skill 聚焦费用预算压降和分类管控
- 与零基预算: 零基预算要求每年从零开始论证，本 skill 更强调基于基线的弹性管控
