# planning-parameter-engineer

## Metadata
- **Version**: 1.0.0
- **Author**: Cangjie distillation from 《华为管理手册（5版）——计划手册》
- **Trigger**: 计划属性 / 提前期 / 计划参数 / 安全库存 / 批量设置 / 固定供应天数 / ABC分类 / 计划员属性 / MRP方法

## Purpose
指导用户正确配置和维护ERP系统中的计划参数（计划属性、提前期、批量、安全库存、ABC分类等），确保MRP计划结果的准确性和可执行性。

## When to Use
- 新产品转产需要设置计划属性时
- MRP计划结果异常（偏大/偏小/漏计划）需要排查属性问题时
- 需要建立或优化计划属性维护流程时
- 组织变更/产品变更需要调整计划员属性时
- 采购提前期变化需要更新时
- 需要设定安全库存策略时

## STOP Checkpoints
- [ ] 是否已区分制造件和采购件的属性维护责任？
- [ ] 提前期是否已按实际货期核实（预处理/处理/后处理）？
- [ ] 批量属性是否与加工标准批量/最小采购批量一致？

## Inputs
- 项目清单（制造件/采购件/内部订单）
- 供应商货期、加工周期、标准批量
- 历史出库数据、需求预测
- 组织分工、产品归属

## Outputs
- 计划属性配置表（制造件/采购件/内部订单）
- 提前期属性表
- 批量属性方案（固定/最小/最大/倍数/供应天数）
- ABC分类与固定供应天数映射
- 安全库存策略

## Procedure

### 阶段一：计划属性维护总体流程
1. **维护项目计划员属性**（明确责任主体，防止计划遗漏）。
2. **确定MRP计划方法**（MPS/MRP/Not planned）。
3. **确定"制造/购买"属性**。
4. **按制造/购买特征确定需维护的属性项目**。
5. **修改已确定的计划属性**（各组织分别维护）。

### 阶段二：计划员属性维护
1. **一般项目**：
   - 量产产品 → "产品名称"（订单生产计划处）。
   - 研发/试产状态 → "R+产品名称"（项目管理处计划员）。
   - 多产品共用 → "使用量较大的产品名称"。
2. **特殊项目**：
   - 终端配套 → "Terminal"
   - 包装材料 → "Package"
   - 库存计划项目 → "StockPlan"
   - 生产辅料 → "A_mid"
3. **禁止**：计划员属性不能为空、"Midtest"、"Research"等无人负责的属性。

### 阶段三：MRP计划方法设置
- **MPS计划**：需手工控制的关键项目（独立需求、计划百分比重点控制、关键资源）。
- **MRP计划**：非关键资源项目，由父项分解而来（大部分原材料）。
- **Not planned**：不必做长期计划的项目（如软件）。

### 阶段四：制造件属性维护
1. **加工批量属性**：
   - 固定订单数量、最小订单数量、最大订单数量、固定批量倍数、固定供应天数。
   - 原则：推式供应类型的制造件需维护；用量稳定设固定批量+供应天数，不稳定设最小/最大/倍数+供应天数。
   - 半成品固定供应天数一般设为一周。
   - 制成板与成品板：制成板设批量属性，多数成品板可设最小批量。
2. **提前期属性**：
   - 预处理提前期、处理提前期、固定提前期、可变提前期。
   - 半成品：可变提前期设为0，固定提前期=常用批量的加工时间。
   - 需分解的整机：维护处理提前期；不分解的整机同半成品。
   - 公式：处理提前期 = INT(提前期批量 × 可变提前期 + 固定提前期)。
3. **控制类属性**：
   - 需求时间栏：PTO/POC设子项总装提前期；其他设项目总装提前期。

### 阶段五：采购件属性维护
1. **提前期属性**（由采购部门维护，计划员定期检查）：
   - 预处理提前期：统一2个工作日。
   - 处理提前期：供应商货期折算为有效工作日。
   - 后处理提前期：境内2个工作日，境外6个工作日。
2. **批量类属性**（由采购部门维护）：
   - 固定订单数量、最小订单数量、最大订单数量、固定批量倍数。
3. **ABC分类与固定供应天数**：
   - A类（5-10%物料，80%金额）：6天
   - B类（10-15%物料，10-15%金额）：11天
   - C类（80%物料，5-10%金额）：22天
   - 修正：JIT到货、单价/体积/货期特殊物料可调整。
4. **无提前期/无批量项目**：计划员提交采购部门确认认证信息。

### 阶段六：内部订单项目属性维护
1. **需求组织**：
   - 制造/购买 = "购买"
   - 在制品制造 = "否"
   - 来源类型 = "库存"
   - 来源组织 = "供方组织"
   - 来源子库 = 供方缺省库名
   - MRP方法 = "MRP Planning"
   - 确认默认接收子库和货位
2. **供给组织**：
   - OE Transactable = "是"
   - 子库Reservation Control = "可预留"

### 阶段七：安全库存设置
1. **动态计算**：安全库存 = 安全库存百分比 × (安全库存时间段天数内毛需求 / 安全库存时间段天数)。
2. **手工输入**：非MRP计划的安全库存。
3. **设置原则**：根据需求波动、提前期不确定性、服务水平要求确定。

### 阶段八：定期核查机制
1. 每月检查新项目计划属性是否维护。
2. 每季度检查提前期是否合理（特别是货期变化的物料）。
3. 每月检查计划员属性为空或无人负责的项目。
4. 版本切换/ECO生效前重点检查相关项目属性。

## Key Principles
- 计划属性相当于计算机程序的参数设置，合理的参数才能运行出合理的结果。
- 采购件提前期和批量由采购部门维护，计划员负责检查和推动。
- 计划员属性的核心是"责任到人"，避免计划遗漏。
- 制造件提前期中，半成品可变提前期常设为0，简化计算。
- 内部订单项目属性错误会导致双方都不下计划（漏计划）或重复计划。

## Failure Modes
| 症状 | 可能原因 | 对策 |
|------|----------|------|
| 某物料双方都不下计划 | 内部订单项目属性双方互设来源/购买错误 | 核查需求组织和供给组织的来源类型、制造/购买、在制品制造属性 |
| 采购计划到货日期严重不准 | 提前期维护错误（预处理/处理/后处理） | 核实供应商实际货期；按境内/境外规则设置后处理提前期 |
| 加工计划批量不合理 | 固定/最小/最大批量与加工标准批量不符 | 对照工艺文件核实；制成板和成品板批量关系理顺 |
| 大量物料无计划员 | 新项目未维护/组织变更后未清理 | 建立新项目属性检查清单；组织变更时专项清理 |
| 安全库存失效 | 百分比或时间段天数设置不当/需求模式变化 | 根据历史需求波动重新计算；定期复核 |
