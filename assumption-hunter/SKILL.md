# 假设猎手

基于丹尼特《直觉泵》第8章"跳出系统"（Jootsing）。

## 核心洞见

争论长期无进展，双方都觉得对——**往往因为他们共享的某个前提是错的**，而双方都不觉得它需要被检验。

你的任务：把它找出来。

## When to use

- 读到理论/模型觉得"结论奇怪但说不出哪里不对"
- 两个学派长期争论毫无进展
- 跨学科时觉得新领域某些基础假设可疑
- 听到"显然"、"众所周知"、"为了简化假设……"
- 想在自己的研究里做出真正创新而非增量修补

## 四步猎杀

### Step 1: 回溯挖假设

从结论倒推，层层追问"这个成立的前提是什么"：

```
结论: "公司应只基于可量化数据做决策"
  ↓ 前提是什么？
前提: 所有有价值的决策因素都可量化
  ↓ 前提又是什么？
前提: 组织绩效可完全分解为测量指标
  ↓ 继续...
前提: 测量本身不改变被测量对象
```

**关键**：不停在第一层。真正隐藏的假设在第三、四层——你平时不会去想"这种问题"的那一层。

→ **检查点**：列出所有假设后，问用户"有没有遗漏或歪曲？"

### Step 2: 分类标记

```
明确假设:   [列出 —— 对方承认的前提]
隐含假设:   [列出 —— 对方没说但推理依赖的]
共享假设:   [列出 —— 双方都默认的，最可疑]
```

特别关注：
- **"为了方便"型**："为了简化，假设X……" → 后来没人记得X是假设
- **"不存在之物"型**：燃素、以太、看不见的手 → 被当实体但可能只是概念便利

### Step 3: 逐个否定

对每个假设：
- 如果它不成立，理论还站得住吗？
- 如果反面成立，导出什么？
- 有没有反例？（一个就够了）

### Step 4: 跳出重建

扔掉或翻转假设，看新图景。**跳得有意义**——新框架必须比旧的解释更多或更简洁。

→ **检查点**：展示发现，问用户"这个假设你觉得值得深挖吗？要切归谬法推到极端吗？"

## 危险信号清单

| 信号 | 含义 |
|------|------|
| "显然"、"当然"、"众所周知" | 未检验的假设 |
| "为了简化" | 可能已被遗忘的初始假设 |
| 争论10年+无进展 | 双方共享错误前提 |
| "这在数学上可以证明" | 问：前提是什么？ |
| 跨学科时觉得"这很怪" | 你看到了圈内人看不到的 |

## 学科转换者的优势

你从金融/经济到战略管理/知识管理——每个学科有自己的"不言而喻"。当觉得某个学科推论"难懂"，往往不是你理解不够，而是你未被同化。**困惑 = 猎物的气味。**

- 经济学：理性人、均衡、完全信息
- 战略管理：竞争优势、资源异质性
- 知识管理：知识可管理、隐性/显性二分

## 学术应用

**论文创新**：最好创新不是"前人没做过X"，而是"前人都假设了Y，而Y是错的"。

**文献综述**：不只总结"谁说了什么"，问"这个领域默认了什么"。

**跨学科**：经济学哪个假设在战略管理里不成立？反过来呢？交叉处 = 创新点。
