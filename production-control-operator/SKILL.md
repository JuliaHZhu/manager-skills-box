# 生产物控与排产发货策略

## R — 原文 (Reading)

> 在整个排产过程中必须坚持交货第一、物流效率第二、设备使用率第三的原则。非加工成熟产品与中研加工产品采用推式生产组织方式；量产产品与加工工艺成熟的中试单板采用拉式生产组织方式（实行精益化生产）。
>
> — 华为计划手册, 3.4.4 加工策略

> 合同排序根据合同交货期初排，根据公司策略、客户重要性进行调整，合同备货各环节按排序结果执行。预留时间应与整机调测进度相配合，正常情况下在整机入库前2--3天预留，不得随意提前。
>
> — 华为计划手册, 3.4.4 发货策略

> 日清日结基本要求：按照时间要求完成工作、同时保证工作结果的正确性。即凡有物流/信息流、需要控制职能的地方，都有如下要求：正确性要求、时间进度要求、流量--数量与金额要求。
>
> — 华为计划手册, 3.4.5 日清日结

## I — 方法论骨架 (Interpretation)

生产物控是一套连接计划与执行的现场运营方法，核心是三句话："交第一、流第二、设第三"。

**排产策略**：推式（按任务令从前向后推动，适合中研/非成熟产品）与拉式（由后工序需求拉动，适合量产/成熟产品）并存。在电装事业部内部，拉式以任务令完工时间为起点倒排，兼顾设备效率。

**任务令排队规则**：
- FICFIS（先到先服务）：任务量<加工能力时、中研中试任务
- SPT（最短操作时间）：前一工序超负荷、下一工序空闲时
- 关键比率（CR=所余时间/完工所需时间）：通用方法，决定排产次序
- 约翰逊规则：两台设备并行作业时最小化总时间

**发货策略五大原则**：合同排序（组合优先）、预留（入库前2-3天）、统筹审批（齐套性优先及时性）、欠料控制（7天内可解决不得入库）、发运跟踪。

**缺料分层分级**：三层通报（一般/严重/重大），对应不同通报对象和响应时效；采购部门按层次升级处理。

**日清日结**：围绕订单履行、生产计划、财务成本三条主流业务，做到正确、及时、数量金额三要求。

## A1 — 书中的应用 (Past Application)

### 案例 1: 推式与拉式并存的生产组织
- **问题**: 华为电装事业部同时承担中研试制和量产加工，任务性质差异大
- **方法论的使用**: 
  - 中研/非成熟产品用推式（收到需求立即安排，控制权在调度）
  - 量产/成熟中试用拉式（由下游需求拉动，减少在制品）
  - 建立柔性生产线应对特急任务，与高效率线分开考核
- **结论**: 不能用单一模式覆盖所有生产类型
- **结果**: 在制半成品存量最小化，任务令平均延迟天数缩短

### 案例 2: 缺料分层分级处理
- **问题**: 生产缺料频发，轻重缓急不分，采购响应不及时
- **方法论的使用**: 
  - 第一层（一般）：影响加工3天内/发货1天内，录入系统
  - 第二层（严重）：影响加工4-8天/发货2-8天，报采购调度部门
  - 第三层（重大）：影响加工8天以上/发货8天以上，报高层领导
  - 采购按层次在当天17:00前/次日11:00前反馈
- **结论**: 分层分级确保重大问题优先解决，避免信息淹没
- **结果**: 建立标准化缺料处理通道

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 车间在制品积压严重，需要调整排产方式（推式改拉式或反之）
2. 多任务令争抢同一设备或产线，需要确定优先级规则
3. 合同发货延误频发，需要重新设计发货策略和预留机制
4. 缺料信息混乱，采购和计划互相推诿，需要建立分级通报制度
5. 仓库数据与系统不一致，需要推行日清日结机制

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **诊断当前生产组织方式**
   - 完成标准: 明确当前主要使用推式还是拉式，在制品水平，任务延迟情况
   - 判断矩阵:
     | 产品类型 | 建议方式 | 原因 |
     |---|---|---|
     | 中研/试制/非成熟 | 推式 | 需求不确定，需调度集中控制 |
     | 量产/成熟中试 | 拉式 | 需求稳定，减少在制品 |

2. **选择并实施任务令排队规则**
   - 完成标准: 根据当前瓶颈选择合适规则
   - 选择指南:
     - 任务量<能力且中研任务多 → FICFIS
     - 前一工序超负荷、后工序空闲 → SPT
     - 通用场景 → 关键比率（CR最小优先）
     - 双面板/双工序并行 → 约翰逊规则

3. **设计发货策略**
   - 完成标准: 输出合同排序规则、预留机制、欠料控制标准
   - 五大要素:
     1. 合同排序: 按交货期初排，组合合同优先，匹配成功合同不改序
     2. 预留: 整机入库前2-3天，超5天未入库解除预留
     3. 统筹审批: 齐套性优先于及时性，组合合同同步入库
     4. 欠料控制: 安装材料不欠发；7天内可解决不得入库；同一合同欠料补货≤2次
     5. 发运跟踪: 提前1天通知客户到货时间

4. **建立缺料分层分级通道**
   - 完成标准: 输出三级缺料定义、通报模板和响应时效
   - 三层定义:
     | 层次 | 影响范围 | 主送 | 响应时效 |
     |---|---|---|---|
     | 一般 | 加工≤3天/发货≤1天 | 系统录入 | 采购当天17:00前回复 |
     | 严重 | 加工4-8天/发货2-8天 | 采购调度部门 | 次日11:00前反馈 |
     | 重大 | 加工>8天/发货>8天 | 高层领导 | 紧急协调 |

5. **推行日清日结（如需要）**
   - 完成标准: 建立业务日清规范、监控标准和考核指标
   - 三要求: 正确性、时间进度、流量（数量与金额）
   - 三条主流: 订单履行、生产计划、财务成本
   - 涉及模块: INV、WIP、OE、PR/PO、CST、AR、AP

6. **输出物控操作手册**
   - 完成标准: 包含排产规则、发货策略、缺料通道、日清规范、责任部门和检查表

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 战略层面的年度产销平衡（属于S&OP/TOM资源管理范畴）
- 纯服务业无实物生产的流程调度
- 高度自动化的黑灯工厂（已由MES/APS自动决策）

### 作者在书中警告的失败模式

- 推式排产导致在制品增加："推式排产方法容易导致车间在制品数量增加"
- 预留提前占用实物："有时提前预留，占用了实物，但后续又有急单来时，却没法预留"
- 欠料发货失控："预计7天内可以解决欠料的合同不得入库，不得欠料发货"——违反此规则会导致发货后长期补不齐
- 日清日结流于形式：需要监控措施和绩效考核挂钩，否则难以持续

### 作者的盲点 / 时代局限

- 基于电装事业部的电子制造场景（SMT、插件、波峰焊），对流程工业（化工、钢铁）的适用性有限
- 日清日结依赖MRPII各模块（INV/WIP/OE等），现代云ERP/MES集成度更高，但核心逻辑仍适用
- 拉式生产建议只应用于电装事业部内部，现代供应链协同已扩展至供应商端拉动（VMI/JIT）

### 容易混淆的邻近方法论

- MRB（物料复审会议）vs 缺料处理: MRB处理质量争议导致的物料使用决策，缺料处理是供应不足时的补货和替代决策
- 推式/拉式 vs JIT: JIT是拉式的极致形态，但书中将JIT作为库存控制方法（原材料JIT），拉式作为生产组织方式（车间排产），层面不同
