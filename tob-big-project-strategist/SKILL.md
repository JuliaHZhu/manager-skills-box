# ToB大项目赢单策略

## R — 原文 (Reading)

> 一个典型的大项目运作过程，从开始到结束是一个简化的五阶段模型……如果前面的五个过程，每一个过程都是70%成功率的话，听上去很好，有70%。可是5个70%乘起来就只有16%，也就是丢掉了84%的项目。
>
> — 华为管理手册（项目管理）, Ch6

> 华为 to B 大项目销售的场景和打法的演进路线。华为的早期也是靠直觉的……打开市场之后需要更加稳健的项目管理，这时，华为提炼出了营销四要素，之后把这些要素固化到组织和流程中。
>
> — 华为管理手册（项目管理）, Ch7

> 我们把销售流程从原来的销售变成了从线索到回款的LTC，就是告诉大家，它不再是一个销售流程，他是一个端到端的流程。我们以前说的销售投标只是中间的一个点而已。
>
> — 华为管理手册（项目管理）, Ch8

## I — 方法论骨架 (Interpretation)

ToB大项目的核心难题：**过程长、成功率低、丢单原因隐蔽**。华为将其从艺术破解为技术，通过“三板斧+营销四要素+LTC”把胜率从偶然变为必然。

**五阶段漏斗模型（隐含16%陷阱）：**
1. 产品准入（供应商清单审核）
2. 方案交流（第二轮淘汰）
3. 投标（交标后淘汰）
4. 短名单现场比拼（2-3家PK）
5. 交付与二期（交付不满意被替换）
每个阶段70%成功率 → 整体仅16%。破解方法：**把事后算账变成事前策划**。

**三板斧（破局武器）：**
1. **参观样板点**：让客户亲眼看到成功部署，第三方客户私下证言胜过一万句自夸
2. **参观总部/公司**：感受公司规模、研发实力、长期信赖感
3. **实验局/POC**：在客户现场做真实验证，给出完美报告

配套工具：**一纸禅** — 将差异化解决方案价值精简到一张纸以内，全团队统一口径反复传递。

**营销四要素（全过程死磕）：**
所有要素站在客户视角、与竞争对手比较，而非自嗨。
1. **客户关系**：关键决策链覆盖、信任建立
2. **解决方案与品牌**：价值主张在客户场景下能算出来（TCU/TVU）、技术标书与评标标准契合、技术评分领先
3. **融资与商务**：帮客户解决资金问题、设计有竞争力的商务方案
4. **交付**：售前售后拉通，用交付能力证明长期合作可靠性

**LTC（线索到回款）端到端流程：**
- 往前：主动培育线索，与客户战略对标
- 中间：管理机会点，铁三角协同
- 往后：做好交付，赢利好才是好项目

## A1 — 书中案例 (Application in Book)

**马来西亚3G项目**：华为在马来西亚品牌仅为二流，爱立信要求供应商必须提供10个以上商用网络。华为使出三板斧：
1. 邀请客户CTO到新加坡样板点参观，与竞争对手网络做对比测试，并请新加坡客户闭门研讨（华为人不参加）
2. 邀请客户参观深圳总部，感受研发园区和年轻队伍
3. 在D公司做实验局，在标书截止前给出完美报告，安排客服和媒体参观
最终客户上上下下都能复述华为的价值主张，项目顺利拿下。

**新加坡4G网络项目**：华为通过四要素分析，发现爱立信与客户有二三十年关系、客户不缺钱、交付要求交钥匙，华为无机会。于是做优先级处理，投入很小，避免资源浪费。

**澳洲传输项目**：通过LTC战略对标，发现客户不仅需要支持4G无线宽带，还需要支持企业专线。重新引导客户采用第三代全IP传输网络，请研发总裁和世界级专家辅助制定战略，最终扳回对手孵化的机会点。

## E — 执行步骤 (Execution)

### Step 1: 绘制你的五阶段漏斗并计算真实胜率
列出你的典型项目从线索到回款的5个关键阶段，计算各阶段历史转化率：
```
阶段1转化率 × 阶段2转化率 × ... = 整体胜率
```
如果整体低于30%，说明存在系统性短板。

### Step 2: 设计你的“三板斧+一纸禅”
| 板斧 | 你的行动 | 成功标准 |
|------|----------|----------|
| 第一板 | 选定1-2个世界级样板点，精兵强将强攻打造 | 客户可实地参观，有第三方证言 |
| 第二板 | 设计总部/公司参观动线，按工程化管理 | 客户感受到长期信赖感 |
| 第三板 | 在客户现场做POC/实验局 | 给出量化对比报告 |
| 一纸禅 | 一页纸价值主张：差异化点+客户收益+长期合作理由 | 销售团队人人能背，客户能复述 |

### Step 3: 用营销四要素做项目策划
对每个重点项目，按四要素打分（每项1-5分）：
- **客户关系**：关键决策人覆盖度、信任度
- **解决方案**：TCU/TVU是否可量化、技术标书契合度、评分领先性
- **融资商务**：是否帮客户解决资金、报价竞争力
- **交付**：是否有可靠交付团队和方案
**规则**：四项中若有两项明显弱于竞争对手，项目优先级降级或放弃。

### Step 4: 沿着LTC流程固化成功要素
1. **管理战略**：每年初与客户中高层做战略对标会，对齐明年规划
2. **管理线索**：主动培育与己方方案方向一致的线索，而非被动响应
3. **管理机会点**：铁三角（AR/SR/FR）端到端负责，售前售后拉通
4. **管理合同执行**：交付代表早期进入，确保可交付、可验收、可回款
5. **授权一线**：让听得见炮声的人呼唤炮火，反应速度比对手快一倍

### Step 5: 训战结合提升个人与团队战斗力
- **721学习**：10%课堂 + 20%同事交流 + 70%实战
- **AAR复盘**：每个项目结束后做After Action Review，训练接近实战
- **铸剑行动**：用真实项目模拟演练，有实践经验的老师引导复盘

## B — 边界与反例 (Boundary)

**不适用场景：**
- toC零售、电商等冲动消费场景，不适用长周期关系营销
- 金额低于百万、决策周期短于1个月的标品采购，三板斧成本过高
- 纯政府关系驱动型项目（如某些单一来源采购），四要素分析中“关系”权重畸高，其他要素形同虚设
- 客户完全无预算、无计划、无需求的三无项目，任何策略都是浪费

**常见陷阱：**
- 三板斧变成“三把钝斧”：样板点比对手还烂，总部参观毫无亮点，实验局草草了事
- 营销四要素变成“自嗨四要素”：站在自己视角打分，而非客户视角、竞争视角
- 忽视交付售后：赢了标丢了口碑，二期三期出局
- 知道对手强还硬攻：四要素全弱时，应聚焦细分市场或放弃，而非压强原则滥用
