# business-design-four-elements

当用户需要"设计业务模式、评估竞争壁垒强度、构建利润护城河"时激活。
适用于战略规划落地、新业务设计、竞争差异化分析、商业模式重构。
不适用于：纯技术实现问题、已有成熟模式后的日常运营微调、没有客户视角的内部流程优化。

Trigger: 业务设计 / business design / 战略控制点 / 利润模型 / 价值主张 / 客户选择 / 活动范围 / 护城河 / 竞争壁垒 / 业务模式设计 / 怎么赚钱 / 利润保护

## 核心方法论

### 一、业务设计四要素框架

业务设计是战略规划的核心环节，回答"业务如何成功"。四要素之间存在严密的因果逻辑：

```
客户选择 + 价值主张 → 利润模型 → 战略控制点（保护利润） → 活动范围（实现落地）
```

### 二、要素一：客户选择与价值主张

**客户选择**：
- 主要服务哪类客户群体？
- 哪类客户**不在**服务范围内？（敢于说不）
- 如何协调现有市场和新兴市场群体？

**价值主张**：
- 客户购买我方产品/服务的核心理由是什么？
- 相对于竞争对手，我们的竞争性差异在哪里？
- 价值主张不是"我们有什么"，而是"客户获得什么"

### 三、要素二：利润模型

常见盈利方式：
- 产品销售
- 服务协议/订阅
- 许可证/使用费
- 知识产权销售
- 品牌溢价
- 解决方案收费

关键问题：在我们的业务领域主要通过什么获得利润？是否开发了多种盈利模式？

### 四、要素三：战略控制点（重中之重）

战略控制点 = 确保为客户长期提供核心利益 + 保护利润流不受竞争对手侵犯 的资源或能力。

**战略控制点强度指数表**：

| 强度 | 指数 | 战略控制点 | 案例 |
|------|------|------------|------|
| 🔴高 | 10 | 拥有标准 | 高通、ARM |
| 🔴高 | 9 | 价值链控制 | 微软、苹果 |
| 🔴高 | 8 | 一系列超级优势地位 | 可口可乐、腾讯、亚马逊 |
| 🟡中 | 7 | 客户关系 | 通用电气、IBM、华为 |
| 🟡中 | 6 | 品牌、版权 | 宝马、LV、Canon |
| 🟡中 | 5 | 两年产品开发提前期 / 技术领先一年 | 村田、Intel、戴森、华为5G |
| 🟢低 | 4 | 一年产品开发提前期 / 功能性能品质领先 | 大金、格力、方太 |
| 🟢低 | 3 | 具有10-20%成本优势 | 西南航空、美的、富士康 |
| ⚪无 | 2 | 具有平均成本 | 无数企业 |
| ⚪无 | 1 | 成本劣势的商品 | 无数企业 |

**战略控制点 vs 护城河**：
- 护城河侧重防守（保护利润流）
- 战略控制点兼顾攻守：支撑价值主张（进攻）+ 保护利润（防守）
- 攻中有守，守中带攻

**设计方法**：
1. 基于客户选择明确价值主张
2. 从业务价值链和财务角度设计几种赢利模型
3. 因果分析：支撑价值主张和持续赢利的具体控制点是什么？

### 五、要素四：活动范围

回答：在价值链中，哪些活动自己做？哪些通过合作/外包完成？

关键概念：**独特运营活动**（迈克尔·波特）
- 竞争战略 = 做到与众不同 = 有目的地选择一整套不同于竞争者的运营活动
- 通过价值创造网（VCW）方法，识别支撑战略定位的特别属性

**案例：华为"小灵通手机"终端售后独特做法**
- 问题：销售渠道、售后服务建设周期长、成本高
- 独特设计：机器坏了就换（而非维修）
- 前提：无线固定台损坏率仅1%左右，即使手机高一倍也不过2%
- 效果：卖100台送2台解决售后，代价小、速度快，为终端业务发展做出历史性贡献

## 使用步骤

1. **明确客户选择**：谁是我们的目标客户？谁不是？
2. **定义价值主张**：客户为什么买我们？竞争差异是什么？
3. **设计利润模型**：通过什么方式赚钱？多种盈利模式？
4. **识别战略控制点**：用什么保护利润？强度指数多少？如何提升？
5. **界定活动范围**：哪些自己做？哪些外包？运营活动如何独特设计？

## 边界与反模式

❌ **不要**：
- 把战略控制点简单等同于"核心竞争力"（过于笼统）
- 只谈防守不谈进攻（护城河思维局限）
- 活动范围设计随大流（抄竞争对手的做法）

✅ **要**：
- 从客户购买和竞争角度深入分析价值主张
- 从业务价值链和财务角度因果推导战略控制点
- 敢于设计独特的运营活动（哪怕看似不合常规）
