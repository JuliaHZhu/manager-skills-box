# strategic-reserve-force-operator

## When to Activate

- 用户提到"战略预备队"、"转人磨芯"、"训战赋能"
- 组织变革/业务转型需要大量跨领域干部，但现有人才结构固化
- 需要把研发/机关的干部输送到一线，或把收缩业务的人员转换到新战场
- 想建立内部"人才缓冲带"，在机会来临时快速组建突击队
- 讨论"能上能下"、"循环流动"、"升官发财请来战略预备队"

## Core Philosophy

> "战略预备队是最重要的转换中介。我们要通过变化，赋予新能量，承前启后，传帮带，使新的东西成长起来。"

战略预备队不是培训机构，而是**能力交付平台**；不是权力机构，而是**人才供给与鉴别的基地**。它的核心使命是：
1. **激活组织血液循环**：防止干部板结、结构老化
2. **完成能力转换**：让有经验的人掌握新战法，适应新结构
3. **筛选高潜质人才**：在实战中识别能打"上甘岭"的人

## The Strategic Reserve Force Loop

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│   选拔入队   │ → │   训战结合   │ → │   实战空投   │
│  (前25% +   │    │  (案例+研讨  │    │  (混编一线   │
│   结构改革   │    │   +考试)    │    │   作战)      │
│   溢出人员)  │    │             │    │              │
└─────────────┘    └─────────────┘    └─────────────┘
       ↑                                    ↓
       └─────────────┐    ┌─────────────┐
                       ← │   鉴定出队   │ ←
                         │  (能力+贡献  │
                         │   双评价)   │
                         └─────────────┘
```

### Phase 1: 选拔入队（Selection）

**入队三大来源**：
1. **优秀种子**：各部门前25%的绩效优秀者，自愿报名+主管推荐+公示背书
2. **风险国家/业务收缩溢出**：因政治风险或产品线下马而撤出的人员，整建制转入预备队充电
3. **结构性改革人员**：关闭的产品开发组织中的人才，转入预备队重新找方向

**选拔原则**：
- 责任结果导向：入队前必须有岗位贡献证明，不是"落后员工收容所"
- 高潜质优先：优先选拔有使命感、愿意接受新挑战的人
- 担保责任制：推荐主管对被推荐者承担连带责任，推荐单位内部公示

### Phase 2: 训战结合（Training + Combat Simulation）

**训练模式**：
- **公共熔炉**：所有体系通用训练（跑步、纪律、文化），打造"合金钢"
- **专业分队**：按场景（网络架构转型、云服务、平安城市等）设立分队，差异化训练
- **铁三角实战**：从散兵训练走向铁三角组成训战，跨职能混编（技术+财务+供应链）

**学习导向**：
- 以**学习理解**为导向，不是以直接作战结果为导向（前方才看结果）
- 天天考试，压力大才能迸发能量
- 教学要结合现实，引导明天但不能跳跃太多

### Phase 3: 实战空投（Combat Deployment）

- **混编作战**：预备队员不是取代一线"江南游击队"，而是与其混编，以区域为中心
- **聚焦新领域/大项目**：优先投向新业务、战略项目、艰苦地区
- **台阶式爬升**：不一定非要爬到"喜马拉雅山顶"，山麓种地、半山腰打猎都是英雄

### Phase 4: 鉴定出队（Evaluation & Assignment）

**鉴定原则**：
- **突出重点**：不是对人做全面鉴定，而是突出训战中的表现和可用方向
- **互动修正**：组织鉴定要与学员互相交流，听听他们的意见再修正
- **持续跟踪**：出队后仍要跟踪其后续岗位表现

**出队去向**：
- 优秀者推荐到新岗位/大项目，以实战贡献结果决定是否升职
- 不适合转型者快速返回原部门，避免"进预备队=死路一条"的恐惧
- 部分人回流研发/GTS/营销，带着客户洞察反哺机关

## Key Operating Rules

### 1. 总队是平台，分队是权力机构
- **总队**：教育组织，负责训练、管理、鉴定、出队；不管职位分配
- **分队**：有鉴定权、使用权、识别权；把需求、训战、任用打通

### 2. 末位淘汰制（精神淘汰）
- 不认真学习、态度不端正者淘汰（不是能力末位淘汰）
- 公示淘汰名单，发函通报推荐单位
- 退队/转岗不算末位淘汰

### 3. 预算与激励
- 预备队队员去战场前可先涨职级/薪，提升积极性
- 作战胜利后利润分摊到国家/项目，预备队也有分成
- 预算不庞大：风险国家人员转入时把薪酬包带回来，原地区部成本降低

### 4. 边缘模糊化
- 在队/不在队的都是公司未来接班人
- 自学成才者同样承认，不局限于集中培训

## Practical Playbook

### Step 1: 明确战略预备队的战略定位

回答三个问题：
1. **为了支撑什么转型？**（如：从管理为中心→项目为中心；从CT→ICT）
2. **需要培养什么新能力？**（如：解决方案销售、云服务、数字化运营）
3. **人才从哪里来、到哪里去？**（来源结构、出队承接组织）

### Step 2: 设计选拔机制

- 制定入队硬性门槛（绩效前25%、必须有担保人）
- 建立自荐+推荐双通道
- 公示+背书，让入队成为荣誉

### Step 3: 设计训战内容

- 公共课程（文化、战略、通用方法论）
- 场景化分队训练（按新业务/新区域划分）
- 案例必须来自公司真实一线，不是通用MBA案例

### Step 4: 设计实战与鉴定机制

- 与一线主管明确：预备队员是"参战部队"不是"空降替换"
- 建立简洁的鉴定模板：突出能力亮点和适用方向，不写"人生鉴定"
- 与HR/atlas打通：出队后持续跟踪3-6个月

### Step 5: 建立回流与淘汰机制

- 不适合者快速回流，不贴标签
- 建立精神末位淘汰，保持预备队纪律性
- 定期向指导委员会述职（每半年）

## Anti-Patterns

- ❌ 把战略预备队变成"落后员工收容所"或"裁员缓冲池"
- ❌ 追求培训人数、点击率等虚荣指标（"林志玲天生丽质，不是训练出来的"）
- ❌ 预备队架空一线，把"江南游击队"挤掉
- ❌ 强调能力预备而忽视实战使用（"储备"思维）
- ❌ 对所有学员公平面面俱到——培训只抓成功的关键点，剩下的靠自学

## STOP Checkpoints

- [ ] 入队人员是否真的是前25%的优秀者，而非被淘汰者？
- [ ] 训战案例是否来自本公司真实战场？
- [ ] 鉴定是否简洁、突出可用性，而非全面评价？
- [ ] 出队后是否有承接岗位，避免"培养了却用不上"？
- [ ] 是否建立了精神末位淘汰，防止预备队变成"温柔乡"？
