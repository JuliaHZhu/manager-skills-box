# 切身利益原则 (Skin in the Game)

## R — 原文 (Reading)

> "解决方案在于强制他们付出切身利益。永远不要相信一个没有自由的人所说的话。只有荣誉感才能促进商业的发展。任何商业都是如此。"
>
> — 塔勒布, 第七卷第23章

---

## I — 方法论骨架 (Interpretation)

切身利益原则是一个可信度评估框架：在听取任何建议、预测、承诺或评估任何决策时，先问一个核心问题——"这个人是否承担了其判断的下行风险？"

如果答案是"否"，则该建议的权重应大幅降低。因为当决策者不拿自己的钱、时间、声誉或自由下注时，他们有动机进行风险转移：将下行风险推给他人，保留上行收益给自己。

这个原则适用于所有领域：投资建议（基金经理是否用自己的钱买他推荐的基金？）、政策建议（经济学家是否为错误预测付出过代价？）、医疗建议（医生是否会因为过度治疗而失去收入？）、商业合作（对方是否以个人资产担保？）。

核心洞察：机构没有荣誉感，个人才有。优先信任以个人信誉背书的承诺，对"机构代表"的承诺保持怀疑。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 阿拉伯的劳伦斯 vs 迈耶·兰斯基
- **问题**: 在流氓的承诺和公务员的承诺之间，该信任谁？
- **方法论的使用**: 劳伦斯（公务员）承诺给阿拉伯部落一个国家，但受制于英法的秘密协议，无法兑现——他没有"自由"来履行承诺。兰斯基（流氓）以个人荣誉担保债务，他的最大资产就是"一言九鼎"。
- **结论**: 机构（和政府）的承诺不可靠，因为机构不承担责任；个人的承诺更可靠，因为个人有荣誉和声誉。
- **结果**: 塔勒布作为交易员，优先与个人而非机构做交易——20年职业生涯中从未见过自雇交易员违约。

### 案例 2: 斯蒂格利茨的预测
- **问题**: 是否应该相信著名经济学家的公开预测？
- **方法论的使用**: 斯蒂格利茨（2008年危机前）大力支持房利美和房地美，危机后却宣称自己"早就警告过"。问题在于：他是否为自己的错误预测付出了代价？答案是否定的。
- **结论**: 没有切身利益的人，其言论不具有决策参考价值——无论其头衔多么显赫。
- **结果**: 塔勒布主张对公共预测者建立"预测记录档案"，并要求预测者以自己的资产/职位为预测做担保。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 看到专家/大V的预测或建议，想知道是否可信时
2. 评估合作伙伴、供应商、顾问的可靠性时
3. 自己在做决策，想检查是否将风险不当转移给他人时
4. 面试/雇佣中评估候选人的"ownership"意识时

### 语言信号 (用户的话里出现这些就应激活)

- "他说的可信吗？"
- "切身利益 / skin in the game"
- "谁承担后果"
- "代理问题 / agency"
- "专家意见"
- "这个承诺靠谱吗？"
- "风险转移"
- "他有没有拿自己的钱下注？"

### 与相邻 skill 的区分

- 与 `fat-tony-heuristic` 的区别: 胖子托尼识别脆弱性，切身利益识别可信度。两者可组合：先识别脆弱性，再检查脆弱性制造者是否有切身利益。
- 与 `iatrogenics-principle` 的区别: 医源性损伤关注"干预是否有害"，切身利益关注"谁承担伤害"。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别建议者/决策者**
   - 完成标准: 明确用户正在评估谁的建议或决策

2. **运行切身利益四问**
   - 完成标准: 逐一回答:
     - 如果他的判断失败，他会损失什么个人资产/声誉/职位/自由？（无→权重趋近于零）
     - 他的回报是否与长期结果绑定？（短期→权重降低）
     - 他是以机构身份还是个人身份发言？（机构→权重降低）
     - 他过去是否为自己的错误承担过后果？（否→权重降低）

3. **评估风险转移结构**
   - 完成标准: 判断是否存在"正面他赢，负面你输"的不对称结构
   - 判停条件: 若存在明显风险转移，建议用户拒绝或要求重新谈判利益绑定

4. **给出可信度评级**
   - 完成标准: 给出"高/中/低"可信度评级，并说明理由
   - 附带: 建议用户如何保护自己的利益（如要求对赌、要求担保、减少依赖）

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯技术/事实性问题（如编程语法、数学公式）——这些不涉及判断和承诺
- 需要保密的专业建议（如律师、医生在保密协议下的建议）——此时专业性约束替代了切身利益
- 艺术/审美判断——这些领域的主观性使得"切身利益"难以定义

### 作者在书中警告的失败模式

- **过度怀疑**: 将"没有切身利益"等同于"完全不可信"——实际上，很多学术研究即使没有切身利益，也有同行评审等替代机制
- **既得利益偏见**: 认为"有切身利益"就一定正确——实际上，有切身利益的人也可能因为沉没成本偏见而做出错误决策
- **机构污名化**: 完全拒绝所有机构建议——有些机构（如航空安全机构）确实建立了有效的责任机制

### 作者的盲点 / 时代局限

- 塔勒布对机构的批判有时过于笼统——现代公司治理中的"股权激励"、"对赌协议"等机制已经在尝试解决代理问题
- 在大型复杂项目中（如基建、航天），完全依赖"个人荣誉"不现实，需要制度化的风险管理

### 容易混淆的邻近方法论

- 与"利益冲突声明"的区别: 利益冲突声明只是披露，切身利益原则要求实际的后果承担
- 与"权威评估"的区别: 权威评估看头衔和资历，切身利益原则看风险承担
