# 凸性识别法 (Convexity Spotting)

## R — 原文 (Reading)

> "如果你拥有有利的不对称性，或正凸性（选择权是特例），从长远来看，你会做得相当不错，在不确定的情况下表现优于平均数。不确定性越强，可选择性的作用越大，你的表现就越好。"
>
> — 塔勒布, 第五卷第18章

---

## I — 方法论骨架 (Interpretation)

凸性识别法是一种收益结构分析框架：判断一个决策的收益曲线是凸性（有利的不对称）还是凹性（不利的不对称）。

- **凸性（Convex）**：损失有限且已知，收益理论上无限。波动越大，长期期望收益越高。图像像微笑的嘴角。
- **凹性（Concave）**：收益有限，损失理论上无限。波动越大，长期期望损失越大。图像像皱眉的眉心。
- **线性**：损失和收益对称。波动无影响（平均而言）。

核心数学直觉：对于凸函数，"函数的平均值 > 平均值的函数"。这意味着即使每次波动的方向和幅度不可预测，只要结构是凸的，波动本身就会带来净收益。

生活中的凸性例子：写作（时间成本固定，但爆款收益无限）、创业（投入有限，但成功可规模化）、学习（投入有限，但知识复利无限）。凹性例子：固定工资（收益有上限，失业损失无上限）、单一大客户依赖（收益固定，丢失客户损失巨大）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 石头实验
- **问题**: 为什么搬运1000块1磅的石头比搬运1块1000磅的石头更安全？
- **方法论的使用**: 搬运一块大石头是凹性的——单次失误（石头掉落）造成毁灭性伤害。搬运1000块小石头是凸性的——每次失误只造成小伤害，但完成任务的确定性更高。
- **结论**: 拆分大风险为多个小风险，将凹性结构转换为凸性结构。
- **结果**: 凸性结构在工程、金融、个人风险管理的广泛应用。

### 案例 2: 泰勒斯的期权
- **问题**: 泰勒斯如何通过橄榄油压榨机交易获利？
- **方法论的使用**: 泰勒斯购买的是"租用权"而非"义务"——凸性结构。如果橄榄歉收，损失=预付租金（有限）；如果丰收，收益=转租差价（无限）。
- **结论**: 期权是凸性的金融表达，生活中很多"非金融期权"具有相同结构。
- **结果**: 塔勒布将期权概念推广到职业选择、技术投资、创新策略等所有决策领域。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 评估一个商业模式/产品策略时
2. 选择职业路径（工资 vs 股权 vs 创业）时
3. 评估投资标的的收益结构时
4. 设计一个系统/流程，想判断其是否"波动友好"时

### 语言信号 (用户的话里出现这些就应激活)

- "凸性 / convexity"
- "不对称 / 波动友好"
- "收益曲线"
- "损失封顶 / upside"
- "凹性 / concavity"
- "几何级 / 指数级"

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **描述收益结构**
   - 完成标准: 明确该决策的"投入→结果"关系：如果成功会怎样？如果失败会怎样？

2. **运行凸性七问**
   - 完成标准: 逐一判断（"是"=凸性特征，"否"=凹性特征）:
     - 损失是否有已知上限？
     - 收益是否理论上无上限？
     - 波动是否增加长期期望收益？
     - 是否允许多次小试错而非一次大押注？
     - 时间是否增强该结构的价值？
     - 错误/失败的成本是否有限且可恢复？
     - 是否存在"赢者通吃"或"网络效应"的正向不对称？

3. **评分与定性**
   - 完成标准: 7个"是"=高度凸性（反脆弱）；5-6个=中等凸性；3-4个=接近线性；0-2个=高度凹性（脆弱）

4. **给出转换建议（如为凹性）**
   - 完成标准: 若凹性，建议如何通过保险/对冲/拆分/杠铃化来转换为凸性结构

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 日常消费决策（如买咖啡还是茶）——这些的凸性/凹性没有意义
- 已经确定为线性的对称博弈（如公平的硬币赌局）
- 涉及道德义务的决策（如赡养父母）——这些不能用凸性框架评估

### 作者在书中警告的失败模式

- **假凸性**: 看似损失有限，实际上存在隐藏的尾部风险（如"低风险投资"中的流动性陷阱）
- **凸性贪婪**: 过度追求凸性而忽视了执行质量和基础能力——凸性只在你"在场"时才有价值
- **尺度错误**: 对个人是凸性的选择（如创业），对家庭可能是凹性的（如用全部家庭储蓄创业）

### 作者的盲点 / 时代局限

- 塔勒布主要用连续函数的凸性概念，但生活中的很多决策是离散、阶段性的——需要更灵活的解读
- 凸性分析假设"可以无限次试错"，但现实中时间、精力、信誉都是有限的试错预算

### 容易混淆的邻近方法论

- 与"期望值计算"的区别: 期望值是对称的加权平均，凸性关注的是收益曲线的形状
- 与"风险调整收益"的区别: 风险调整收益假设风险可量化，凸性关注的是结构性的不对称
