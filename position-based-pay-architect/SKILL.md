# position-based-pay-architect

基于职位的薪酬管理体系设计：通过「以岗定级→以级定薪→人岗匹配→易岗易薪」四步闭环，结合HAY岗位评估与宽带薪酬，构建既公平又有竞争力的薪酬架构。

## 触发条件

当用户需要设计薪酬体系、岗位评估、职级体系搭建、宽带薪酬、任职资格、人岗匹配、易岗易薪、薪酬改革时激活。

**关键词**：薪酬体系 / 岗位评估 / 职级 / 宽带薪酬 / 任职资格 / 人岗匹配 / 易岗易薪 / HAY / 岗位价值 / 薪酬改革 / 定岗定级定薪

## 使用说明

### 第一步：以岗定级 — HAY三维度八要素法

对每一个职位进行系统评估，建立职位职级对照表。

**三维度**：
1. **知识技能**（Know-How）：管理技巧、人际能力、专业知识
2. **解决问题能力**（Problem Solving）：思维环境、思维难度
3. **岗位责任**（Accountability）：岗位责任、对结果的作用、行动自由度

**八要素等级定义**（摘自第20章）：
- 管理技巧：起码的→相关的→多样的→广博的→全面的（5级）
- 人际能力：基本的→重要的→关键的（3级）
- 专业知识：基本教育→初等→中等→高等→基本专业→熟练专业→精通专业→权威专业（8级）
- 思维环境：高度常规→常规→半常规→标准化→明确规定→广泛规定→一般规定→抽象规定（8级）
- 思维难度：重复性→模式化→中间性→适应化→无先例（5级）
- 岗位责任：微小的→少量的→中等的→大量的（4级）
- 对结果的作用：后勤→辅助咨询→分摊→主要（4级）
- 行动自由度：有规定→受控制→标准化→一般规范→有指导→方向性指导→广泛指引→战略性指引→仅有一般性/无指引（9级）

**STOP检查点**：
- [ ] 是否由专业委员会/行政管理团队集体评分，而非单人决定？
- [ ] 管理类/技术类/营销类/专业类/操作类是否设置了不同的维度权重？
- [ ] 是否建立了12-23级的职位职级对照表？

### 第二步：以级定薪 — 宽带薪酬体系

为每一职级设定C/B/A三档薪酬区间，形成宽带薪酬表。

**华为参考区间**（2010年标准岗位工资，第20章/第19章）：
- 13级：5,500 / 6,500 / 7,500
- 14级：7,500 / 9,000 / 10,500
- 15级：10,500 / 12,500 / 14,500
- 16级：14,500 / 17,000 / 19,500
- 17级：19,500 / 22,500 / 25,500
- 18级：25,500 / 29,000 / 32,500
- 19级：32,500 / 36,500 / 40,500
- 20级：40,500 / 44,500 / 49,500
- 21级：49,500 / 54,500 / 59,500
- 22级：59,500 / — / —

**设计原则**（第20章）：
- 基层职位：与当地同行同业市场持平
- 中层职位：略高于市场一定比例
- 高层职位：参考全球同行同业市场水准
- 宽带设计允许同职级内根据绩效调薪，无需晋升也能涨薪

**STOP检查点**：
- [ ] 是否做了外部薪酬调查？
- [ ] 是否确保绩效前20%员工薪酬高于市场平均？
- [ ] 宽带区间是否足够宽（通常50%-100%）以容纳绩效差异？

### 第三步：人岗匹配 — 任职资格体系

评估员工与职位要求的匹配度，确定个人职级。

**任职资格标准三要素**（第20章，英国NVQ体系）：
1. **基本条件**：现从事职位、专业经验（非工龄，而是关键事件）、最近一年绩效
2. **核心标准**（至少选一种）：
   - 必备知识（业务理论、公司制度流程）
   - 技能（通用技能、专业技能、工具技术）
   - 行为（成功关键工作行为）
   - 素质（素质模型或岗位说明中的素质要求）
3. **参考项**：品德（关键事件支撑）、个性特征（岗位配置参考）

**三族分离**（2017年任正非讲话，第20章）：
- **职员族**：确定性问题的合理化管理，当地招聘当地使用，不参加循环流动，绝对考核
- **专家族**：参加循环作战（纵向/横向/跨领域循环），持续考核贡献增值
- **管理族**：末位淘汰，每年必须淘汰一部分到战略预备队，找不到岗位则降职降薪

**STOP检查点**：
- [ ] 是否区分了三族并设置了差异化考核方式？
- [ ] 专家族是否有循环成长机制？
- [ ] 管理族是否有能上能下的通道？

### 第四步：易岗易薪 — 薪酬随职位能升能降

**晋升调薪规则**：
- 若当前薪酬已达/超过新岗位下限：可不变或提升
- 若未达新岗位下限：调整至下限，绩效好可调至下限以上

**降级调薪规则**：
- 若降级前薪酬高于新岗位上限：必须降至上限或以下

**任正非要求**（第20章）：
- 职位重量是不断变化的，需要循环认证岗位重量
- 在关键责任岗位（新产业、新市场、扭转劣势）采取弹性定级
- 大胆破格提拔业绩突出人员，打破平衡→再造平衡

**STOP检查点**：
- [ ] 是否有明确的晋升/降级薪酬调整规则？
- [ ] 是否建立了内部人才市场支持横向换岗？
- [ ] 老员工申请低级别岗位时，氛围是否正常化而非负面看待？

## Anti-Example Blacklist

❌ **不要把学历、工龄、社会职称作为定薪依据** — 华为明确："员工的学历、工龄、社会支撑等不作为其工资确定的因素"（第20章）。

❌ **不要让岗位评估一劳永逸** — 任正非要求循环认证岗位重量，岗位重量随业务变化而变化。

❌ **不要把专家职级定得比行政主管低** — 合理提升一线业务专家岗位职级，专家的职级不一定要比行政主管低。

❌ **不要让职员参加末位淘汰** — 职员族走绝对考核道路，不需要末位淘汰，主管对命令承担决策责任，职员对执行符合度承担责任。
