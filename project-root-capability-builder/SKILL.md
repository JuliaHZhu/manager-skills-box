# project-root-capability-builder

当用户需要构建组织级项目管理体系、提升项目管理价值、或讨论"项目管理如何成为企业根能力"时激活。

适用于：企业级PMO建设、项目管理体系升级、项目经理群体能力培养、数字化转型中的项目管理赋能、项目CEO文化塑造。

不适用于：单一项目的技术执行问题、无需组织级支撑的个人项目管理、没有项目管理成熟度基础的初创团队。

关键 trigger：项目管理根能力 / 项目管理体系 / PMO / 项目CEO / 价值交付 / 降解思维 / 四个一 / 一体两翼 / 项目管理之道 / 项目治理。

## 核心理念：项目管理是华为的根能力

华为项目管理经历了四代演进：
- **1.0**：成立PMO，发布项目管理流程，形成专业交付管理能力。
- **2.0**：从以功能为中心向以项目为中心转变，建立企业级项目管理文化和制度。
- **3.0**：构建数字化项目管理体系（ISDP），业务可视、可管、可控，项目经理向项目CEO转变。
- **4.0**：项目经理成为商业精英，驱动项目管理产业化发展，能力外溢变现。

### 一、价值交付正循环

项目管理始终围绕**发现价值 → 定义价值 → 创造价值 → 分享价值**的循环，构建为客户服务、实现客户商业成功的正循环，同时实现企业自身的商业价值正循环。

**超越铁三角**：不仅要满足进度、成本、质量，更要看是否实现了客户的商业价值、企业的商业价值。最终实现**商业价值闭环**。

### 二、降解思维：从分解到降解

- **分解（Decomposition）**：物理分解，假设项目确定，便于专业分工。WBS是物理组合。
- **降解（Degradation）**：面对复杂、模糊、迭代的问题，直接物理分解难以奏效。
  - **升维思考**：宏观视角，看到系统整体结构和趋势。
  - **封装收敛**：在升维基础上进行抽象和收敛。
  - **降维打击**：从升维到降维的过程就是降解。
  - **化学融合 > 物理组合**：更加逼近第一性原理，更有效实现项目价值。

**应用**：在VUCA时代，市场机会和客户需求模糊易变，需要发掘底层相对稳定的客户价值需求，看整个系统而非个体，考虑关联关系而非单纯因果，通过降解而非分解来解决问题。

### 三、项目CEO的HEROS模型

项目CEO不只是协调员或执行指挥员，而是要有责任心和使命感，承担对外代表企业、对内代表客户的价值创造责任。

**HEROS**：
- **H（Head）**：项目团队的领导者
- **E（Environment）**：项目合作生态管理者
- **R（Responsibility）**：项目经营、质量和客户满意的责任者
- **O（Operation）**：项目端到端的运营者
- **S（Strategy & Solution）**：客户商业成功的整合者

**核心理念**："像老板一样思考"。在集体主义下的个人英雄主义，鼓励项目CEO带领团队赢得一个又一个胜利。

### 四、PMO作为项目CEO的"娘家人"

在项目CEO时代，PMO的角色转变：
1. **护航者**：确保以项目为中心模式的落地和夯实。大家遇到问题时可以来PMO求助。
2. **赋能者**：能力上有不足时可以来PMO充电。
3. **治理者**：监控所有项目进展，通过大数据分析主动发现项目风险，提供健康运行指导，主动给全球项目提供炮火支援。

### 五、项目治理的四道防线

1. **极简并合适的流程体系**：能力被流程灵活调用，组织分工明确，执行有力而敏捷。
2. **正确的决策、合适的授权、严格的监控**：通过确定的机制和规则应对不确定性。
3. **数字化增加透明度和敏感性**：让聪明的数据发挥提醒和告警作用。
4. **人才队伍建设**：前线作战的项目经理能力高低决定项目风险大小。

### 六、项目管理体系"一体两翼"与"四个一"

**一体两翼**：
- **一体**：文化体系 + 管控/流程/平台工具的治理体系
- **两翼**：方法 + 资源

**四个一**：
- 一组治理规章
- 一套流程方法
- 一个集成平台
- 一支优秀队伍

## 使用流程

1. **评估代际**：当前组织的项目管理处于1.0-4.0的哪个阶段？
2. **识别短板**：是缺流程（1.0）、缺文化/制度（2.0）、缺数字化平台（3.0）、还是缺商业变现能力（4.0）？
3. **选择杠杆点**：资源有限时，优先投入"四个一"中最缺的1-2个。
4. **建设PMO定位**：根据组织成熟度，确定PMO当前应扮演"管控者"还是"赋能者"还是"治理者"。
5. **推动项目CEO文化**：从选拔一个试点项目CEO开始，用HEROS模型评估其能力提升方向。
