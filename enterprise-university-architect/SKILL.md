# enterprise-university-architect

## When to Activate

Trigger when the user mentions:
- 企业大学 / corporate university / enterprise academy
- 培训中心的转型 / training center transformation
- 培训自运营 / self-sustaining training organization
- 获取分享制 / revenue-sharing / charge-back model
- 培训预算独立核算 / training budget autonomy
- 华为大学模式 / Huawei University model

## Core Principle: From Cost Center to Strategic Engine

华为大学的核心定位转变：

| Stage | Role | Funding |
|---|---|---|
| **培训中心** | HR下属职能部门 | 公司拨款 |
| **企业大学** | 战略伙伴、使能器 | 内部有偿服务、收支平衡 |

> "大学要从人力资源部的框架里跳出来，聚焦到战略当中去。" — 任正非

## When to Build a Corporate University

**1998年华为为什么不建大学？**
1. 管理变革刚起步，成熟的管理方式/工具/理念尚未形成
2. 战略是“活下去”，使命愿景不清晰
3. 不知道怎么建——战略、业务运作、组织架构、能力、资源五层未澄清

**2005年为什么可以建了？**
- 从国际化向跨国化转变，战略方向清晰
- 业务成熟，需要系统化人才供给
- 组织能力建设到了新阶段

**自检清单**：你的企业是否 ready？
- [ ] 业务方向基本定型，有明确的使命、愿景、价值观
- [ ] 有成熟或相对成熟的管理方式、工具、理念
- [ ] 培训需求大到需要专职组织承载
- [ ] 有最高层（如CEO）直接支持的资源投入

## The Self-Sustaining Model: 获取分享制

华为大学作为**轻装子公司**，独立核算、有偿服务、收支平衡。

### Why Charge Internal Customers?

1. **防止无偿浪费**：业务部门不花钱就不珍惜，学习不认真
2. **摆脱预算束缚**：不向公司要预算，超预算业务不被限制；赚得多=资源多=能力更强
3. **用市场机制检验价值**：如果培训真有价值，各部门愿意出钱；没价值就自然淘汰

### Revenue Cycle

```
业务部门提出需求 → 华大设计项目 → 报价收费 → 
交付培训 → 效果验证 → 口碑扩散 → 更多部门付费 → 
收入增加 → 提升教学能力 → 更受欢迎 → (正循环)
```

## Faculty Architecture: Part-Time First

### 讲师梯队三来源

| Source | Role | Why |
|---|---|---|
| **业务专家（主力）** | 兼职讲师，讲授实战经验 | 离业务最近，内容最具实战性 |
| **退休专家** | 传承经验、思想引导 | 解决老员工人数有限的问题 |
| **外部权威** | 前沿理论、跨界视野 | 保证站在最新技术/管理前沿 |

### 四级讲师等级与激励

- 等级与授课费挂钩（最高可达18000元/天）
- **版权激励**：讲义有著作权，改版须注明引用，成为个人影响证明
- **先有鸡还是先有蛋**：先给激励，再吸引优秀讲师；不要怕初期讲师差，差的也奖，才能建立信任

> "人最优秀的是哪段你就输出哪段。兼职教师是在人生最好的时刻来给学生讲课。" — 任正非

## Curriculum Architecture

华为大学四大核心能力系 + 共享平台：

| 能力系 | 培养内容 | 目标人群 |
|---|---|---|
| **管理能力系** | 领导力、管理哲学、文化研讨 | 中高层管理者 |
| **专业能力系** | 技术、销售、财务等专业技能 | 专业岗位员工 |
| **项目管理系** | 项目管理全流程、端到端经营 | 项目经理、储备干部 |
| **新员工培训系** | 文化融入、基础技能、价值观 | 新入职员工 |

### 核心能力输出机制

1. **选拔制**：所有进入华大培训的人都是选拔出来的，不是随便送的
2. **以优秀培养更优秀**：只有业务最优秀的员工才能当兼职讲师
3. **训战结合**：学到的技能与部门工作无缝连接
4. **网络覆盖**：在线平台覆盖全球每一个办事处
5. **有偿服务**：收支平衡，无依赖压力传递激活组织

## Governance Structure

- **指导委员会**：任正非任指导员，三个轮值CEO任委员，半年开一次会
- **需求-供给关系**：片联（代表业务需求）→ 华大（供给培训）
- **人才推荐体系**：华大向片联推荐1/3优秀学员，组合上前线打仗

## Implementation Checklist

- [ ] 判断企业是否 ready（战略清晰度、管理成熟度、高层支持）
- [ ] 明确大学使命（传承文化？提升业务能力？知识管理？）
- [ ] 设计组织架构（需求分析 → 课程开发 → 交付 → 评估）
- [ ] 建立有偿服务/内部收费机制
- [ ] 组建筹建团队（未来管理者从筹建期就进入）
- [ ] 搭建兼职讲师队伍与激励体系
- [ ] 建立与业务部门的强合作关系（人员流通、需求对接）
- [ ] 设计效果评估与口碑扩散机制

## Anti-Patterns

| Anti-Pattern | Why It Fails |
|---|---|
| 过早建立（战略未清） | 大学定位模糊，变成高级培训中心 |
| 纯成本中心、靠公司拨款 | 业务部门不珍惜，培训沦为福利 |
| 追求专职讲师队伍 | 脱离业务，内容过时 |
| 照搬高校模式（终身制、学历导向） | 企业大学不是清华北大，目标是实战 |
| 课程从市场热门找 | 与业务需求脱节，学而无用 |

## Example Interaction

**User**: 我们培训中心做了5年了，一直被当成成本中心，老板想升级为企业大学，怎么搞？

**Skill Response**:
> 升级的关键不是改名字，而是改**定位 + 机制**。
>
> **第一步：定位升级**
> - 从“HR下属的培训执行者”变为“业务战略的使能器”
> - 重新定义使命：传承文化、提升业务能力、知识管理（三选一或组合）
>
> **第二步：机制改造 — 获取分享制**
> - 华大向业务部门收费，独立核算
> - 收费不是目的，目的是用市场机制筛选有价值的培训
> - 业务部门有钱→愿意买→证明有价值→华大收入增加→提升能力→更受欢迎
>
> **第三步：师资改造**
> - 停止招聘专职讲师讲业务课
> - 建立兼职讲师池：让当前业务最优秀的20%员工轮值授课
> - 授课与晋升/荣誉挂钩
>
> **第四步：效果闭环**
> - 向业务部门推荐优秀学员上前线
> - 学员打胜仗=华大口碑=更多部门愿意付费
>
> **时间线建议**：机制改造（3个月）→ 试点收费（6个月）→ 全面推广（12个月）
