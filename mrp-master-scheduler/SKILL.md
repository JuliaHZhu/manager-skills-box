# mrp-master-scheduler

## Metadata
- **Version**: 1.0.0
- **Author**: Cangjie distillation from 《华为管理手册（5版）——计划手册》
- **Trigger**: MRP排产 / 主生产计划 / MPS调整 / 物料需求计划 / 缺料 / 急单 / 版本切换 / 计划百分比

## Purpose
基于MDS-MPS-MRP三层计划架构，指导用户完成从需求汇总到采购/加工计划下达的完整排产流程，重点解决主生产计划调整、版本切换控制、例外信息处理和预缺料管理。

## When to Use
- 需要制定月度/周度生产计划和采购计划时
- 主生产计划结果偏大/偏小需要调整时
- 遇到版本切换、新产品转产、老产品退市时
- 系统跑出大量例外信息（提前/推迟/取消）需要处理时
- 出现预缺料或急单需要拉动采购到货时
- 需要处理研发需求、内部需求对量产计划的冲击时

## STOP Checkpoints
- [ ] 是否已确认MDS中销售订单、预测、内部需求装载正确？
- [ ] 是否已检查计划百分比和计划属性的准确性？
- [ ] 当前调整是否基于最新的BOM和库存数据？

## Inputs
- 销售订单、市场要货预测、内部需求计划
- BOM清单、项目计划属性、计划百分比
- 库存数据、在途PO、在制量
- 版本切换方案、ECO信息

## Outputs
- 主需求计划(MDS)、主生产计划(MPS)、物料需求计划(MRP)
- 加工计划（周任务令）、采购计划（PR/预测）
- 例外信息处理清单、预缺料报告

## Procedure

### 阶段一：MDS装载与检查
1. **预测准备**：录入市场要货预测（按天均匀分布），设置冲减标识为"否"。
2. **装载MDS**：先加载销售订单（覆盖所有记录），再加载预测（不覆盖），最后加载内部需求（不覆盖）。
3. **预测冲减**：整机冲减（订单冲整机预测，适合SDH类）或分解冲减（订单冲半成品预测，适合CC/GSM类）。
4. **检查MDS**：提取MDS报表，抽查订单/预测/内部需求是否装载完整；调整冲减后剩余预测。

### 阶段二：MPS排产与调整
1. **排产MPS**：基于MDS运行MPS，设置计划参数（计划选项/申请标识符）。
2. **调整原则**：
   - 整机和功能模块看要货计划；总装机柜看出库+百分比；母板插框看功能模块百分比。
   - 结果偏大：查MDS需求来源，若是预测则检查百分比；若是内部需求则核对需求量。
   - 结果偏小：检查订单冲减或需求时间栏是否隔掉预测。
3. **版本切换控制**：
   - **平滑切换**（老版本有需求）：按最贵专用物料库存+在制确定切换量，齐套配套器件。
   - **定时切换**（老版本无需求）：按未来需求配套，库存+在制>需求则取消在途，<需求则增补。
   - **并行期**：重叠量10-20%，并行2-3个月（旧版100%→80%→0%，新版10%→40%→100%）。
4. **特殊事项**：制造件改采购件需维持过渡期MPS属性；临时市场需求调整需同步调整配套器件MPS。

### 阶段三：MRP排产与调整
1. **排产MRP**：基于调整后的MPS运行MRP，选择"所有计划项目"。
2. **加工计划调整**：
   - 删除机柜、资料等不下任务令的项目，保留单板和电缆。
   - 依据库存、在制、要货评审需求、安全库存、提前期、产能调整为可执行周计划。
   - 急单立即释放任务令；检查制成板-成品板加工数量和日期合理性。
3. **采购计划调整**：
   - 删除假需求、版本切换造成的急单。
   - 真实急单：立即下达，通知采购争取最快到货。
   - 其他组织有库存：先协商转库。
   - 控制器件替代、归一化、ECO切换的物料衔接。
   - 金额大的物料需上级批准。
4. **例外信息处理**：
   - **提前**：两周内不处理；2-3个月且提前≤7天不处理；3个月后不处理。
   - **推迟**：按金额排序，只处理占金额80%以上的；原到货日期4个月后暂不处理；推迟≤15天不处理。
   - **取消**：逐项确认，鉴别真伪；版本切换/ECO引起的可随时处理。
5. **预缺料处理**：提取未来两周毛需求 → 对比库存+在途+其他组织库存 → 运行预缺料 → 调整（排除MPS错误/版本切换/基础数据问题/百分比问题/替代/转库）→ 导入系统 → 跟踪采购回复。

### 阶段四：采购预测制定
1. **一般物料**：每月18日前排产"净采购=否"的MRP，结果经调整后作为采购预测。
2. **结构件/电缆/JIT/POC**：参考库存计划方法，根据历史出库+要货趋势制定3个月预测。
3. **配额物料**：货期内按现有PO；货期外需求≥配额按需求，需求<配额按1.5倍需求与配额较大者。

## Key Principles
- MPS是"承上启下"的手工控制层，计划员必须干预，不能全信系统。
- 计划百分比是计划工作的"基础中的基础"，偏差会指数级放大。
- 版本切换的核心是"减少呆死料+保证新版本顺利衔接"。
- 例外信息处理要"有重点、有梯度"，不能全盘接受系统建议。
- 预缺料是"拉动式补货"的关键工具，必须及时准确。

## Failure Modes
| 症状 | 可能原因 | 对策 |
|------|----------|------|
| MRP结果全部偏大 | 计划百分比过大/内部需求重复装载/预测未冲减干净 | 检查百分比；确认内部需求是否已核销；重新冲减预测 |
| 大量急单 | 假需求/版本切换/百分比过大/任务令提前下达/大量领料 | 删除假需求；控制版本切换；修正百分比；规范领料流程 |
| 专用物料积压 | 版本切换未控制老版本专用物料/计划百分比未调整 | 按库存+在制定切换量；及时维护停产项目属性为特殊标识 |
| 预缺料不准确 | MPS错误/基础数据不准/库存数据滞后/未考虑替代物料 | 核查MPS；检查BOM和库存；确认替代关系 |
