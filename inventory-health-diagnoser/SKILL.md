# 库存健康诊断与结构优化

## R — 原文 (Reading)

> 库存分析与控制是计划人员的重要工作，探索与总结库存分析与控制方法是提高计划业务水平的重要途径。通过库存分析，将物料按不同的类别进行分析与控制，依据供需形势的准确判断，充分发掘它们不同的生产特点/器件采购特点，进行计划细分，采取恰当的计划策略、生产策略、采购策略，实现公司经营的目标。
>
> — 华为计划手册, 3.2 库存分析

> 死料就是没有用途、要报废的物料。华为的死料定义为：库存项目在当前计划期内需求为零，并且在公司范围内没有最终用途的物料。低周转物料就是周转频次低于正常物料的那部分库存。华为的定义为：库存大于6个月需求的物料或周转率小于1次/年的物料。
>
> — 华为计划手册, 3.2.2

## I — 方法论骨架 (Interpretation)

库存健康诊断是一套从结构、周转、根因到处置的闭环方法。核心逻辑是：先通过库存周转率和结构比例判断整体健康度，再细分到不良库存的根因类别，最后对不同性质的库存采取差异化处置策略。

关键公式：
- 库存周转率 = 发货(成本) / 平均库存 × (365 / 统计天数) （次/年）
- 合理库存结构比例：原材料 : 半成品 : 成品 = (1 - V×{B+C+A×[D+E]}/365) : V×A×[D+E]/365 : V×[B+C]/365
  （其中A为非原材料占发货成本比例，B为调测周期，C为理货周期，D为半成品补货提前期，E为加工周期，V为库存周转率）

不良库存六大根因：市场预测偏差、版本切换、结构性偏差、试产批量失控、备件返回偏差、储备计划失当。处置手段按金额分级：转库（<20万一次性）、内部订单（≥20万分批）、替代消耗、报废。

## A1 — 书中的应用 (Past Application)

### 案例 1: 传输产品2000年第五期低周转物料分析
- **问题**: 传输产品低周转物料、死料总计168项，总金额321.53万元
- **方法论的使用**: 按形成原因分类统计（计划/技术/认证采购/BOM/商务/其他），识别版本切换和ECO更改占78.8%（253.43万元）
- **结论**: 技术原因（版本切换+ECO）是低周转主因，计划原因仅占16.9%
- **结果**: 通过转库、替代、转待处理品等方式处置31项48.96万元，为后续版本切换管理改进提供数据依据

### 案例 2: 网络产品2001年库存控制
- **问题**: 网络产品库存从2000年8月起持续增长
- **方法论的使用**: 建立每日库存监控表，按产品监控原材料/半成品/在途PO/在制；实施用户框单板计划细分、智能网按项目方式运作、加强储备计划审核
- **结论**: 库存控制最重要的是领导支持，所有做法都可能有负面风险
- **结果**: 库存从4月开始持续下降，周转率稳定在5.5-6.5次，智能网累积周转率达9.1次

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 库存总额持续增长，需要判断是合理增长还是结构性恶化
2. 发现大量物料长期未动，需要区分死料、低周转和正常安全库存
3. 版本切换或产品换代后，老版本物料形成积压，需要清理策略
4. 要货计划频繁偏差，想知道对库存周转率的具体量化影响
5. 需要向管理层汇报库存健康度，需要结构化的诊断框架和指标

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **收集库存基础数据**
   - 完成标准: 获取原材料库存、半成品库存、半成品在制、成品库存及在制、发货成本（按月度）
   - 数据来源: ERP/MRPII系统、财务存货报表

2. **计算库存周转率与结构比例**
   - 完成标准: 算出年度/月度库存周转率，对比理论合理结构比例（原材料:半成品:成品）
   - 关键公式: 周转率 = 发货成本 / 平均库存 × (365/统计天数)；结构比例按书中公式1推算
   - 判停条件: 若周转率达标且结构比例正常，跳到步骤5给出维持建议

3. **不良库存根因分析**
   - 完成标准: 对超出合理值的库存按六大根因分类（市场预测偏差、版本切换、结构性偏差、试产批量、备件返回、储备计划/技术问题/提前期/计划百分比）
   - 操作方法: 对A/B类高金额物料逐一追溯入库时间、计划来源、版本切换记录、ECO记录

4. **死料与低周转物料清单确认**
   - 完成标准: 列出死料（当前计划期需求为零且无最终用途）和低周转（库存>6个月需求或周转率<1次/年）清单，标注金额和形成原因

5. **制定处置方案**
   - 完成标准: 按金额分级给出处置路径
   - 处置路径:
     - 单项<20万且接收方不形成低周转: 一次性转库
     - 单项≥20万: 内部订单分批转库（每次半个月用量）
     - 有替代可能: 发起替代评审
     - 无用途: 转待处理品中心报废

6. **输出库存健康诊断报告**
   - 完成标准: 包含周转率现状、结构对比、不良库存根因分布、处置计划、责任部门和时间表

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯零售业无BOM结构的商品库存分析（需要不同的SKU管理逻辑）
- 已经实施纯拉动式生产且供应链响应时间极短的场景（如部分汽车JIT）
- 服务业无形资产/数字产品的"库存"概念不适用

### 作者在书中警告的失败模式

- 刻意追求高周转率而忽视缺货风险："库存周转率的提高意味着缺货风险增大，或因小批量采购导致采购成本增加。一些企业所犯管理错误，是对库存周转率指标的刻意追求。"
- 只处理现有库存而不监控PO："发现了死料与低周转物料，仅对现有的生产库存进行处理是不够的。还需要审视其他环节的库存情况，同时需要对PO进行监控。"
- 多库存组织分开运作加大处理难度：需要跨组织协调，避免"组织拆分"成为低周转的新原因

### 作者的盲点 / 时代局限

- 基于MRPII/Oracle ERP时代的库存管理，对现代云原生供应链系统（如实时IoT库存、AI预测补货）的兼容性未涉及
- 主要面向通信设备制造业，多品种小批量特征明显；对流程工业或大规模标准化生产的适用性需调整

### 容易混淆的邻近方法论

- ABC分类 vs 计划ABC/仓储ABC：计划ABC按需求金额分类控制订货点，仓储ABC按单价分类控制盘点频率，二者目的不同但常混用
- 安全库存 vs 储备库存：安全库存防需求波动，储备库存防供应风险（独家供应商、长货期、停产），管理逻辑不同
