# inventory-plan-controller

## Metadata
- **Version**: 1.0.0
- **Author**: Cangjie distillation from 《华为管理手册（5版）——计划手册》
- **Trigger**: 库存计划 / 库存控制 / 最小最大值 / ABC分类 / 死料 / 低周转 / 缺料 / 物控 / 日清日结

## Purpose
指导用户通过最小-最大值库存计划、ABC分类管理、死料/低周转分析、缺料解决和日清日结等手段，实现库存水平合理、结构健康、周转高效。

## When to Use
- 需要为低值/稳定消耗物料制定库存计划时
- 库存水平过高或出现大量呆死料时
- 需要建立ABC分类体系和固定供应天数时
- 出现缺料影响生产/发货时
- 需要优化库存结构、提高周转率时
- 需要建立物控日常作业规范时

## STOP Checkpoints
- [ ] 当前库存数据是否准确（含在途、在制）？
- [ ] 历史出库数据是否已统计并分析趋势？
- [ ] 是否已识别出真正的死料（无未来需求）？

## Inputs
- 历史出库数据（至少3-6个月）
- 库存台账、在途PO、在制量
- 要货计划/销售预测
- 物料单价、采购提前期、最小采购批量

## Outputs
- 最小-最大值参数表
- ABC分类与固定供应天数方案
- 死料/低周转物料处理清单
- 缺料解决方案
- 日清日结记录

## Procedure

### 阶段一：ABC分类与固定供应天数设定
1. **数据准备**：统计各物料过去3-6个月毛需求总金额。
2. **ABC分类**：
   - A类：占总物料种类5-10%，占总金额80% → 固定供应天数6天
   - B类：占总物料种类10-15%，占总金额10-15% → 固定供应天数11天
   - C类：占总物料种类80%，占总金额5-10% → 固定供应天数22天
3. **修正因素**：考虑物料单价、体积、货期、供应商数量、独家供应等因素调整。已实现JIT到货或金额/体积特别大的A类物料可设为<6天。
4. **定期复核**：每季度根据出库变化重新分类。

### 阶段二：最小-最大值库存计划
1. **适用物料**：需求连续、消耗稳定、价值较低的物料（螺钉螺母等）；未做进BOM或BOM不准确的物料。
2. **参数设置**：
   - 最小值 = 安全库存量 + 采购提前期 × 日平均消耗量（安全库存一般取半个月消耗量）
   - 最大值：在满足最小采购批量前提下设定的库存上限，需防止积压。
3. **计划逻辑**：库存低于最小值时，采购至最大值。购买量 = 最大值 - 现有库存 - 未来某段时间合同未到货 + 未来某段时间销售订单需求。
4. **定期维护**：根据需求波动、采购到货、库存消耗情况定期调整最小-最大值。
5. **采购批量**：低值物料可批量放大、库存放松，减少监控成本；高值物料严格控制批量。

### 阶段三：死料与低周转物料分析处理
1. **死料识别**：统计库存>6个月无出库，且确认无未来需求的物料。
2. **低周转识别**：周转率低于设定阈值（如年周转<2次）的物料。
3. **原因分析**：
   - 计划百分比偏大/未及时调整
   - 版本切换/ECO更改导致旧物料不再使用
   - 内部需求错误/编码错误
   - 预测不准/要货计划波动
4. **处理措施**：
   - 与供应商协商退换货
   - 转作维修备件
   - 跨组织调拨
   - 拍卖/变卖/报废
   - 对ECO替换物料：与供应商协商换成新编码物料
5. **预防**：及时维护停产项目计划属性为特殊标识（如"useless"）；ECO生效前评估库存影响。

### 阶段四：缺料解决
1. **缺料识别**：现有库存+在途<未来生产需求（通常看2周）。
2. **解决路径**：
   - 紧急采购/催货（正常货期<2/3为急单）
   - 跨组织调拨（查询其他组织库存）
   - 替代物料（确认替代关系和技术可行性）
   - 生产计划调整（推迟加工/调整优先级）
   - 客户沟通（协商交期）
3. **缺料跟踪**：建立缺料台账，日跟踪到货进度，到货后及时核销。

### 阶段五：物控日常作业（日清日结）
1. **存货出库控制**：按任务令/订单发料，控制杂项领料，及时核销。
2. **来料质量控制**：IQC检验不合格物料组织MRB会议，紧急情况下多方共同决定。
3. **加工策略调整**：根据缺料/产能/优先级调整加工顺序。
4. **发货策略调整**：根据ATP能力调整发货优先级。
5. **日清日结**：每日清理单据、核对账实、处理异常，做到"今日事今日毕"。

## Key Principles
- 库存管理的最高境界是"以信息代替库存"。
- 高库存掩盖管理低效，降低库存才能暴露问题。
- ABC分类的目的是"区别对待"，把管理精力放在A类物料上。
- 库存计划方法对未来需求敏感性低，必须定期维护参数。
- 死料处理要快，时间越长价值损失越大。

## Failure Modes
| 症状 | 可能原因 | 对策 |
|------|----------|------|
| 库存计划项目频繁欠料 | 最小值设置过低/需求突然增长未及时调整 | 提高安全库存；缩短参数维护周期；建立需求预警 |
| 库存计划项目严重积压 | 最大值设置过高/需求下降未及时调整/ECO未同步 | 降低最大值；及时调整参数；ECO时同步调整库存计划 |
| A类物料库存失控 | ABC分类未定期更新/固定供应天数未按实际情况调整 | 每月复核ABC分类；考虑单价/体积/货期调整供应天数 |
| 缺料反复出现 | 提前期不准/安全库存不足/需求波动大 | 核实并修正提前期；提高安全库存；建立供应商备货机制 |
