# award-culture-designer

仪式感激励与发奖文化：将发奖视为生产力和战斗力，通过多样化的奖项设计、零奖金承诺与领导者的自我激励，构建「让奋斗者被看见」的组织氛围。

## 触发条件

当用户讨论发奖、仪式感、激励文化、零奖金、年终评优、表彰大会、企业文化、非物质激励时激活。

**关键词**：发奖 / 仪式感 / 激励文化 / 零奖金 / 评优 / 表彰 / 企业文化 / 非物质激励 / 荣誉 / 奖项设计

## 使用说明

### 核心一：发奖是生产力，也是战斗力

**任正非观点**（第13章小结）：
> "发奖是生产力，发奖也是战斗力；仪式感是管理要素，仪式感也是管理举措，从而可以让个体性'一枝先秀'的榜样引导出群体性'百花齐放'的奋进。"

**发奖三原则**：
1. **奖励及荣誉是重大激励手段**：在任何组织中，发奖及荣誉不是个小事情，是门大学问，此事重大，千万不可小觑。
2. **奖励需要创新与拿来主义**：如果不知道如何创新，那就静下心来，谦卑地向领先者学习，如军队，如华为。
3. **仪式感引导群体性奋进**：让个体的"一枝先秀"引导出群体的"百花齐放"。

**STOP检查点**：
- [ ] 公司是否把发奖当作"顺便做个奖状"的应付行为？
- [ ] 奖项设置是否多年不变，员工已经无感？
- [ ] 颁奖仪式是否足够正式，让获奖者感到被尊重？

### 核心二：零奖金承诺 — 用仪式感强化规则刚性

**华为案例**（第13.5节）：
- 2013年市场大会上，未达到底线目标的团队负责人践行"不达底线目标，团队负责人零奖金"的承诺
- 轮值CEO郭平、胡厚崑、徐直军，CFO孟晚舟，片联总裁李杰，以及任正非和孙亚芳，七位拿到"零奖金"
- 零奖金者获得伴手礼：任正非亲自参与设计的"航母起航"飞机模型，由巴黎造币厂制作，命名为"英雄万岁"

**应用要点**：
- 零奖金不是羞辱，而是规则的刚性执行
- 用高仪式感的"象征物"替代现金，既表达了规则不可妥协，又保留了对奋斗者的尊重
- 领导者必须带头执行，包括最高层

**STOP检查点**：
- [ ] 是否有明确的底线目标？未达成时负责人是否真的零奖金？
- [ ] 零奖金是否只针对基层，而高层网开一面？
- [ ] 是否有替代性的高仪式感象征物，让"零奖金"不变成纯粹的惩罚？

### 核心三：奖项多样化 — 让不同的人被看见

**华为特色奖项**（第13章）：
- **"市场部集体大辞职"奖**：纪念1996年市场部集体大辞职，颁发金质纪念牌。这不是奖励业绩，而是奖励对组织变革的勇气。
- **"蓝血十杰"奖**：华为管理体系建设的最高荣誉奖。获奖者有在职员工、离职员工、咨询公司顾问。2014年首届表彰大会邀请国内媒体观摩，会后任正非首次接受国内媒体集体采访。
- **家属奖**：为华为人的家属发奖，任正非亲自颁奖。认可员工家属对组织的间接贡献。
- **"明日之星"奖**：2016年初任正非等高层领导没被评为明日之星，自制奖牌自己给自己评了一个，并手举奖牌合影留念。

**应用要点**：
- 奖项不要局限于"业绩最好的人"
- 可以奖励：变革勇气、管理体系贡献、家属支持、自我激励精神
- 让离职员工也能获奖，体现组织的开放与格局

**STOP检查点**：
- [ ] 公司奖项是否只有"年度最佳员工"一种？
- [ ] 是否考虑了非业务岗位（行政/支持/后勤）的表彰？
- [ ] 奖项命名是否有企业独特的文化印记？

### 核心四：领导者的自我激励 — 分蛋糕的人最后一个拿

**任正非哲学**（第13.6节/小结）：
- 世界上最伟大的激励，就是自我激励，自己相信自己，自己鼓励自己
- 任正非及高层所做的就是制定好分蛋糕的规则，分好蛋糕，并保证必须让分蛋糕的人最后一个拿蛋糕
- 拒绝外部几乎所有的奖项，保持内心的使命感和危机感

**应用要点**：
- 领导者不应依赖外部认可来确认自身价值
- 分配规则必须公开透明，且制定规则者要接受规则约束
- 最高层的自我激励是组织激励的源头

**STOP检查点**：
- [ ] 领导者是否把自己放在规则之外？
- [ ] 领导者是否过度依赖外部奖项和荣誉？
- [ ] 分配规则是否公开透明，让团队信任？

## Anti-Example Blacklist

❌ **不要把发奖变成走过场** — 如果发奖没有仪式感、没有精心准备、没有让获奖者感到光荣，就是在浪费激励资源。

❌ **不要只奖励业绩** — 只奖励业绩会忽视对组织文化、变革勇气、长期贡献的认可。

❌ **不要让零奖金变成羞辱** — 零奖金是对规则的尊重，不是对人的否定。需要高仪式感的象征物来平衡。

❌ **不要领导者第一个拿奖** — "让分蛋糕的人最后一个拿蛋糕"，领导者如果抢占了荣誉资源，激励就会失效。
