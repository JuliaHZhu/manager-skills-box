# overseas-project-entrepreneur

当用户面临海外项目拓展、海外市场交付、或在陌生环境中从零开始运作项目时激活。

适用于：海外"交钥匙"工程、一带一路项目、本地化团队建设、跨国供应链管理缺失场景、海外代表处初创期。

不适用于：纯本土成熟市场运营、已有完善海外平台和本地团队的项目、非工程类纯贸易业务。

关键 trigger：海外项目 / 国际化交付 / 本地化团队 / 项目经理创业者 / 海外从零开始 / 跨国工程 / 交钥匙项目 / 海外生存。

## 核心理念：项目经理就是创业者

华为海外项目先驱总结：在海外发展中国家，工程环境十有八九非常不理想。原先只需关心技术，现在必须关心经营。一切需要从头来，我们就是创业者，是在荒岛上想办法生存的人。

---

### 一、本地化队伍是根基

**没有本地化队伍是做不长的。** 中方员工最终是要走的，但要走得体面、走得放心，还能持续做贸易做工程，就必须建立本地化队伍。

**实践要点：**
1. **找到社会关系综合节点**：当地专业协会、大学、甚至酒店服务员，都可能成为招聘和资源整合的入口。
2. **避免"来叫Come去叫Go"**：不要把本地员工当听差，要培养他们，送他们到区域培训中心集中培训，日常工作中言传身教。
3. **建立"根据地"**：在区域核心城市建立培训中心、后勤基地，既做物资补给，也做能力补给。

### 二、信任决定权限

企业给你的权限依据是**信任**。信任从入职、选拔、培养、使用、挽留全过程中逐步形成。

- 将心比心：企业信任你，反过来也验证你对企业的信任和忠诚。
- **"将能而君不御者胜"**：将要能，才能得到信任；领导就不管你。
- 把业绩做出来，法律守在那里。做事过程中凭觉悟，站在企业角度考虑问题。
- **案例**：项目经理发现仓库月租9000美元过高，发动本地员工两周内找到月租不到1000美元的仓库，企业至今仍在使用。

### 三、客户标准是管理的唯一尺度

- 不要盲目提高管理标准，因为**管理是有成本的**。
- 以客户能接受的标准为准。铁塔按当地通用标准搭建三角铁塔即可，不必搭四方铁塔把成本转嫁给客户。
- 精细化管理的本质不是降成本上瘾，而是**增加客户体验**。体验为王。

### 四、以奋斗者为本

- 想做一件事必须要有牺牲。人的价值观不应随时间发生根本性改变。
- 华为"天道酬勤奖"：海外持续奋斗10年以上员工获得。
- **将军是打出来的，从项目实战中提拔战将。**
- 企业要把工作的意义给员工讲清楚（改变当地投资环境、战乱地区通信保障等），同时尽最大能力改善员工生活（优秀厨师派驻艰苦地区）。

### 五、实战能力补给

- 线上学习、区域中心集中学习、项目中学习、回国返程集中培训。
- 选拔制培养人才，给予锻炼机会，战训结合，在实战中增长才干。

## 使用流程

1. **环境扫描**：当地供应链是否完整？法律/税务/劳务环境如何？语言能力缺口在哪里？
2. **根据地建设**：找到区域中心节点，建立培训+后勤基地，找到本地招聘的社会关系入口。
3. **信任积累**：前3个月通过小事建立个人信用（节约成本、按时交付、信守承诺）。
4. **本地造血**：选拔有潜力的本地员工，制定3-6个月培养计划，赋予逐步递增的职责。
5. **经营闭环**：以客户标准为准绳，控制管理成本，把省下来的资源投入客户体验和团队保障。
