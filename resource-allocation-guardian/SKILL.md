# resource-allocation-guardian — 资源配置约束与倾斜

## R (Reading) — 原文引用

> "销管费用增长不高于收入与销售毛利额增长，且机关销管费用增长不高于区域销管费用增长。就是说，公司资源要向一线倾斜。"

> "研发费用增长不高于销售毛利额增长。"

> "应收账款余额增长低于收入增长，存货余额增长低于成本增长。就是说，公司要提高运营资产周转率。"

> "对于负增长的区域，董事会财委会要求落实'先减后加'的资源配置策略，及时释放资源。"

## I (Interpretation) — 方法论骨架

资源约束不是"省钱"，而是**确保资源流向正确的战场**。华为的资源配置框架包含三层约束：

1. **增长匹配约束**：费用增长 ≤ 收入增长/毛利增长。防止规模扩张时费用失控。
2. **结构倾斜约束**：机关费用增长 ≤ 区域费用增长。确保资源向客户界面倾斜，而非总部膨胀。
3. **效率约束**：应收账款增长 < 收入增长，存货增长 < 成本增长。防止虚假增长（收入变应收、成本变库存）。

附加机制：**负增长区域"先减后加"**——不直接追加资源救亏损，而是先释放冗余，再定向投入。

## A1 (Past Application) — 书中案例

华为董事会财委会年度预算评审中的硬约束清单：
- 盈利：各BG毛利率同比不下降，贡献利润增长率 ≥ 销售毛利额增长率
- 资源配置：研发费用增长 ≤ 销售毛利额增长；销管费用增长 ≤ 收入与毛利增长；机关费用 ≤ 区域费用
- 效率：应收账款增长 < 收入增长；存货增长 < 成本增长
- 创新：预研费用比例从10-20%逐步提升到20-30%
- 专项：面向客户的营销费用由BG统一归口，非客户界面的产业生态费用由产品线管理

## A2 (Future Trigger) — 触发场景

用户在以下情境需要调用本skill：
- "总部越来越庞大，一线资源不够怎么办？"
- "费用增长怎么设上限才合理？"
- "怎么防止收入增长了但不赚钱？"
- "亏损区域还要投入吗？"
- "研发投入和收入怎么挂钩？"

## E (Execution) — 可执行步骤

### 步骤1：建立三类约束指标

| 类型 | 约束公式 | 目的 |
|---|---|---|
| 增长匹配 | 费用增长 ≤ 收入/毛利增长 | 防止费用膨胀快于价值创造 |
| 结构倾斜 | 机关费用增长 ≤ 一线费用增长 | 资源向客户界面倾斜 |
| 效率约束 | 应收增长 < 收入增长；存货增长 < 成本增长 | 防止虚假增长 |

### 步骤2：区分客户界面/非客户界面投入
- **客户界面**（BG统一归口）：营销活动、客户拜访、展会、样品
- **非客户界面**（产品线/平台承担）：产业生态、品牌建设、内部变革

### 步骤3：设计负增长区域的"先减后加"
对连续负增长单元：
1. 冻结非必要招聘和资本开支
2. 清理冗余库存和超期应收
3. 释放人力/资金后，定向投入新机会点
4. 设定复苏里程碑，未达标则继续收缩

### 步骤4：建立季度监控与动态调整
- 绿灯：三项约束均满足 → 正常执行
- 黄灯：一项约束触及边界 → 预警并提交纠偏计划
- 红灯：两项及以上约束突破 → 暂停新增投入，启动专项整改

## B (Boundary) — 不适用场景

- **资源极度充裕**：现金储备充足、无融资压力的企业，约束动力不足。
- **纯战略投入期**：为构建长期壁垒需要超常规投入时，约束可能抑制创新。
- **个人费用审批**：报销标准、差旅额度等执行层问题。
