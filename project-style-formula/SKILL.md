# project-style-formula

当用户需要建立个人项目管理风格、提升项目经理软技能、或讨论"项目经理应该怎么管事/管人"时激活。

适用于：新项目经理快速上手、项目团队组建期、相关方冲突频繁、项目节奏混乱、希望形成可复用的个人管理章法。

不适用于：纯技术方案设计、无团队管理的个人任务、已有成熟PMO体系且运转良好。

关键 trigger：项目管理风格 / 一魂三动五意 / 项目经理软技能 / 破冰 / 闭环 / 冲锋 / 相关方管理 / 团队融入 / 项目章法。

## 核心框架：十四字风格

华为老兵提炼的项目管理风格公式：

> **一魂三动五意聚，两极四世八方齐**

数字记忆：1-3-5-2-4-8

---

### 一魂：明确、有效、可控

管理风格的核心灵魂，思想主线。

- **明确**：项目背景清楚，客户应用场景清晰，需求范围具体，交付成果要求明了，人员匹配确定。
- **有效**：工程思维聚焦产品落地，不追求前沿理论（预研除外），不吹毛求疵，不力求完美。适配流程，合适就好。
- **可控**：全局视野，抓住核心骨干、关键路径和主要风险。没有盲区、没有死角，放出去还能收回来。

### 三动：破冰、闭环、冲锋

管理风格的动作要领。

**1. 破冰行动（启动）**
- 走进去：向产品经理了解、向技术专家求教、向同行学习，快速学习全盘熟悉。
- 跳出来：站在高处整体分析，三板斧砍出关键点——关键技术及关键人员、关键路径及里程碑、关键风险及预防措施。
- 提前参与立项、应用场景分析、技术方案讨论。挑选最适合的人员，没得选则安排针对性培训串讲。

**2. 闭环行动（执行）**
- 开环系统 = 大炮发射：只发指令无过程响应，偏差大，返工重来。
- 闭环系统 = 导弹发射：弹道跟踪制导，过程稳定、结果精确、响应及时。
- 不断检测对比 → 偏差反馈 → 调整控制。需求变更及时管理，阶段输出偏差及时纠正，新风险识别处理，最终一次性把事情做好。

**3. 冲锋行动（攻坚）**
- 目标明确具体，统一思想，集中火力，心存强烈取胜欲望，展现高昂斗志和非凡攻击力。
- **三切忌**：切忌长久、切忌大面积铺开、切忌陷于疲惫而厌战。
- 不压一压不知道自己有多大能耐，不逼一逼不知道自己有多优秀。

### 五意：项目经理条件反射级软技能

1. **绩效意识**：结果导向。关注业务绩效、团队成长绩效、组织管理绩效。成长比成功更重要。
2. **全局意识**：内外部环境依赖、全方位风险、不同工种协调。"向关键路径要时间，向非关键路径要资源"。取舍之间必有得失，得失之间必有因果。
3. **拥抱意识**：积极乐观OPEN心态。
   - 拥抱变化：政策制度适应、客户需求变化敏捷应对。
   - 拥抱问题：问题发现越早越好。状态报告"很漂亮"没有问题最可怕。
   - 拥抱个性：取其专长，放出高倍光彩。
   - 拥抱失败：失败可怕，但拥抱失败。只有一次失败最接受不了——特别用心、特别在意的事情失败了。
4. **质量意识**：比质量经理更深入产品、更贴近项目的"更有效"重视。
5. **成本意识**：控制成本，合适就好，不浪费人力物力。在进度/质量/成本上权衡决策。

### 两极：沟通的双方，相互承诺，共同成长

- 工作计划是彼此评估讨论出来的，也是一份相互承诺。
- 项目经理按计划满足要求；成员延期要找出原因（环境/评估/冲突/效率），双方及时沟通更新。
- 不要总是计划延期，兑现不了承诺，失去个人品牌信用。
- 年初PBC，年中及时补充调整，避免半年后"综合一下给了B"的差沟通结果。

### 四世：四世同堂，项目经理是"当家人"

团队成员经历"认同→磨合→冲突→融入"四阶段，项目经理充当不同角色：
- **导师**（引路）→ **教练**（指导）→ **朋友**（支持）→ **当家人**（授权）
- 当家人：能屈能伸，有原则有弹性，有柔有刚，吃苦耐劳，换位思考，有威严，有嘻哈。

### 八方：来自四面八方的相关方管理

- 上有老板，下有兄弟姐妹；左产品右市场；前销售后生产服务；甲方提需求、合作方盯进度、质量经理来敲打。
- **状态报告是双刃剑**：主动定期汇报进展、计划、困难、求助，把领导拉入项目组统一战线。
- **沟通策略**：先点对点沟通，达成共识的纳入书面报告；暂无法共识的走OR/RAT/CCB/工作联络单等特殊通道。
- 去拥抱相关方，做有效沟通，成为朋友。最大的敌人是你自己。

---

## 使用流程

1. **诊断**：当前项目最缺"事"的管理还是"人"的管理？
2. **聚焦**：从十四字中选出最需要强化的1-2个字。
3. **行动**：制定具体的本周改进动作（如：本周开始每天发状态报告、安排一次与关键相关方的一对一沟通）。
4. **复盘**：两周后回顾，这1-2个字的改进是否带来了项目氛围或效率的变化。
