# admin-baseline-manager

## R — 原文 (Reading)

> "行政采用基线管理，不是指全球统一基线，而是各个国家自己和自己比。用前三年数据统计出科学的基线，不要年年去干预基线。确定基线管理方法，然后公开基线。节约机制和人力资源激励机制相结合，节约是要分享的，浪费是要分担的。"
>
> — 任正非, 第7章（简化行政管理）

---

## I — 方法论骨架 (Interpretation)

行政基线管理是一种"分权+激励"的成本控制框架。核心逻辑有三层：

1. **二元分类**：把所有行政业务分为两类——生活服务类（吃住行等）提倡以国家/区域为颗粒度自治；业务保障类（办公设施、安全、IT等）由总部建立全球标准并强制执行。

2. **基线设计**：不为全球设统一标准，而是以每个国家/区域为单位，用前三年滚动平均值建立生活基线（汽车租赁、住房租金、伙食成本等）。基线一旦确定，短期内不频繁调整，让一线有稳定预期。

3. **激励绑定**：对照基线，节约部分与团队人力资源激励挂钩（分享），超出基线的浪费由相关人员分担。用利益机制驱动自发节约，而非机关层层审批。

这套框架解决的是全球化组织中"统一标准行不通、完全放任会失控"的两难。

## A1 — 书中的应用 (Past Application)

### 案例 1: 华为170个国家的行政基线管理
- **问题**: 华为员工遍布170个国家，各国生活成本差异巨大（瑞士房租 vs 尼日利亚房租），全球统一行政标准既不现实也不公平。
- **方法论的使用**: 以国家为颗粒度，用前三年滚动平均值建立吃住行基线；生活服务类自治，业务保障类标准化。
- **结论**: 自己和自己比，不是和别的国家比；节约分享、浪费分担。
- **结果**: 全球行政费用200亿在可控范围内运行，代表处对基线有稳定预期，减少了对总部的依赖。

### 案例 2: 巴西20级行政标杆
- **问题**: 行政人员职级偏低（多为13级），优秀人才不愿来，管理质量上不去。
- **方法论的使用**: 在巴西破格提拔20级行政干部作为标杆，证明行政系统可以高配高阶人才。
- **结论**: 行政不是低端岗位，需要高阶人才来管200亿费用。
- **结果**: 带动全球行政体系人才升级，改变"行政=低端"的刻板印象。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 企业有多个海外/跨区域分支机构，行政成本失控或总部与分部矛盾重重。
2. 需要建立一套既能让一线灵活应对当地差异、又能总体可控的行政管理体系。
3. 行政费用逐年上涨，但说不清钱花在哪里、为什么花、怎么省。
4. 想要用激励机制替代审批机制来驱动成本节约。
5. 在推行全球化时遇到"统一标准水土不服、完全放权又乱套"的困境。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **二元分类梳理**
   - 完成标准: 列出该组织所有行政支出项，按"生活服务类"和"业务保障类"分为两列。
   - 判停条件: 若组织无跨区域分支（单一城市），跳到步骤5（输出不适用建议）。

2. **确定基线颗粒度**
   - 完成标准: 确定基线计算的最小地理单位（国家/省/城市），并收集该单位前2-3年的历史行政支出数据。
   - 判停条件: 若历史数据不足3年，改用"行业对标+当年实际"混合基线，并标注为临时基线。

3. **基线计算与公开**
   - 完成标准: 计算各颗粒度在吃住行等关键维度的滚动平均基线，形成可查阅的基线表，并向相关团队公开。

4. **激励规则设计**
   - 完成标准: 明确"节约分享比例"和"浪费分担比例"，写入团队考核/奖金制度。
   - 判停条件: 若组织无独立核算权限或奖金池，改为"通报表扬+晋升加分"非物质激励。

5. **输出框架文档**
   - 完成标准: 输出一份包含二元分类清单、基线表、激励规则的《行政基线管理框架》文档。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 组织无跨区域分支（单一办公室/单一城市）——基线管理对单一地点价值有限。
- 行政支出极小（<年营收1%）且不是管理痛点——投入产出比不成比例。
- 组织已有成熟的ERP系统自动核算全球成本且运行良好——无需另建基线。
- 处于初创期、分支机构尚未稳定——基线需要历史数据，新设机构数据不足。

### 作者在书中警告的失败模式

- **全球一刀切**: 试图为全球设统一标准，忽视各国差异，导致标准在当地完全不可行。
- **频繁干预基线**: 年年调整基线，让一线永远不知道明年标准是什么，失去稳定预期。
- **只压不奖**: 只要求节约但不设计分享机制，导致一线消极对抗、数据造假。

### 作者的盲点 / 时代局限

- 华为是全球7000亿级巨头，有200亿行政费用可管。中小企业行政体量小，基线管理的统计意义和激励效果都有限。
- 华为有强大的IT系统和财务能力支撑基线计算和公开。缺乏数据基础设施的企业难以复制。
- "国家自治"在战乱、极不发达国家可能失效——基线甚至没有统计意义。

### 容易混淆的邻近方法论

- 与"预算管理"的区别: 预算管理是"自上而下设定上限"，基线管理是"用历史数据建立参考标准+激励驱动"，后者更柔性。
- 与"OKR/KPI考核"的区别: 基线管理不考核行政满意度，只考核成本效率和基线遵守。
