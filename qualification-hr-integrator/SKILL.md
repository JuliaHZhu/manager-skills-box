# qualification-hr-integrator — 任职资格与人力资源体系整合

## R (Reading) — 原文引用

> "任职资格体系建立在HAY项目完成的人力资源基础工作之上，是HAY项目的继续和补充。两项目的整合，基于操作方法、原理上的一致性。"（Ch6）

> "任职资格在职位管理与资格管理方面的应用包含：定级调薪、职位晋升选拔、技能提升培训、任职聘用与调配四个作用。"（Ch7.15）

> "以岗定级，以级定薪，人岗匹配，易岗易薪。"（Ch5.1）

> "任职资格与绩效管理实现的目的是有底层差距的……任职资格更关注于行为和工作过程标准，以及与能力相关的工作过程实例。"（Ch5.6）

> "任职资格只是一个岗位晋升的一个必要前置条件，并不是有了任职资格就一定有相关的坑准备着……相当于一本驾照，你要开车你一定要有驾照才合法，你考了驾照，不意味着交管局就一定要给你配好一辆车。"（Ch5.6）

> "任职资格管理属于人力资源管理的子体系，它与人力资源管理其他子体系之间有着非常紧密的联系，它与职位共同构筑了华为人力资源管理的基础平台。"（Ch9）

> "任职资格为比较每个职位的相对价值大小提供了科学依据……职位价值大通常对应的是高标准的任职资格。"（Ch9.3）

## I (Interpretation) — 方法论骨架

任职资格不是HR的一个孤立模块，而是**人力资源管理的"底座"**——它与职位体系共同支撑招聘、绩效、薪酬、培训、晋升五大模块的运转。

**华为HR基础平台架构：**

```
        招聘          绩效          薪酬          培训          晋升
          │            │            │            │            │
          └────────────┴────────────┴────────────┴────────────┘
                              │
                    任职资格管理体系
                              │
                    职位体系（HAY项目）
                              │
                    战略/文化/价值观
```

**五大整合逻辑：**

| HR模块 | 任职资格的作用 | 关键原则 |
|--------|--------------|---------|
| **招聘** | 提供准入标准（知识、技能、行为门槛） | 按任职资格标准设计面试考察点 |
| **绩效** | 区分"能力"与"产出"；绩效是资格认证的参考 | 资格看行为过程，绩效看结果贡献 |
| **薪酬** | 职能工资制基础；以级定薪、人岗匹配 | 任职资格等级决定薪酬带宽 |
| **培训** | 指明能力差距，驱动精准培训 | 缺什么补什么，而非撒胡椒面 |
| **晋升** | 必要前置条件（驾照比喻） | 有资格≠必晋升，无资格=不晋升 |

**核心公式：**
- **价值评价** = 职位价值（岗）+ 任职资格（人）+ 绩效结果（事）
- **价值分配** = 职位工资（岗）+ 能力工资（人）+ 绩效奖金（事）+ 长期激励（贡献累积）

## A1 (Past Application) — 书中案例

**华为的"四定"原则：**
- **以岗定级**：岗位价值决定级别区间
- **以级定薪**：级别决定薪酬带宽
- **人岗匹配**：员工能力与岗位要求匹配
- **易岗易薪**：岗位变动则级别和薪酬相应调整

**任职资格与薪酬联动（华为实践）：**
- 任职资格3级对应岗位级别16-17级
- 拿到3级资格 ≠ 一定升到17级，还需AT例会（管理例会）决策
- 没有3级资格 = 一定不能升到17级（天花板锁定）
- 换岗后需重新认证，每次认证有效期2年
- 有效期内无新认证 → 级别瓶颈 → 工资/奖金/配股到达天花板

**任职资格与绩效的区别（华为厘清）：**

| 区别 | 任职资格 | 绩效考核 |
|------|---------|---------|
| 基础 | 职类划分与行为标准 | 考核指标与标准 |
| 关注点 | 行为 + 过程 | 结果 + 贡献 |
| 管理对象 | 能力/技能 | 绩效改进/实际贡献 |
| 管理过程 | 标准建立/认证/培训 | 计划/辅导/检查/反馈 |
| 结果 | 达标/不达标（或四级） | 优秀/良好/正常/需改进 |

**关键关系：** 绩效不佳可能是因为技能需改进（→触发培训）；资格认证的主要依据之一是绩效输出（→前置条件）。

**华为秘书系统与HR整合：**
- 招聘：按任职资格标准考察秘书技能（文档管理、会议组织、信息系统）
- 转正：新员工培训后需获得"预备等"资格方能上岗；上岗3个月后需获"基础等"
- 调配：跨部门调动需重新认证，确保能力匹配新岗位要求
- 薪酬：不同资格级别对应不同薪酬等级

## A2 (Future Trigger) — 何时调用

- 任职资格体系建好了，但招聘还是老标准、薪酬还是老办法，体系没打通
- 员工问"我任职资格通过了，为什么工资没涨？"
- 绩效考核和任职资格认证混为一谈，用一个结果代替两个评价
- 招聘时面试官凭感觉，没有按任职资格标准设计面试问题
- 调岗/晋升时没有重新认证，人岗不匹配
- 想推行职能工资制，但不知道级别怎么和薪酬挂钩
- 培训部门不知道给谁培训什么，与任职资格差距脱节

## E (Execution) — 可执行步骤

### Step 1: 任职资格与招聘整合

**面试考察点设计：**

1. **拆解任职资格标准**
   - 将目标岗位的任职资格标准分解为"知识-技能-行为"三维考察点
   - 示例（招聘3级软件测试工程师）：
     - 知识：掌握系统测试方法、缺陷跟踪流程（笔试/问答）
     - 技能：能独立设计测试用例、搭建测试环境（上机/案例）
     - 行为：在项目中主动发现重大缺陷并推动解决（行为事件访谈）

2. **设计结构化面试题**
   - 每个考察点设计1-2个行为面试问题（STAR法则）
   - 示例："请讲述一次你在测试中发现了开发人员遗漏的重大缺陷的经历。当时你是怎么发现的？怎么沟通的？最终结果如何？"

3. **建立面试评估表**
   - 与任职资格标准一一对应
   - 评分：不达标/基础达标/完全达标/超出预期
   - 一票否决：品德/诚信问题

### Step 2: 任职资格与绩效整合

**明确边界（最重要）：**

| 场景 | 归任职资格 | 归绩效考核 |
|------|-----------|-----------|
| 员工是否能胜任岗位 | ✅ | ❌ |
| 员工本季度目标完成度 | ❌ | ✅ |
| 员工工作行为是否符合标准 | ✅ | 部分参考 |
| 员工对团队的贡献大小 | 参考 | ✅ |
| 员工能力是否有提升 | ✅ | ❌ |

**联动机制：**
1. **绩效作为资格认证的前置条件**
   - 申请2级以上认证：近两次绩效不能为D/E
   - 申请4级以上认证：近两次绩效至少1次B以上

2. **资格认证结果影响绩效目标设定**
   - 认证通过某级别 → 下一周期绩效目标可按该级别标准设定
   - 认证未通过 → 绩效目标应包含能力提升项

3. **能力短板 → 绩效改进计划**
   - 任职资格评估发现"沟通能力不足" → 纳入季度PBC改进项
   - 绩效评估发现"交付延迟" → 追溯是否为技能不足，触发培训

### Step 3: 任职资格与薪酬整合（职能工资制）

**薪酬结构设计：**

| 薪酬模块 | 挂钩依据 | 说明 |
|---------|---------|------|
| **基本工资** | 职位价值 + 任职资格级别 | 以岗定级、以级定薪 |
| **能力工资** | 任职资格等级 | 同一岗位级别内，资格等级高则能力工资高 |
| **绩效奖金** | 绩效考核结果 | 与任职资格无关 |
| **长期激励** | 累积绩效 + 任职资格 + 任职年限 | 饱和持股、期权 |

**宽带薪酬设计：**
- 1个任职资格级别对应2-3个岗位级别
- 示例：
  - 任职资格3级 ↔ 岗位级别16-17级
  - 任职资格4级 ↔ 岗位级别18-19级
- 同一任职资格级别内，能力工资带宽建议30-50%

**调薪规则：**
- **晋升调薪**：岗位级别提升 → 按新级别薪酬带宽定薪
- **资格调薪**：同一岗位级别内，任职资格等级提升 → 能力工资上调
- **易岗易薪**：转岗后按新岗位任职资格重新定级定薪

### Step 4: 任职资格与培训整合

**培训需求生成机制：**

1. **差距分析**
   - 目标级别标准 - 当前级别达标情况 = 能力差距
   - 差距项自动生成为培训需求

2. **培训计划生成**
   - 知识差距 → 课堂培训/在线课程
   - 技能差距 → 实操训练/项目历练
   - 行为差距 → 导师辅导/情境模拟

3. **培训效果验证**
   - 培训后3-6个月进行资格认证复评
   - 或在工作产出中观察行为改变

**示例（任职资格差距→培训计划）：**

| 差距项 | 目标标准 | 当前水平 | 培训方式 | 周期 |
|--------|---------|---------|---------|------|
| 产品规划能力 | 独立制定产品Roadmap | 仅能参与讨论 | 方法论培训+实战任务 | 3个月 |
| 跨部门协作 | 协调3个以上部门 | 仅能协调本部门 | 跨部门项目PM历练 | 6个月 |
| 需求分析 | 独立完成用户调研 | 仅能整理需求文档 | 客户现场实践+导师辅导 | 2个月 |

### Step 5: 任职资格与晋升整合

**晋升决策公式：**

```
晋升 = 任职资格达标（必要）+ 绩效优秀（必要）+ 岗位空缺（必要）+ 素质匹配（优先）
```

**操作流程：**

1. **资格筛选**
   - 晋升到X级岗位 → 必须已获X级任职资格
   - 无资格者自动排除

2. **绩效排序**
   - 有资格者中，按近两次绩效排名
   - 建议：晋升候选人近两次绩效至少1次B+以上

3. **AT例会评议**
   - 华为实践：AT例会（管理例会）专门解决"人"的问题
   - 评议内容：任职资格、绩效、品德、组织需要
   - 与ST例会（业务经营会议）分离，避免混淆

4. **岗位匹配**
   - 有晋升资格 ≠ 一定有岗位
   - 需等待岗位空缺或组织扩张
   - 可先到更高资格级别，待有岗时再晋升

### Step 6: 建立人岗匹配动态管理机制

**上岗匹配：**
- 新员工/转岗员工上岗3-6个月内完成上岗认证
- 未通过 → 延长试用期或退回
- 通过但未达基础等 → 制定改进计划

**例行匹配：**
- 每半年至1年进行例行认证
- 认证结果：维持/升级/降级
- 降级触发条件：连续两次绩效D/E、重大失误、技能退化

**易岗匹配：**
- 岗位变动（晋升/转岗/降级）→ 自动触发任职资格重新评估
- 新岗位资格要求 > 当前资格 → 给予过渡期（3-6个月）补差距
- 新岗位资格要求 < 当前资格 → 资格保留2年，期间可向新岗位更高资格挑战

## B (Behavior) — 行为变化

**Before:** 任职资格体系孤立存在，招聘凭感觉、绩效和资格混为一谈、薪酬和级别脱节、培训撒胡椒面、晋升靠关系。

**After:** 任职资格成为HR各模块的共同语言：招聘按标准选人、绩效和资格各管一摊、薪酬随资格等级调整、培训瞄准差距、晋升有明确门槛和流程。
