# 五大成本聚焦管理

## R — 原文 (Reading)

> 设计成本：产品成本的80%取决于设计。一旦设计完成，进入生产制造环节，最多只能再影响产品成本的20%。
>
> — 华为管理手册, 第52章

> 采购成本：降低采购成本的核心是选择优质的供应商，并且实现长期稳定的合作。
>
> — 华为管理手册, 第52章

> 质量成本：它由预防成本、鉴定成本、内部故障成本和外部故障成本四部分组成。华为关注的是质量成本中的"隐性成本"——即因为质量问题导致的客户满意度下降和品牌价值损失。
>
> — 华为管理手册, 第52章

> 库存成本：库存管理的核心在于平衡——既不能因为缺货影响交付，也不能因为库存过多导致资金占用和跌价损失。
>
> — 华为管理手册, 第52章

> 期间费用：华为关注三项——管理费用、销售费用、财务费用。通过精简机构、提高效率、优化流程来降低期间费用。
>
> — 华为管理手册, 第52章

## I — 方法论骨架 (Interpretation)

华为成本管理的聚焦策略是**"抓住关键少数，从源头控制成本"**——80%的成本在设计阶段就已决定。

**五大成本聚焦框架：**

```
成本结构
├── 设计成本（决定80%后续成本）← 源头控制
├── 采购成本（供应链优化）
├── 质量成本（隐性成本为主）
├── 库存成本（资金效率）
└── 期间费用（运营效率）
```

**设计成本管理（最重要）：**

| 原则 | 含义 | 操作要点 |
|------|------|----------|
| **80/20法则** | 设计决定80%的后续成本 | 设计阶段是成本控制的关键窗口 |
| **可制造性设计** | 设计时考虑制造可行性 | 避免设计出来却造不出来或成本过高 |
| **标准化设计** | 减少定制件，多用标准件 | 降低采购成本和制造复杂度 |
| **价值工程** | 功能与成本的最优匹配 | 不牺牲核心功能的前提下降低成本 |

**采购成本管理：**

| 策略 | 含义 | 操作要点 |
|------|------|----------|
| **优质供应商** | 选择质量、价格、交付综合最优的供应商 | 不以最低价中标 |
| **长期合作** | 与核心供应商建立战略合作 | 获得价格优惠和技术支持 |
| **集中采购** | 整合需求，批量采购 | 发挥规模效应 |
| **国产化替代** | 用国内供应商替代进口 | 降低采购成本和供应链风险 |

**质量成本管理：**

质量成本四象限：
```
            高
  预防成本 ↑  外部故障成本
  (投入)   │  (损失最大)
           │
  鉴定成本 │  内部故障成本
  (检验)   │  (返工/报废)
            低
```

华为特别关注：**隐性质量成本** = 客户满意度下降 + 品牌价值损失 + 市场份额流失

**库存成本管理：**

| 风险 | 表现 | 控制方法 |
|------|------|----------|
| **缺货风险** | 影响交付，客户投诉 | 安全库存 + 供应链协同 |
| **资金占用** | 库存占用大量流动资金 | JIT + 精准预测 |
| **跌价损失** | 产品降价/过时导致库存贬值 | 版本管理 + 快速周转 |
| **呆滞风险** | 长期不动库存变成死库存 | 定期清理 + 预警机制 |

**期间费用管理：**

| 费用类型 | 控制重点 | 方法 |
|----------|----------|------|
| **管理费用** | 机构臃肿、层级过多 | 精简机构、扁平化、流程优化 |
| **销售费用** | 低效营销、费用失控 | 精准营销、费效比考核 |
| **财务费用** | 资金成本高、汇兑损失 | 资金集中管理、汇率对冲 |

## A1 — 书中的应用 (Past Application)

### 案例 1: 华为产品设计成本控制
- **问题**: 产品上市后成本居高不下
- **方法论的使用**: 在设计阶段引入成本评估，可制造性设计评审
- **结论**: 设计阶段多投入1元成本优化，生产阶段可节省10元
- **结果**: 产品综合成本显著降低

### 案例 2: 供应商战略管理
- **问题**: 采购价格波动大，质量不稳定
- **方法论的使用**: 选择优质供应商，建立长期战略合作
- **结论**: 长期合作带来价格优惠、质量稳定、技术协同
- **结果**: 采购成本下降，供应链风险降低

### 案例 3: 库存周转优化
- **问题**: 库存占用大量资金，版本升级导致呆滞
- **方法论的使用**: JIT生产 + 版本管理 + 快速周转
- **结论**: 库存管理的关键是平衡，不是越低越好
- **结果**: 库存周转率提升，资金效率提高

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **设计成本管控（源头控制）**
   - 完成标准: 在产品设计阶段引入成本评估
   - 建立可制造性设计（DFM）评审机制
   - 推行标准化设计，减少定制件
   - 价值工程分析：功能/成本最优匹配

2. **采购成本优化**
   - 完成标准: 建立供应商分级管理体系
   - 选择优质供应商（质量/价格/交付综合最优）
   - 与核心供应商建立长期战略合作
   - 集中采购，发挥规模效应

3. **质量成本管理**
   - 完成标准: 建立质量成本核算体系
   - 统计预防成本、鉴定成本、内部故障、外部故障
   - 特别关注隐性成本：客户满意度、品牌损失
   - 加大预防投入，减少外部故障损失

4. **库存成本平衡**
   - 完成标准: 建立库存分类管理机制
   - ABC分类：A类（高价值）重点管控，C类（低价值）简化管理
   - 安全库存 + JIT生产 + 快速周转
   - 版本管理：避免升级导致呆滞

5. **期间费用精简**
   - 完成标准: 管理费用、销售费用、财务费用分别设定控制目标
   - 管理费用：精简机构、扁平化、流程优化
   - 销售费用：费效比考核、精准营销
   - 财务费用：资金集中管理、汇率对冲

6. **建立成本监控仪表盘**
   - 完成标准: 五大成本各有核心KPI
   - 设计成本：设计变更次数、标准化率
   - 采购成本：采购价格指数、供应商集中度
   - 质量成本：质量成本率、外部故障损失
   - 库存成本：库存周转率、呆滞库存占比
   - 期间费用：费用率、人均费用

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯服务业（无实体产品）— 设计成本和库存成本不适用
- 已完全外包生产 — 设计成本和制造成本由外包商控制
- 没有设计环节的组织 — 如贸易公司
- 初创期产品尚未定型 — 先跑通模式再优化成本

### 作者在书中警告的失败模式

- **只关注采购降价**: 忽视设计成本，导致后期无法优化
- **质量成本只看显性**: 忽视客户满意度和品牌损失的隐性成本
- **库存一味追求零库存**: 导致缺货影响交付
- **期间费用一刀切**: 砍了不该砍的战略投入

### 作者的盲点 / 时代局限

- 华为成本管理基于硬件制造，软件/服务业需调整框架
- 数字化时代，设计成本可通过仿真和数字孪生进一步前置优化

### 容易混淆的邻近方法论

- 与全面质量管理: TQM是质量体系，本skill是质量成本管理
- 与精益生产: 精益是生产方式，本skill是成本结构管理
