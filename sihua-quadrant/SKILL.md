# 四化象限（禄权科忌动力结构分析）

## R — 原文 (Reading)

> 「禄是能量来源，权是力量结构，科是操作姿势，忌是代价产出。」
> 四者不分先后，是同一动力结构的四个模糊侧面。
>
> — 紫微斗数四化飞星基础框架，用户自定义 operational 版本

---

## I — 方法论骨架 (Interpretation)

分析任何一个行为、决策、事件或人物时，不直接给结论，
而是用**四化象限**同时照亮它的四个侧面：

| 四化 | 核心问题 | 感知维度 |
|------|----------|----------|
| **禄** | 能量从哪来？ | 欲望 / 恐惧 / 利益点 / 触发条件 / 原始冲动 / 缺口 |
| **权** | 力量结构是什么？ | 立场 / 派系 / 博弈筹码 / 靠山与敌人 / 谁压谁 |
| **科** | 操作姿势是怎样的？ | 技术路径 / 执行细节 / 时机选择 / 具体动作 / 节奏感 |
| **忌** | 代价产出是什么？ | 显性后果 / 隐性成本 / 回旋镖 / 谁替谁买单 / 结构的反噬 |

**核心规则：**
1. **四格是同一现象的四个投影**，不是时间上的先后顺序。可以从任何一格开始填。
2. **必须四格全填**。缺一格 = 存在感知盲区，结构不完整。
3. **忌不可回避**。任何分析都必须回答"代价是什么"，哪怕看起来没有代价。
4. **禄忌共振检验**。禄（能量）和忌（代价）是否在同一个频率上震动？如果能量很小但代价很大，说明有隐藏的能量来源未被发现。
5. **权科贴合检验**。力量结构（权）和操作姿势（科）是否气质一致？用核弹头当敲门砖 = 权科气质错配。

## A1 — 应用案例 (Past Application)

### 案例 1: 某中层干部突然大力推数字化转型
- **禄（能量）**: 恐惧驱动——新任CEO点名"不数字化就下课"，他上季度刚被批评"反应慢"
- **权（结构）**: 拉上IT部门结盟，同时排挤竞品部门，两头押注——对上是CEO的试点，对下是联合项目的话事人
- **科（姿势）**: 先上低成本OA（3个月见效），再逐步扩展，每次升级都发战报——节奏是"快赢+持续曝光"
- **忌（代价）**: 业务团队被系统绑架，效率先降后升；竞品部门怀恨，年终反噬；技术债越堆越高，下一任接手时可能崩盘
- **共振检验**: 禄（恐惧）与忌（延迟崩盘）气质一致 → **结构自洽，但代价被藏在了时间后面**

### 案例 2: 小说角色突然背叛盟友
- **禄（能量）**: 丧失之痛——盟友"为了大局"牺牲了他的部下，而那个部下是他的私生子
- **权（结构）**: 手里握着盟友通敌的信件（此前留着没揭穿），此刻选择交给敌方——权力来源是"秘密的保质期"
- **科（姿势）**: 不在正面冲突时翻脸，而是在盟友最需要支援的战场上"迟到"，同时通过第三方把信件放出去——姿势是"借刀+缺席"
- **忌（代价）**: 盟友倒台，但他自己也失去信誉，无人再敢结盟；私生子的死永远无法被正名
- **共振检验**: 禄（丧失）与忌（进一步丧失）形成闭环 → **复仇完成了，但复仇的对象是自己**

## A2 — 可执行工作流 (Workflow)

当用户给出一个需要分析的对象（人物/决策/事件/组织行为）时，按以下流程执行：

**Step 1 — 确认对象**
明确分析的是"谁的什么行为"或"什么事件的什么环节"。

**Step 2 — 填四化表**
从任意一格开始，凭直觉先填最有体感的那一格。四格全填，每格至少一句话。
忌必须包含"显性结果"和"隐性代价"两个子项。

**Step 3 — 共振检验**
- 禄和忌是否在同一个频率震动？（恐惧驱动的行为往往导致恐惧级别的代价）
- 权和科气质是否一致？（温和的结构不会长出暴力的姿势）
- 四格之间有没有断裂？（比如禄很小，权却很大 → 有隐藏的能量来源未被发现）

**Step 4 — 输出结论**
给出一句**bool 式判断**：
- 如果这个行为继续按此结构推进，最终忌的代价是否可承受？
- 如果要改变结果，应该从禄/权/科哪一格介入最有效？

---

## S — 自我检查 (STOP Checkpoints)

- [ ] **忌不可为空**: 如果分析完发现"没有代价"，说明观察不够深，重新检查。
- [ ] **权不可模糊**: "努力/争取"不是权，必须具体到"用什么资源、靠什么关系、压什么筹码"。
- [ ] **禄忌共振**: 能量和代价是否在同一个频率？表面是贪婪，代价却是恐惧级 → 禄被伪装了。
- [ ] **科的颗粒度**: 方法必须具体到"可以执行"的程度，不能停留在战略口号。
- [ ] **反方视角**: 如果从被分析对象的对手/受害方视角填四化表，四格内容是否还成立？

## P — 失败模式 (Anti-Patterns)

| 失败模式 | 表现 | 修正 |
|----------|------|------|
| **忌被美化** | 把代价说成"暂时的困难"或"必要的牺牲" | 忌必须是**净损失**，不能用修辞消解 |
| **权科混淆** | 把"用什么方法"填到权里，把"有什么资源"填到科里 | 权 = **谁/什么力量**，科 = **怎么操作** |
| **禄太浅** | 只写表面动机（"为了赚钱"），不写深层触发（"为什么是现在赚"） | 追问"为什么是这个时间点/这个对象/这个方式" |
| **四格同质** | 四格都在说同一件事，没有分层 | 检查每格是否回答了不同的问题 |
| **事后合理化** | 已知结果后倒推四化，把过程填得很顺 | 遮住忌那一格，先填其他三格，再看忌是否被预判到 |

## T — 扩展与变体 (Tools & Variations)

### 变体 1: 双人四化对照
两个利益相关方各自填一张四化表，然后对比：
- 禄是否冲突？（动机矛盾）
- 权是否重叠？（资源竞争）
- 科是否干涉？（操作撞车）
- 忌是否转嫁？（一方代价被另一方承担）

### 变体 2: 时间切片四化
同一个对象在不同时间点各填一张四化表，观察：
- 禄的衰减或转移（动力枯竭或转移）
- 权的聚散（联盟形成或瓦解）
- 科的升级或降级（方法迭代或退化）
- 忌的累积（代价雪球）

### 变体 3: 虚构角色检验
在小说/剧本创作中，用四化表检验角色的关键行为：
- 如果忌填不出来 → 这个行为缺乏真实代价，戏剧张力不足
- 如果禄和忌不对冲 → 角色缺乏内在矛盾，太平面
- 如果权科太顺 → 剧情缺乏波折，需要人为制造阻碍
