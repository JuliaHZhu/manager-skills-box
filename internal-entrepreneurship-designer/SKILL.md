# internal-entrepreneurship-designer

基于华为内部创业与衍生战略实践，帮助用户设计大企业内部创业机制、业务分拆（spin-off）方案，以及通过内部创业激活组织活力、解决老员工沉淀、弥补渠道短板、实现新老接替的完整方法论。

## When to activate

当用户需要设计内部创业制度、鼓励员工离职创业、将非核心业务外包给员工创业公司、通过衍生公司建立分销渠道、解决机构庞大和人才沉淀问题时激活。

适用于：大企业二次创业、业务分拆、分销体系建设、组织活化、新老接替。
不适用于：初创公司（无存量业务和老员工）、纯外部并购、已有成熟独立子公司体系仅做微调。

关键 trigger：内部创业 / 衍生公司 / spin-off / 业务分拆 / 员工创业 / 分销渠道建设 / 激活休克鱼 / 新老接替 / 港湾网络 / 内部创业政策。

## Core Framework

### 1. 内部创业的三大战略意图

- **激活休克鱼**：让缺乏动力的老员工/管理层通过创业重新焕发活力，或腾出位置引入新血
- **后向一体化/渠道建设**：让创业员工成为公司产品的分销商、服务商，降低市场交易成本
- **新老接替**：通过有组织的人才分流，解决机构庞大、层级僵化、创新乏力的大企业病

### 2. 两阶段推进模型

| 阶段 | 时间窗口 | 创业类型 | 业务范围 | 与母公司关系 |
|------|----------|----------|----------|--------------|
| 第一阶段 | 政策推出后1-2年 | 服务型创业 | 非核心业务外包（生产、印刷、文印、食堂、物流、工程安装） | 优先采购其服务 |
| 第二阶段 | 验证成功后2-3年 | 代理/分销型创业 | 市场销售代理、工程服务外包 | 代理母公司产品，建立分销网络 |

### 3. 政策设计五要素

- **准入门槛**：工龄要求（如满2年）、业绩贡献标准、核心业务排除条款
- **资产清算**：股权以优惠价格兑现（如1元/股），提供设备扶持（如股权价值70%的货物/设备）
- **保护期机制**：半年至1年的创业保护期，失败可回流公司重新安排工作
- **竞争边界**：明确禁止与母公司核心业务直接竞争（如只能做代理，不能自主研发同类产品）
- **回购/整合通道**：保留对优质创业公司的收购权，为回归母体留门

### 4. 风险防火墙

- **核心技术与客户资源隔离**：创业范围限定在分销、服务、非核心外围业务
- **竞业与知识产权约束**：通过协议明确知识产权归属、竞业限制、客户信息保护
- **动态监控与熔断**：若创业公司转向与母公司直接竞争（如港湾网络模式），启动竞争反制或回购谈判
- **文化输出而非管理介入**：创业公司保持独立核算、独立经营，母公司不介入日常管理

### 5. 成功标准

高水平的内部创业需同时具备三个特征维度：
- **创新性（innovativeness）**：在商业模式或运营方式上有新意
- **冒险性（risk-taking）**：创业者承担真实的经营风险
- **先动性（proactiveness）**：主动捕捉市场机会，而非被动承接母公司外包

## Workflow

1. **诊断**：评估组织是否存在"休克鱼现象"（老员工沉淀、创新乏力、渠道薄弱）
2. **设计**：根据业务特性选择第一阶段（服务外包）或第二阶段（代理分销）切入点
3. **定策**：制定内部创业政策文件（准入、清算、扶持、保护期、回流机制）
4. **划界**：明确核心业务红线、竞业条款、知识产权边界
5. **试点**：选择1-2个区域或业务线小范围试点
6. **监控**：跟踪创业公司业绩、竞争关系、人才流动，评估是否偏离边界
7. **进化**：对验证成功的创业公司，可选择深化合作、收购回归或独立发展

## Output format

当被激活时，按以下结构输出：

1. **一句话诊断**：当前组织是否适合启动内部创业
2. **阶段选择建议**：第一阶段还是第二阶段，或两阶段并行
3. **政策框架草案**：准入、清算、扶持、保护期、回流五条核心条款
4. **风险清单与防火墙**：至少3条明确的红线和应对措施
5. **演进路径**：从试点到推广的时间表和判断标准

## Notes

- 内部创业不是目的，而是解决组织特定问题的机制。若组织无沉淀、无渠道短板，不必强推。
- 警惕"李一男陷阱"：创业成功者获得外部资本后，可能从代理商蜕变为直接竞争者。政策设计时必须预设竞争边界和回购机制。
- 内部创业成功的关键在于产生积极的创新文化，而非单纯的人员分流。
