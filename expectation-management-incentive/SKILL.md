# expectation-management-incentive

基于华为激励机制实践，提供以"期望值管理"为核心的薪酬激励设计方法论。解决"发钱越来越多、员工越来越不满"的悖论，通过目标挑战性设计、获取分享制、差异化区域分配和TUP递延激励，实现精准激励和持续激励。

## When to activate

当用户遇到"奖金发了但员工不满意""目标太容易完成导致激励失效""新拓展区域无人愿意去""激励成了刚性福利""需要设计中长期激励"时激活。

适用于：薪酬体系 redesign、奖金分配机制设计、销售/区域激励差异化、期望值管理、中长期激励（TUP/期权）。
不适用于：纯个人理财、无业务数据的空想法设计、已有成熟激励体系仅做局部参数微调。

关键 trigger：期望值管理 / 激励失效 / 目标挑战性 / 获取分享制 / 奖金包 / TUP / 薪酬包 / 多劳多得 / 激励设计 / 发钱不满意 / expectation management / incentive design。

## Core Framework

### 1. 期望值管理核心公式

员工激励感受 = 实际获得值 - 心理期望值

- 同样的18万年薪：期望值15万的人感到满意，期望值20万的人感到不公
- **管理期望值比提高绝对值更重要**
- 70%的人会高估自己，女性比男性更容易低估自己（招聘定价时需反向校准）

### 2. 目标挑战性设计（压动平衡）

目标设定的黄金标准：
- **同类最优员工使出全力刚好够着**
- **全公司目标完成率控制在70%-80%**
- **绩效分布**：A（杰出，10%）/ B（良好，40%）/ C（正常，45%）/ D（需改进，5%）

为什么任正非每年都完不成目标但仍能发高额奖金？
- 目标挑战性高 → 大家考核C → 但公司利润因高目标而更高 → 可分配总额更多
- 员工一边"内疚"（考核不高），一边"感激"（奖金不少），形成持续奋斗动力
- 反之，目标定得太低 → 人人超额 → 公司没钱 → 员工抱怨"做得这么好才给这点"

### 3. 获取分享制：按业务属性差异化分配

| 业务类型 | 奖金逻辑 | 关键机制 |
|----------|----------|----------|
| 成熟区域 | 存量按贡献利润，增量按效益改善率 | 测算奖金包 = 去年奖金包 × (1 + 经营效益改善率) |
| 成长区域 | 与业务增长挂钩 | 熔断机制：奖金超过预算2倍时，超出部分不再计算 |
| 拓展区域 | 保护期机制 | 2年内以原区域奖金为起点，仅微调考核系数，鼓励冲锋 |
| 支撑部门 | 与业务部门挂钩 | 支撑部门总奖金包 = 业务部门平均奖金 × 支撑部门人数 |

### 4. 奖金包确定公式

公司年度总奖金池 =（公司年度净利润 - 年度经营性净资产 × 基准回报率）× 人力资本分配比例

- 先满足资本（股权）的基准回报（如15%），超额利润由知识资本（劳动者）与货币资本分享
- 劳动所得与资本所得比例：华为实践约为 3:1

### 5. TUP（奖励期权计划）：5年递延递增

| 年度 | 分红权 | 说明 |
|------|--------|------|
| 第1年 | 0 | 无分红 |
| 第2年 | 1/3 | 递延兑现 |
| 第3年 | 2/3 | 递延兑现 |
| 第4年 | 100% | 全额分红 |
| 第5年 | 100%分红 + 升值结算 | 权益清零，优秀者转虚拟受限股 |

- **对冲离职**：工作2-3年后离职成本过高，自然留人
- **筛选奋斗者**：5年后不符合价值观者离开，真正奋斗者获得长期股权
- **与股价挂钩**：TUP面值增值与虚拟受限股股价联动

### 6. 薪酬包管理

- 总薪酬包基线：销售额的15%
- 加薪包公式：预算销售额×15% - 上一年薪酬包 - 新增编制薪酬包
- 固定底薪原则：定岗定级、以级定薪、人岗匹配、易岗易薪
- 调薪规则：优先调弹性工资（奖金/专项奖），固定工资一旦上涨很难下降

## Workflow

1. **诊断**：当前激励是否陷入"肉多骂娘"或"大锅饭"困境
2. **校准期望**：通过面试定薪、绩效反馈、内部沟通，将员工期望值拉回合理区间
3. **挑战目标**：将公司/部门目标设定在"最优者刚好够着、整体完成率70-80%"的水平
4. **设计获取分享规则**：按成熟/成长/拓展区域差异化设计奖金公式
5. **引入TUP**：对5年左右的中坚力量实施递延递增激励，衔接短期与长期
6. **动态调整**：每季度审视薪酬包使用情况，不定期加薪替代年度普调

## Output format

当被激活时，按以下结构输出：

1. **期望值诊断**：当前员工激励感受是正向还是负向，主要原因
2. **目标挑战性评估**：现有目标完成率是多少，是否处于70-80%黄金区间
3. **获取分享制方案**：根据业务属性（成熟/成长/拓展/支撑）设计的奖金公式草案
4. **TUP适用性判断**：当前团队是否适合引入5年递延激励
5. **立即行动项**：接下来一个季度可落地的3个激励调整动作

## Notes

- 期望值管理是激励设计的"第一性原理"，做不好这一点，发再多钱也是填不满的欲望深坑。
- 目标完成率100%不是好事，说明目标定低了；全员A不是好事，说明考核尺度废了。
- 固定工资是刚性成本，弹性奖金是调节阀。涨薪时优先涨弹性，降本时优先保固定。
