# collective-leadership-decision

基于华为"民主决策、权威管理"原则，设计集体领导与首长负责相结合的决策机制。帮助企业在避免一言堂的同时保持决策效率，通过委员会充分讨论、首长个人担责、纪要注明异见等制度设计，实现高层决策的智慧集中与执行有力。

## When to activate

当用户需要设计高层决策机制、解决"议而不决"或"一把手拍脑袋"、建立EMT/委员会/轮值制度、讨论"从贤不从众"时激活。

适用于：大企业高层治理、集体领导制度设计、部门首长负责制、决策制衡机制、避免个人独裁。
不适用于：初创期无分工的团队、纯技术决策、紧急危机中的快速决断、已有成熟外部董事会治理的上市公司。

关键 trigger：集体领导 / 民主决策 / 权威管理 / 从贤不从众 / EMT / 轮值CEO / 委员会 / 首长负责制 / 决策体系 / 华为基本法第53条 / collective leadership / decision mechanism。

## Core Framework

### 1. 核心原则：民主决策，权威管理

- **民主决策**：重大决策需经高层管理委员会充分讨论，鼓励不同意见存在和发表
- **权威管理**：一经形成决议，必须严格执行，不允许选择性执行或扭曲执行
- **决策原则**：从贤不从众（真理往往掌握在少数人手里），不采用少数服从多数的投票表决

### 2. 双机制架构

| 机制 | 职能 | 人员构成 | 权力边界 |
|------|------|----------|----------|
| 高层管理委员会（专业委员会） | 议事、监督 | 各部门首长兼任 | 议事而不管事；对决议有监督权；防止一长制片面性 |
| 部门首长负责制下的办公会议 | 管事、执行 | 部门首长+核心成员 | 对日常管理决策负责；决策后果由首长承担个人责任 |

### 3. 委员会设计要点

- **人员兼职化**：委员必须是业务部门首长，不能是专职委员或外部顾问，确保讨论贴合业务实际
- **议事不管事**：委员通过个人影响力发挥作用，不拥有决策权，防止利益部门化
- **监督制衡**：委员会对形成的决议有监督权，可制衡首长权力集中带来的片面性
- **人员轮岗**：核心高管在不同部门（市场、研发、人力等）轮流坐庄，防止形成小圈子

### 4. 首长办公会设计要点

- **个人担责**：部门首长对决策后果承担个人责任，不能因委员会压力而推卸
- **纪要硬约束**：办公会讨论结果以会议纪要呈报，须**三分之二以上正式成员签名**
- **异见公开化**：纪要必须**特别注明讨论过程中的不同意见**，防止"老好人"现象，便于事后追溯责任
- **定期述职**：首长年初承诺目标，年中审视，年末述职，形成闭环

### 5. 决策演进路径

- **总裁办公会**（早期）：总裁领导下的日常管理最高决策机构
- **EMT（经营管理团队）**（2004年后）：集体领导、集体决策，成员轮流担任主席
- **轮值CEO/董事长**（2011年后）：进一步分权，各自主持半年，保留创始人否决权
- **日常运营下放**：集团EMT聚焦战略，业务集团EMT聚焦日常，实现分层决策

### 6. 关键纪律

- 干部只能以个人名义表达意见，不允许联合签名
- 个人意见通过专用邮箱反映，未经批准不得擅自上公告栏
- 决策前充分讨论，决策后严格执行；反对者可以保留意见，但必须服从组织决议

## Workflow

1. **诊断**：当前决策机制是否存在"一言堂"或"议而不决"
2. **搭班子**：组建高层管理委员会（战略、人力、财经等专业委员会），明确委员必须是业务首长
3. **定规则**：确立"从贤不从众"的决策原则，取消投票表决
4. **建会议**：建立部门首长办公会议制度，明确纪要签名和异见注明要求
5. **明责任**：强化首长个人责任制，决策后果与首长个人绩效强挂钩
6. **设监督**：委员会对决议执行情况进行监督，防止选择性执行
7. **迭代演进**：从总裁办公会→EMT→轮值机制，根据企业规模逐步分权

## Output format

当被激活时，按以下结构输出：

1. **决策机制诊断**：当前是独裁、民主还是混沌状态
2. **双机制设计方案**：委员会（议事+监督）+ 首长办公会（管事+担责）的具体设计
3. **决策原则声明**：从贤不从众、纪要签名、异见注明等关键纪律
4. **演进路线图**：从当前状态到理想状态的3个阶段
5. **风险清单**：委员会沦为橡皮图章、首长推卸责任、议而不决的预防措施

## Notes

- 民主决策的目的不是投票，而是让一把手在充分听取多方意见后做出更优判断。
- "纪要必须注明不同意见"是本机制最具杀伤力的设计，它迫使每个人对决策质量负责，避免"跟着混"。
- 集体领导的前提是最高决策者（总裁/创始人）拥有最终决策权和否决权，否则容易陷入无政府主义。
