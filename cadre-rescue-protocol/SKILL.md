# 干部监管与挽救协议

## R — 原文 (Reading)

> 华为的干部监管制度，是一种以干部为对象，以监督干部是否忠于职守、勤勉尽责为目的的制度。
>
> — 华为管理手册, 第53章

> 华为干部调查的原则：查处分离原则。查处分离，是指把对领导干部的调查权与处理权分离，以保证监督机构客观公正地行使职权。
>
> — 华为管理手册, 第53章

> 查处分离制度具体措施：第一，组建独立的调查部门——调查部门独立于其他部门之外，不受任何部门或个人干涉；第二，建立独立的审理部门——审理部门对调查部门移交的案件进行独立审理，不受调查部门或其他部门干涉；第三，调查部门与审理部门分别对各自的部门负责人负责。
>
> — 华为管理手册, 第53章

> 华为的挽救措施，对于首次违规或轻微违规的干部，进行约谈提醒、批评教育，帮助其认识错误、改正错误。对于已经造成一定损失或影响的干部，进行降职、免职、调离岗位等处理，使其受到应有的惩罚。同时，对于能够认识错误、积极改正的干部，给予一定的宽容和机会。
>
> — 华为管理手册, 第53章

> 华为的挽救措施：华为的挽救措施不是一种惩罚，而是一种帮助，是组织对于犯错干部的一种关心和爱护。
>
> — 华为管理手册, 第53章

> 被冤枉/诬陷时的应对措施：当事人应向相关部门说明情况并提供证据，也可向纪检监察部门申诉。对于诬告陷害的行为，要严肃查处，维护被诬告干部的合法权益。
>
> — 华为管理手册, 第53章

## I — 方法论骨架 (Interpretation)

华为干部监管的核心理念是**"以挽救为出发点，以查处为手段，以教育为目的"**。

**查处分离原则（核心制度）：**

```
调查权（发现事实）    审理权（定性处理）    执行权（落实整改）
    ↓                    ↓                    ↓
 调查部门            审理部门            人事/业务部门
 独立运作            独立运作            协同执行
 对事实负责          对定性负责          对结果负责
```

**干部调查七大原则：**

| 原则 | 含义 | 关键规则 |
|------|------|----------|
| **查处分离** | 调查权与处理权分离 | 调查部门、审理部门各自独立，分别对上级负责 |
| **挽救出发点** | 调查是为了挽救，不是一棍子打死 | 帮助干部认识错误、改正错误，给予宽容和机会 |
| **集体决策** | 干部监管和调查由集体决策 | 避免个人独断，确保客观公正 |
| **不能随便侦查** | 只有在有明确线索和证据时才能启动 | 不能仅凭怀疑就启动调查 |
| **无罪推定** | 未经查实前，应推定干部无罪 | 保护干部合法权益，避免冤假错案 |
| **尊重干部** | 尊重干部的人格和权利 | 维护干部自尊心和积极性 |
| **适度问责** | 根据违规情节轻重，给予相应处理 | 首犯从宽、累犯从严 |

**挽救措施的梯度：**

1. **首次违规/轻微违规**: 约谈提醒 → 批评教育 → 帮助认识错误、改正错误
2. **造成一定损失/影响**: 降职 → 免职 → 调离岗位（惩罚+教育并重）
3. **能认识错误、积极改正**: 给予宽容和机会，不"一棍子打死"
4. **拒不改正/严重违规**: 从严处理，甚至移交司法机关

**举报处理四步法：**
1. **受理**: 多渠道受理（纪委、监察、组织部门、审计部门等）
2. **调查**: 调查部门独立调查，收集证据
3. **审理**: 审理部门独立审理，提出处理意见
4. **处理**: 相关部门根据审理意见进行处理

**被诬告的救济：**
- 当事人可向纪检监察部门申诉
- 诬告陷害行为要严肃查处
- 维护被诬告干部的合法权益

## A1 — 书中的应用 (Past Application)

### 案例 1: 任正非对待犯过错误的干部
- **问题**: 有干部因管理问题导致重大损失
- **方法论的使用**: 任正非公开说，犯了错误的干部仍可以在华为继续干，但前提是承认错误并改正
- **结论**: 挽救不是无原则纵容，而是给改正机会
- **结果**: 华为干部敢担当、敢试错，不因怕犯错而保守

### 案例 2: 审计发现中层干部违规报销
- **问题**: 某中层干部存在虚假报销行为
- **方法论的使用**: 审计部调查 → 审理部门定性 → 根据情节给予降级处理（非开除）
- **结论**: 区分"贪污腐败"与"管理疏忽"，前者绝不姑息，后者给予改正机会
- **结果**: 干部受到教育，组织保留了人才

### 案例 3: 华为轮值董事长被审计问责
- **问题**: 三位轮值董事长因报销问题被处罚
- **方法论的使用**: 审计发现 → 集体决策定性 → 公开处罚（每人50万）
- **结论**: 高层也要接受调查和处理，但处理是教育性的而非毁灭性的
- **结果**: 强化了"人人平等"的制度权威

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **建立查处分离制度**
   - 完成标准: 设立独立的调查部门和独立的审理部门
   - 调查部门：负责收集证据、查明事实
   - 审理部门：负责定性处理、提出意见
   - 两部门分别对各自上级负责，互不干涉

2. **设计干部调查启动机制**
   - 完成标准: 明确启动调查的触发条件（举报线索、审计发现、业绩异常等）
   - 关键规则：不能随便侦查，必须有明确线索和证据
   - 调查须经集体决策批准，不得个人擅自启动

3. **制定调查与审理流程**
   - 完成标准: 调查→审理→处理，三权分离
   - 调查部门只负责事实，不介入定性
   - 审理部门只负责定性，不介入调查
   - 处理部门根据审理意见执行

4. **建立挽救与教育机制**
   - 完成标准: 区分违规性质和情节，实施梯度处理
   - 首次/轻微：约谈提醒、批评教育
   - 有一定损失：降职、免职、调岗（惩罚+教育）
   - 能认识错误：给予宽容和改正机会
   - 拒不改正/严重：从严处理

5. **设计被诬告救济机制**
   - 完成标准: 设立申诉渠道（纪检监察部门）
   - 对诬告陷害行为严肃查处
   - 保护被诬告干部的合法权益

6. **推动集体决策文化**
   - 完成标准: 干部监管和调查重大事项由集体决策
   - 避免个人独断，确保客观公正
   - 建立干部管理委员会或类似机构

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 普通员工违纪 — 用一般纪律处分制度
- 刑事犯罪案件 — 移交司法机关
- 已由司法机关定性的案件 — 按司法结果执行
- 微型企业（<50人）— 可由老板直接管理

### 作者在书中警告的失败模式

- **调查权与处理权不分**: 调查部门既查又判，导致冤假错案
- **一棍子打死**: 干部一犯错就开除，导致人才流失、干部不敢担当
- **纵容包庇**: 以"挽救"为名包庇严重违规，破坏制度权威
- **个人独断**: 主要领导个人决定干部命运，缺乏客观公正

### 作者的盲点 / 时代局限

- 华为的干部监管基于其"以奋斗者为本"的文化，其他企业需适配自身文化
- 数字化时代可增加数据分析辅助调查，但调查结果仍需人工审理

### 容易混淆的邻近方法论

- 与纪检监察: 纪检监察是党内监督，干部监管是企业制度
- 与审计: 审计发现线索，干部监管调查处理
