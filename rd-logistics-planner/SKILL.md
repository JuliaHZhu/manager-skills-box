# 研发物流与新品供货风险管理

## R — 原文 (Reading)

> 随着市场竞争加剧与采购环境的剧烈变化，产品物料的可获得性问题已成为影响新产品上市进程的重要因素。可获得性（可采购性）管理是指通过对产品开发早期物料选型管理的运作，保障产品在切入供应链后批量物料的持续可获得性保障。器件选型是产品开发过程中硬件工程师最重要的工作之一。在设计中构建成本，在设计中构建可获得性。
>
> — 华为计划手册, 2.6.2 器件选型管理

> 受市场压力的影响，目前华为80％新产品在发布决策前已面临供货，且市场启动的时间不断靠前，批量日益加大。在明确必须战略满足市场需求时，产品经理所要作的，就是投入风险评估。技术风险、市场风险、物料采购风险、试制风险、开局风险五维评估。
>
> — 华为计划手册, 2.6.3 例外管理

---

## I — 方法论骨架 (Interpretation)

研发物流管理是保障新产品从概念到量产全过程中物料及时供应的方法论，核心目标是"缩短开发周期、保障ESP供货"。

**四阶段划分**:
1. **原型机阶段**（概念→TR4前）: 器件选型、关键器件及供应商选用、原型机物料申购
2. **实验局阶段**（TR4启动）: BETA测试/试产验证/展厅/参展/培训备件需求，物料齐套
3. **RAMP UP阶段**（TR4A→TR5）: ESP早期市场供货物料准备
4. **批量生产阶段**（TR5→发布）: 进入公司ISC供应链运作

**器件选型五维评估**:
- 技术性能指标（设计关注点） ↔ 技术与技术服务（采购关注点）
- 物料生命周期（避免选型后停产）
- 批量供货能力（避免独家供应受制）
- 成本支持（在设计中构建成本）

**新品提前供货五维风险评估**:
1. 技术风险: 开发进展、测试问题解决进度
2. 市场风险: 战略重要性、市场需求紧迫度、受控销售可能性
3. 物料采购风险: 设计更改比例、呆死料风险、关键物料货期
4. 试制风险: 产能、装备进展、加工困难
5. 开局风险: 人力投入、工程人员到位、维护投入

**研发自购**: 紧急需求下的例外通道，限定外围器件、国内交货、每月≤3次/≤3万元。

## A1 — 书中的应用 (Past Application)

### 案例 1: 宽带某产品关键器件选型失误
- **问题**: PDT开发人员直接与供应商谈判关键器件，价格较高，产品组迫于进度选定
- **方法论的使用**（反面教材）: 未在早期让采购参与，未评估批量成本；半年后市场启动，成本成为最大障碍，供应商因知道方案变更可能性小，价格难降
- **结论**: "在'选'与'不选'的评估时，我们才能掌握主动权，确保未来成本的支持"
- **结果**: 上市后成本竞争力不足

### 案例 2: 3G DSP器件实验阶段风险
- **问题**: 选用厂家实验阶段的DSP，量产时间无法满足开发要求
- **方法论的使用**（反面教材）: 未评估厂家成品率和量产时间表
- **结论**: 越来越多新产品选用厂家实验阶段器件，这是产品开发中高风险因素
- **结果**: 不得不使用低版本过渡方案，冲击开发进度

### 案例 3: 数通某系列TI套片停产
- **问题**: 产品开发完成准备发布时，TI宣布器件半年后停产
- **方法论的使用**（反面教材）: 器件选型早期未掌握路标规划与生命周期，未签早期供货协议
- **结论**: 必须在选型早期掌握器件路标，签订早期供货协议
- **结果**: 不得不重新评估新方案开发时间，并一次性储备4000多万停产器件

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 新产品开发中需要选择关键器件，担心供应风险或成本失控
2. 市场要求新产品提前供货，需要评估是否满足以及风险多大
3. 研发紧急缺料，正常采购流程来不及，需要判断能否自购
4. 实验局/试产阶段物料总是不齐套，需要规范研发物流流程
5. 版本切换涉及研发物料（如替代单板开发），需要管理研发端的切换计划

### 与相邻 skill 的区分

- 与 `version-switch-controller` 的区别: 本 skill 覆盖研发全阶段物流，version-switch-controller 专门处理版本切换执行；本 skill 包含切换中的研发端（替代单板开发、新旧物料衔接），但不如 version-switch-controller 深入
- 与 `inventory-health-diagnoser` 的区别: 本 skill 处理新品开发中的物料投入风险，inventory-health-diagnoser 处理量产后的库存健康
- 与 `production-control-operator` 的区别: production-control-operator 处理量产阶段的车间执行，本 skill 处理研发阶段的物料计划

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **判断研发物流阶段**
   - 完成标准: 明确当前处于四阶段中的哪一阶段
   - 阶段判定:
     | 阶段 | 特征 | 关键动作 |
     |---|---|---|
     | 原型机 | 概念→TR4前 | 器件选型、供应商选用、原型机申购 |
     | 实验局 | TR4启动 | 开局申请（提前2-3个月）、BOM清单实施、物料需求规模评估 |
     | RAMP UP | TR4A→TR5 | 半成品加工、ESP供货协调、供货保障小组 |
     | 批量生产 | TR5→发布 | 进入ISC供应链、设计更改通报、清单归档 |

2. **执行器件选型可采购性评估（如处于原型机阶段）**
   - 完成标准: 输出选型评估表
   - 评估维度:
     - [ ] 技术性能是否满足？技术服务是否到位？
     - [ ] 生命周期：是否已发布EOL通知？路标规划是否清晰？
     - [ ] 批量供货：是否独家供应？供应商产能是否充足？
     - [ ] 成本：批量价格 vs 样品价格差异？未来降价空间？
     - [ ] 早期供货协议：是否已签署？供货承诺是否书面化？
   - 判停条件: 若关键器件处于实验阶段或独家供应且无替代，启动风险升级

3. **评估新品提前供货风险（如市场要求提前）**
   - 完成标准: 五维风险评分和总体建议
   - 评分模板:
     | 维度 | 低风险 | 中风险 | 高风险 |
     |---|---|---|---|
     | 技术 | 开发完成、测试通过 | 少量问题、进度可控 | 大量问题、规格不满足 |
     | 市场 | 非战略、可推迟 | 重要但可受控销售 | 战略必须、无法推迟 |
     | 物料 | 无专用料、货期充足 | 部分专用料、货期紧张 | 大量专用料、货期严重不足 |
     | 试制 | 产能充足、工艺成熟 | 产能紧张、需协调 | 未验证、工艺困难 |
     | 开局 | 人员充足、无冲击 | 人员紧张、有冲击 | 人员不足、严重冲击开发 |
   - 决策规则: 任一维度高风险 → 不建议提前；全部中风险以下 → 可战略满足

4. **规范实验局物料计划（如处于实验局阶段）**
   - 完成标准: 实验局物料计划下达并跟踪
   - 关键动作:
     - 提前2-3个月启动物料准备（系统联调启动时提交开局申请）
     - 单板BOM清单提前实施（避免加工时开发人员花费大量精力领料备料）
     - 需求规模 = 实验局需求 + 小批量试产 + 展厅(≥2套) + 参展/演示 + 培训/备件 + 周边PDT需求 + IT需求
     - 实验局发货必须签订实验局合同或借货合同，不允许自带发货

5. **处理研发自购申请（如遇到紧急需求）**
   - 完成标准: 判断是否符合自购条件并指导操作
   - 条件检查清单:
     - [ ] 开发测试或开局紧急需求？
     - [ ] 正常采购无法满足或采购建议自购？
     - [ ] 非关键器件（外围器件如阻容、功率管、接插件）？
     - [ ] 国内交货、人民币付款？
     - [ ] 每月≤3次、金额≤3万（超1万需产品线总监审批）？
   - 判停条件: 不符合任一条件 → 走正常采购流程

6. **输出研发物流计划文档**
   - 完成标准: 包含阶段判定、选型评估/风险评分、物料计划、责任人和跟踪表

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯软件/SaaS产品开发（无物理BOM和物料选型）
- 成熟产品的量产供应链管理（用 production-control-operator 或 tom-order-manager）
- 标准件的日常采购（用 procurement-strategy-designer 等采购skill）

### 作者在书中警告的失败模式

- 开发后期才引入采购谈判："产品组迫于进度最终选作此器件...供应商了解我们经过半年多开发，方案变更可能性很小，因此价格下降十分困难"
- 忽视器件实验阶段风险：选用厂家实验阶段器件，"厂家器件推出的进程往往对我们产品进度冲击十分大"
- 未掌握器件生命周期："在产品完成开发准备市场发布时，TI宣布器件在半年后停产"
- 实验局物料无合同发货：导致研发资产流失

### 作者的盲点 / 时代局限

- 基于通信设备的长开发周期（数月到数年），对消费电子等短周期迭代的适用性需调整
- 器件选型主要关注TQRDC中的T/Q/R/D/C，未明确涉及ESG/碳足迹等现代供应链关注点
- 研发自购的限额（3万/3次）基于2000年前后的物价水平，现代需调整

### 容易混淆的邻近方法论

- 器件选型 vs 供应商认证: 器件选型由研发主导关注技术+可采购性，供应商认证由采购主导关注质量体系+商务条款；二者应协同但常割裂
- 研发物流 vs 量产物流: 研发物流风险高、批量小、变更多；量产物流追求稳定、低成本、高效率
- 实验局 vs 试产: 实验局面向客户现场验证（BETA测试），试产面向内部工艺验证；物料需求和时间节点不同
