# org-top-designer

从"三湾改编"到华为基本法，帮助企业创始人完成从业务能手到组织高手的蜕变。提供组织顶层设计的完整方法论：通过压缩编制、民主制度、价值观下沉、人才评价体系，建立不依赖个人的制度化组织能力。

## When to activate

当用户面临"公司大了管不过来""创始人疲于奔命""文化无法传承""新员工与老员工价值观冲突""需要从业务管理转向组织设计"时激活。

适用于：企业从0到1后的组织升级、跨区域/多层级扩张、创始人领导力瓶颈、企业文化制度化。
不适用于：初创期（<50人）尚无稳定业务、纯技术问题、已有成熟职业化管理体制的微调。

关键 trigger：组织顶层设计 / 三湾改编 / 政委体系 / 业务能手到组织高手 / 创始人瓶颈 / 华为基本法 / 组织传承 / 顶层设计 / 支部建在连上 / top-level org design。

## Core Framework

### 1. 核心矛盾：业务能手 vs 组织高手

- **业务能手**：精通产品研发、市场销售、客户谈判，靠个人英雄主义推动公司从0到1
- **组织高手**：设计制度、流程、文化、人才机制，让组织不依赖任何个人也能有序运转
- **分界线**：当员工数量超过个人可覆盖范围（通常100人以上），或跨区域发展时，必须从业务能手进化为组织高手

### 2. 三湾改编三大决策（组织设计原型）

| 决策 | 核心动作 | 现代企业管理映射 |
|------|----------|------------------|
| 压缩编制 | 缩编成团、再缩编成连 | 扁平化组织、减少管理层级、消灭叠床架屋 |
| 民主制度 | 士兵委员会、官兵平等 | 员工参与、信息透明、分配公平、破除雇佣关系 |
| 支部建在连上 | 党组织下沉到班排连 | 价值观/文化下沉到最小业务单元、HRBP/政委体系 |

### 3. 阿里巴巴实践：政委体系

- **垂直管理**：政委不向业务线汇报，隶属总部HR垂直管理
- **双首长负责**：司令（业务负责人）+ 政委（HR/文化负责人），司令管短期业绩，政委管长期文化
- **分级设置**：小政委（基层单元）→ 大政委（区域/事业部）→ HR负责人（集团）
- **核心职能**：人力资源体系搭建、文化倡导与诠释、公司与员工沟通桥梁

### 4. 华为实践：从人治到制度

- **《华为基本法》**：将任正非的经营管理理念系统化为公司纲领，让员工行为有规则可依
- **人力资源评价体系**：科学化人才评价，摆脱对创始人"死盯"的人治管理
- **人力资源管理委员会**：从集团到基层层层渗透，专职"管人"，类似"支部建在连上"
- **任职资格体系**：每个岗位有明确的级别、标准、晋升通道，实现人岗匹配、易岗易薪

### 5. 组织顶层设计的五层架构

1. **理念层**：愿景、使命、核心价值观（回答"为什么存在"）
2. **制度层**：基本法、商业行为准则、干部标准、决策制度（回答"游戏规则是什么"）
3. **机制层**：评价、分配、激励、晋升、淘汰（回答"凭什么得到回报"）
4. **结构层**：组织架构、委员会体系、首长负责制、授权体系（回答"谁决策、谁执行"）
5. **文化层**：同心圆放射状文化能量场，从中心向边缘传递（回答"我们相信什么"）

## Workflow

1. **诊断**：创始人时间分配（多大比例对内管理 vs 对外管理）、组织层级数量、信息失真程度
2. **铸魂**：提炼并书面化公司愿景、使命、核心价值观（可参考《华为基本法》形式）
3. **建制**：建立与业务匹配的人才评价、激励、晋升、淘汰机制
4. **下沉**：将文化/HR能力下沉到最小业务单元（如政委体系、HRBP、思想导师）
5. **松绑**：通过委员会体系、首长负责制、授权机制，让创始人从日常事务中解脱
6. **固化**：通过IT系统、流程、标准化操作，实现"无生命管理"

## Output format

当被激活时，按以下结构输出：

1. **创始人角色诊断**：当前处于业务能手阶段还是组织高手阶段
2. **顶层设计蓝图**：理念层→制度层→机制层→结构层→文化层的现状与差距
3. ** immediate 行动项**：接下来90天内可落地的3个组织设计动作
4. **制度模板建议**：基本法/干部标准/决策制度中优先级最高的一项

## Notes

- 组织顶层设计不是一次性工程，而是随业务演进的持续迭代过程。
- 伟大的领袖不一定是业务能手，但一定是组织设计工程师。——柯林斯
- 文化一旦深入人心，80%的管理动作都可以取消。反之，文化沦丧则管理丛生。
