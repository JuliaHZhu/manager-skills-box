# 可选择性评估 (Optionality Evaluation)

## R — 原文 (Reading)

> "选择权——以及可选择性，即选择权的特征——可以带我们去很多地方。从根本来说，选择权能让你具备反脆弱性，它帮助你从不确定性的积极面中受益，同时也不会因其消极面而经受严重的伤害。"
>
> — 塔勒布, 第四卷第12章

---

## I — 方法论骨架 (Interpretation)

可选择性评估是一种决策框架：在不确定环境中，优先选择"期权结构"的选项，而非"预期收益最高"的选项。

一个选项具有可选择性，当且仅当：最坏情况损失已知且可承受（下行封顶），最好情况收益理论上无限（上行不封顶），且不需要准确预测未来就能获益。就像金融期权——你付一笔期权费，有权在未来以固定价格买入，但无义务执行；如果市场走势不利，你最大损失就是期权费。

塔勒布的核心洞察是：生活中很多高价值选择（创业、写作、学习跨领域技能、建立弱关系网络）天然具有期权结构——成本有限，但可能带来翻转式回报。反过来，很多看似"稳定"的选择（固定工资、单一雇主、窄专技能）实际上是"卖出期权"——放弃了上行可能性，却保留了全部下行风险。

## A1 — 书中的应用 (Past Application)

### 案例 1: 泰勒斯的橄榄油压榨机
- **问题**: 古希腊哲学家泰勒斯如何在没有财富的情况下，证明自己可以凭智慧赚钱？
- **方法论的使用**: 泰勒斯没有预测橄榄会丰收，而是提前以低价租下了所有橄榄压榨机。如果橄榄歉收，损失很小（预付租金）；如果丰收，他以高价转租给农民，获得巨大收益。
- **结论**: 他购买了一个"期权"——有权使用压榨机，但没有义务。不需要预测天气或市场。
- **结果**: 泰勒斯大赚，证明了智慧可以转化为财富，且不需要预测能力。

### 案例 2: 技术创新史
- **问题**: 为什么很多重大技术创新不是规划出来的，而是"意外发现"的？
- **方法论的使用**: 技术史中，大多数重要发明（互联网、激光、青霉素、微波炉）都是研究者在解决A问题时意外发现了B应用。他们拥有"可选择性"——研究成本已经沉没，但成果可能有超出预期的用途。
- **结论**: 资助基础研究和自由探索，本质上是在批量购买"技术期权"。
- **结果**: 计划性研发（如苏联模式）效率远低于试错式探索（如硅谷模式）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到多个offer/机会，纠结"稳定的但上限低"vs"不确定但可能翻转"时
2. 想尝试副业/创业/新项目，但担心失败代价时
3. 评估一个商业模式或产品策略是否可持续时
4. 思考职业技能的"保值性"——哪些技能像期权、哪些像负债

- "失败了会怎样？"

- "选择权"
- "下行有限 / downside有限"

### 与相邻 skill 的区分

- 与 `barbell-strategy` 的区别: 可选择性评估关注单个选项的期权结构，杠铃策略关注多个选项的组合分配。
- 与 `convexity-spotting` 的区别: 凸性识别是可选择性的数学表达，可选择性评估更偏向生活/商业决策中的直觉判断。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **列出候选选项**
   - 完成标准: 明确用户正在考虑的2-5个选项

2. **对每个选项评估可选择性六维度**（每项0-3分）
   - 下行封顶: 最坏损失是否已知且可承受？（0=不可控；3=几乎无损失）
   - 上行不封顶: 成功时收益是否可规模化？（0=固定；3=无限）
   - 退出成本: 进展不顺时退出是否容易？（0=极难；3=随时可退）
   - 试错友好: 是否允许多次低成本迭代？（0=一次定生死；3=天然迭代）
   - 预测依赖度: 是否需要准确预测？（0=完全依赖；3=完全不需要）
   - 时间友好: 持有越久是否越有利？（0=时间敌人；3=时间增益）

3. **计算总分并排序**
   - 完成标准: 每个选项0-18分，按分数排序
   - 判读: 0-6分=低可选择性（脆弱）；7-12分=中等；13-18分=高可选择性（反脆弱）

4. **给出建议**
   - 完成标准: 明确推荐高可选择性选项，并解释其期权结构（为什么下行有限、上行无限）
   - 判停条件: 若用户最偏好的选项得分很低，要求其解释该选项的凸性证据，否则建议杠铃化改造

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 涉及道德/伦理抉择（可选择性框架不处理"应该做什么"，只处理"哪个结构更有利"）
- 已经承诺的长期关系（如婚姻、合伙）中试图"评估退出成本"——这会伤害信任基础
- 需要精确计算的金融衍生品定价（应使用Black-Scholes等专业模型，而非直觉框架）

### 作者在书中警告的失败模式

- **假期权**: 看似有选择权，实际上退出成本极高（如"试用期"后发现沉没成本太大而不敢退出）
- **负期权**: 不仅没有选择权，还在不断累积"卖出期权"的义务（如签了对赌协议、接受了限制性股票）
- **过度分散的期权**: 同时持有太多低质量期权，导致资源分散，没有一个能深入执行

### 作者的盲点 / 时代局限

- 塔勒布主要用金融期权类比，但生活中的"期权"往往没有明确的"期权费"和"行权日"，评估更主观
- 书中较少讨论"如何选择何时行权"——拥有期权不等于知道何时使用它

### 容易混淆的邻近方法论

- 与"机会成本分析"的区别: 机会成本关注"放弃了什么"，可选择性关注"保留了什么不对称权利"
- 与"风险矩阵"的区别: 风险矩阵通常是对称的（高概率高损失），可选择性是结构性的不对称
