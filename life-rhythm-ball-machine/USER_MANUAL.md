# 生活节律发球机（life-rhythm-ball-machine）

**用户说明书 v1.0**

---

## 一、这是什么

生活节律发球机是一个**一次装填、零决策执行**的生活节律管理系统。

它的工作逻辑很像一台扭蛋机：你先往里面倒进一批彩色球（装填阶段），然后每天早上踩一脚（触发抽取），机器吐出三个球，告诉你今天早中晚各做什么。你不需要选、不需要改、不需要纠结——**直接做就行**。

核心理念：**相信往里倒球的自己**。装填时的你是最诚实的，执行时不要怀疑当时的判断。

---

## 二、它解决什么问题

| 问题 | 发球机的解法 |
|------|-------------|
| 每天早上纠结"今天干什么" | 前一晚已生成好，醒来直接看 |
| 计划列完随时改，改着改着就废了 | 当日日程一旦生成，**不可修改、不可重抽** |
| 想多读书但一周后发现根本没读 | 装填时设定比例（如读书30%），系统自动配额 |
| 收藏夹里囤了200本书单从不看 | 书单直接导入球池，变成"读书球"进入日程 |
| 状态差时抽到"读50页书"完全不想动 | 能量分级机制，保底低能量球 |
| 多人共用nanobot，数据和偏好混在一起 | 角色卡隔离，每人独立存档 |

## 三、核心概念

### 3.1 球（Ball）

球是系统中最小执行单元，一条具体的、可执行的活动描述。

- **读书球**："读《反脆弱》第3章，30页"
- **休息球**："午睡30分钟，不设闹钟"
- **社交球**："给汐汐发一条语音"
- **探索球**："去一家从没去过的餐厅"
- **趣味球**："学一首新歌，任意语言"

每个球可选标记能量等级：🔥高 / ⚡中 / 🌙低

### 3.2 球池（Ball Pool）

球池是某个角色在某一周期内的全部待抽取球集合。

比如你设定未来10天的比例为：读书30% / 休息30% / 自由探索20% / 社交20%，系统生成 10×3=30 个球，按配额分配为：读书9个、休息9个、探索6个、社交6个。

### 3.3 角色卡（Profile）

每个用户有一张角色卡，包含：
- 昵称 + 头像emoji
- 独立的球库（你收藏的活动清单）
- 独立的装填比例偏好
- 独立的执行历史与统计

**角色之间数据完全隔离。** 雷管的球不会出现在汐汐的机器里。

### 3.4 装填（Fill）

一次性配置未来N天的活动比例，系统自动生成球池。这是整个周期中**唯一需要你做决策**的环节。

### 3.5 三球制

每天三个场次，各一个球：
- 🌅 **早场**（08:00–11:00）
- 🌞 **中场**（13:00–17:00）
- 🌙 **晚场**（19:00–23:00）

场次仅提供时间参考，球的内容与场次无强制绑定。一个"读书球"完全可能出现在晚场。

## 四、快速上手

### 步骤1：创建角色卡

```
/发球机 创建角色 昵称=雷管 头像=🐧
```

系统返回：
```
🐧 角色卡「雷管」已创建。
当前绑定角色：雷管
```

### 步骤2：填充你的球库（可选但推荐）

把你的收藏夹导入成球：

```
/发球机 导入书单
《反脆弱》
《黑天鹅》
《统计学习方法》
《像计算机科学家一样思考Python》
```

也可以导入片单、餐厅清单、旅行清单。导入后它们会变成对应类别的候选球。

### 步骤3：装填周期

```
/发球机 装填 天数=10
读书: 30%
休息: 30%
自由探索: 20%
社交: 20%
低能量保底: 是
混入趣味球: 3
```

系统返回：
```
✅ 装填完成
周期：10天 | 总球数：30
读书 9球 | 休息 9球 | 探索 6球 | 社交 6球
趣味球已混入：3
低能量保底：每天至少1个🌙球

⚠️ 提醒：装填完成后，在周期结束之前，你将无法修改任何日程。
相信此刻的判断。
```

### 步骤4：每日执行

**每天早上8:00**，系统会自动推送早报：

```
🎰 雷管的今日三球（第3/10天）

🌅 早场 | 读《反脆弱》第3章，30页 | 🔥高
🌞 中场 | 午睡30分钟 | 🌙低
🌙 晚场 | 给汐汐发一条语音 | ⚡中

昨日：3/3 完成 ✅
周期进度：████████░░ 30%
```

你也可以随时手动触发：
```
/发球机 今日
```

### 步骤5：完成或跳过

执行完一个球：
```
/发球机 完成 晚场
```

实在做不了：
```
/发球机 跳过 早场 理由=状态太差
```

**注意**：跳过会留下记录，但不补球。今天就是2个球，不会变成4个。

## 六、硬规则（不可违背）

1. **当日日程不可修改**
   - 不能重抽、不能替换、不能删除、不能调整顺序。
   - 只有「完成」和「跳过」两个选项。
   - 改日程的权限在"装填时的你"手里，不在"现在的你"手里。

2. **跳过不补球**
   - 今天跳过1个，今天就只有2个球。
   - 跳过记录会计入统计，与完成区分显示。

3. **周期内不可重新装填**
   - 当前周期的球抽完之前，不能覆盖装填。
   - 提前结束周期 = 放弃剩余全部球，需确认。

4. **球库枯竭则停**
   - 如果某类别球库数量不足装填配额，系统拒绝装填，提示你补充球库。
   - 不允许用重复内容凑数。

## 七、能量分级说明

每个球标记的能量等级帮助你在状态波动时仍能保持执行：

| 等级 | 标识 | 典型内容 | 使用场景 |
|------|------|---------|---------|
| 高 | 🔥 | 读书50页、健身1小时、写2000字 | 状态好时抽到，顺水推舟 |
| 中 | ⚡ | 读20页、散步30分钟、整理笔记 | 日常默认档位 |
| 低 | 🌙 | 看一集纪录片、午睡、听播客、发呆 | 状态差时保底，确保能启动 |

**低能量保底策略**：装填时勾选后，系统确保每天三球中至少有一个🌙球。即使你今天只想躺平，也还有一个"躺着能做的事"。

## 八、趣味球库

系统内置一批预置趣味球，装填时可选择混入数量。它们来自以下类别：

- **探索**：去一家从没去过的餐厅、走一条没走过的小路、尝试一种新的交通方式
- **社交**：给老朋友发一条语音、约一个人吃饭、在社交媒体发一条原创内容
- **创作**：拍一张满意的照片、写一段140字的观察、画一幅简笔画
- **身体**：做一组拉伸、喝一杯没喝过的饮品、早睡一小时
- **认知**：读一篇论文摘要、看一个TED演讲、整理一个旧笔记

趣味球自动匹配对应类别参与比例分配。

---

## 九、统计指标

系统记录以下指标供回顾：

- **完成率**：周期内完成球数 / 总球数
- **跳过率**：周期内跳过球数 / 总球数
- **类别分布**：实际完成的各类别占比 vs 装填时的设定比例
- **连续完成天数**：连续N天完成全部三球
- **能量分布**：高/中/低能量球的完成率对比
- **平均执行时间**：从"看到球"到"标记完成"的间隔（需手动记录或估算）

## 十、常见问题

**Q：我今天真的很忙，三个球都做不了怎么办？**
A：全部跳过。跳过记录会计入统计，诚实地面对数据比美化数据更有价值。

**Q：我抽到一个不想做的球，能不能换一个？**
A：不能。这是系统的核心约束。你可以跳过它，但抽出来的球不会回去，也不会换新的。

**Q：比例设定后可以改吗？**
A：当前周期内不能改。周期结束后重新装填时可以调整。如果你发现"读书30%"太多或太少，下一个周期改就是。

**Q：两个人能共享一个球吗？比如"和汐汐聚餐"？**
A：初版不支持实时协同通知，但你可以手动创建一个社交球"约汐汐聚餐"，各自在自己的机器里执行。

**Q：球库要准备多少个球才够？**
A：建议每类别至少准备周期天数×3×比例 的1.5倍。比如10天周期、读书30%，至少需要 10×3×0.3×1.5 ≈ 14 个读书球。

**Q：可以跟todo-ball-machine一起用吗？**
A：可以。todo-ball-machine管"必须做的事"（工作/学习/家务），发球机管"想做的事"（读书/探索/社交/休息）。两者互补，不冲突。

## 十二、技术说明

- **数据存储**：单文件 `state.json`，按角色隔离，无需外部数据库。
- **早报推送**：每日08:00自动推送，依赖系统cron。
- **随机算法**：标准random.sample，不重复抽取，球池抽空即周期结束。
- **多用户隔离**：`profile_id` 作为全部数据前缀键，严格隔离。
