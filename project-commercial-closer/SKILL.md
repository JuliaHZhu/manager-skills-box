# project-commercial-closer

当用户需要打通售前与售后、实现项目经营闭环、或在交付阶段持续创造商业价值时激活。

适用于：交付项目经理、解决方案经理、项目群经理、需要"营赢盈"全周期思维的售前售后团队。

不适用于：纯技术交付无商业目标、一次性交易无需后续经营、售后运维与售前完全隔离的组织。

关键 trigger：营赢盈 / 售前售后拉通 / 项目经营 / 项目盈利 / 交付即销售 / 合同盈利 / 商业价值闭环 / 项目CEO。

## 核心理念：营 → 赢 → 盈

华为项目经理一线作战实录提炼的三段论：

> **营**：以客户为中心，瞄准客户痛点  
> **赢**：助力客户商业成功，实现双赢  
> **盈**：售前售后拉通，一切为了盈

---

### 营：价值主张对准客户痛点

在项目初期ATI（立项决策）阶段，只有以客户为中心，认真听取客户需求，挖掘客户痛点，提出正确的价值主张，才会得到客户认可。

**操作要点：**
1. 仔细分析客户需求和战略，识别真实痛点（而非表面需求）。
2. 提出能够解决痛点的差异化方案，让客户感受到"你理解他们的真实需求"。
3. 用现网试点、对标参观等方式，让价值主张可感知、可验证。

**案例**：客户希望用4G吸引用户实现弯道超车，但语音呼叫时延高。华为提出"全部新建会使网络更复杂、效率更低"，建议"升级改造大部分现网设备+少量新建"，既节省投资又符合客户"更简化网络"的内在诉求。该价值主张迅速获得客户高层共鸣。

### 赢：助力客户商业成功，实现双赢

在ATB（投标决策）阶段，展现独特价值，让客户坚定支持你。

**操作要点：**
1. 识别客户深层诉求：客户不仅买设备，更希望找到能一起为未来运营和新商业模式实践的合作伙伴。
2. 主动提供商业咨询（BC）：通过数据分析、用户调研、渠道访谈，对客户业务发展做全面"体检"。
3. 展示核心能力和新价值主张：如NFV/VoLTE能力开放策略，助力客户探索新商业套餐。
4. 将合作提升到战略层面：在高层战略合作峰会上签署合作协议，获得集团批准。

**关键认知**：让客户称赞你是"真正的战略合作伙伴"，而非简单的设备供应商。

### 盈：售前售后拉通，一切为了盈

在合同决策（ATC）和谈判阶段，把服务纳入一起考虑，识别合同场景、销售/交付/验收/回款时可能面临的风险。

**操作要点：**
1. **学会"读"合同和"管"合同**：系统学习6421、概预算等知识。
2. **售前售后双轨迹并行**：
   - 识别合同场景、交付风险、验收陷阱、回款障碍。
   - 制定和刷新概预算，发现服务合同亏损点时，积极拓展网络集成服务、培训等，扩大收入喇叭口，弥补亏损。
3. **不冒进，规避交付风险**：加强和集团沟通，采用试点省规范。
4. **交付即销售**：在交付过程中不断发掘新的商业机会，实现项目经营的持续盈利。

**关键认知**：未来行业环境越来越复杂，必须在促进营、赢、盈方面多思考多行动。**只有想办法帮助客户成功，我们才能成功。**

---

## 使用流程

1. **营阶段**：重新梳理当前项目的客户痛点，是否真正被满足？价值主张是否足够差异化？
2. **赢阶段**：客户是否把你定位为"合作伙伴"而非"供应商"？是否提供了超越产品本身的商业咨询价值？
3. **盈阶段**：检查当前合同的盈利空间，售前和交付团队是否共享了同一套风险清单？是否有扩大服务收入的计划？
4. **闭环**：项目结束后，复盘营赢盈三个阶段中哪个环节 weakest，形成下一个项目的改进清单。
