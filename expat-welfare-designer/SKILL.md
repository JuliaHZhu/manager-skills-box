# expat-welfare-designer

## R — 原文 (Reading)

> "食堂是半个家，要让员工吃得饱、吃得好、吃得放心。吃饱了才不想家。生活不搞好，海外艰苦奋斗就没有基础。代表处都要有伙食管理委员会，由家属轮流来做，定期检查食堂账目、采购和卫生。"
>
> — 任正非, 第1、4、6章

---

## I — 方法论骨架 (Interpretation)

海外员工保障体系设计是一套围绕"吃饱了才不想家"理念、以自治+监督为核心的四支柱框架。

核心逻辑：

1. **食堂即半个家**：海外食堂不仅是吃饭场所，更是员工心理支撑。通过伙委会自治（家属轮流监督采购/验收/卫生）、中外共餐、指定环境采购（大超市优先），确保"吃得饱、吃得好、吃得放心"。

2. **医疗保障前置**：在海外配置24h待命医生，员工随身携带保险卡和紧急联系卡，战乱/危险国家增加血检、疫苗等预防性措施。

3. **住宿与安全**：宿舍统一管理，禁止酗酒，定期抽查卫生和安全，防盗防泄密。

4. **关系润滑**：建立小费制度（员工每月出10-20美金给厨师/司机/保姆），作为感恩行为改善服务关系；保障家属探亲签证。

核心机制是"自治+监督"而非"机关直管"——机关出政策基线，代表处自治执行，伙委会/员工监督。

## A1 — 书中的应用 (Past Application)

### 案例 1: 东南非小费制度
- **问题**: 海外服务人员（厨师、司机、保姆）积极性不高，服务质量下降。
- **方法论的使用**: 在东南非实行员工每月出10-20美金的小费制度，作为感恩行为改善关系。
- **结论**: 小钱改善大关系，服务人员有尊严、员工有感激。
- **结果**: 服务关系改善，员工满意度提升。

### 案例 2: 尼日利亚水质保障
- **问题**: 尼日利亚等国水资源存在严重问题，员工饮水安全无法保障。
- **方法论的使用**: 专门采购欧美先进净水设备，费用纳入公司空耗成本而非伙食分摊。
- **结论**: 海外保障要因国施策，安全问题不能算伙食账。
- **结果**: 员工饮水安全得到保障，健康风险降低。

### 案例 3: 法国代表处食堂争议
- **问题**: 法国代表处认为当地餐饮发达，想关闭食堂。
- **方法论的使用**: 任正非明确表示不赞成，要求与周边餐厅签协议补贴，不能让员工下班买菜做饭。
- **结论**: 食堂是半个家，是战斗力的组成部分，不能因当地条件好就取消。
- **结果**: 法国代表处保留食堂或补贴机制，员工精力集中在工作上。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 企业开始海外扩张，需要为外派员工设计吃住行医保障体系。
2. 海外代表处员工抱怨生活条件差、思乡情绪重、工作积极性下降。
3. 需要平衡"保障成本"和"员工满意度"，不想无限制投入。
4. 海外食堂/宿舍管理混乱，出现卫生问题、贪污浪费、安全隐患。
5. 不同国家差异大，不知道各国保障标准怎么定。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **国情风险评估**
   - 完成标准: 评估目标国家在吃住行医安全四个维度的风险等级（高/中/低），识别特殊需求（水质、战乱、疫情等）。

2. **四支柱设计**
   - 完成标准: 针对该国设计食堂方案（自营/外包/补贴）、医疗保障（医生/保险/预防）、住宿安全（集中/分散/标准）、关系润滑（小费/探亲/文化活动）。

3. **自治组织建立**
   - 完成标准: 建立伙食管理委员会（伙委会）或同类员工自治组织，明确其监督职责和运作机制。
   - 判停条件: 若当地法律/文化不允许员工自治组织，改为行政直管+定期员工满意度调研。

4. **基线与成本控制**
   - 完成标准: 为该国生活成本设定基线，明确公司承担部分vs员工个人承担部分，避免福利无限扩张。

5. **输出保障方案**
   - 完成标准: 输出《海外员工保障方案》，含国情评估、四支柱设计、自治机制、成本基线、应急预案。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯本土企业、无海外业务、无外派员工。
- 员工短期出差（<3个月）——出差用差旅标准即可，不需要建保障体系。
- 已外包给国际 relocation 公司（如Cartus、SIRVA）——他们的体系已成熟。
- 战乱/极端危险国家且企业无能力保障基本安全——应考虑撤离而非设计保障。

### 作者在书中警告的失败模式

- **关闭食堂**: 认为当地餐饮发达就取消食堂，导致员工精力分散、没有"家"的感觉。
- **一刀切标准**: 用全球统一标准管所有国家，忽视当地特殊需求（如水质、宗教饮食）。
- **忽视医疗前置**: 等员工病了才处理，不配置24h医生、不做预防性血检。

### 作者的盲点 / 时代局限

- 华为外派员工以中方为主，本框架对"本地化外籍员工"的保障设计较少。
- 小费制度在中国企业文化中极为罕见，推行时可能遇到文化阻力。
- 书中案例以发展中国家为主，对发达国家/高成本国家的保障设计参考有限。

### 容易混淆的邻近方法论

- 与"国际派遣政策（relocation policy）"的区别: 后者是HR层面的薪酬/税务/签证规则，本 skill 是行政层面的生活保障运营。
- 与"员工关怀/EAP"的区别: EAP聚焦心理健康，本 skill 聚焦物理生活保障。
