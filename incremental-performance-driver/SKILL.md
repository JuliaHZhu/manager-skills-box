# incremental-performance-driver

增量绩效与价值分配：通过「价值创造→价值评价→价值分配」闭环，以增量绩效驱动组织增长，用工资包和预算管控实现"三个人干五个人的活拿四个人的工资"。

## 触发条件

当用户需要设计增量绩效管理体系、讨论价值分配机制、工资包管理、预算管控编制、或讨论"绩效管理是为了赚钱还是分钱"时激活。

**关键词**：增量绩效 / 价值分配 / 工资包 / 预算管控 / 三个人五个活 / 价值闭环 / 价值创造 / 价值评价 / 分钱机制 / 人均效益

## 使用说明

### 第一步：价值创造→评价→分配闭环

**华为核心观点**：真正的驱动力在于"把钱分好"，但钱从客户来，所以首先是价值创造。

**三环闭环**：

```
价值创造 → 价值评价 → 价值分配
    ↑___________________↓
```

1. **价值创造**：
   - 谁创造了价值？全体员工
   - 价值来源：客户（只有客户给企业钱）
   - 聚焦：把企业最终价值贡献都聚焦在客户身上

2. **价值评价**：
   - 科学评价谁创造了多少价值
   - 绩效管理是价值评价最重要的工具
   - 评价原则：责任结果导向，客观事实和数据为依据

3. **价值分配**：
   - 根据贡献度分配利益
   - 分配机制要公平、透明、刚性
   - 不患寡而患不均 → 解决"凭什么他多我少"

**华为成功公式**："评功、行赏、打胜仗"七个字

**STOP检查点**：
- [ ] 是否建立了从价值创造到评价再到分配的完整闭环？
- [ ] 价值评价是否有科学、客观的标准？
- [ ] 分配机制是否有足够说服力，能让员工接受差异？

### 第二步：增量绩效管理 — 三个人干五个人的活拿四个人的工资

**核心公式**：
- **3个人干5个人的活，拿4个人的工资**
- 本质：提高人均效益，而非简单增加人头

**增量绩效的两个维度**：

1. **增量产出**：
   - 相比去年/上期，新增了多少收入、利润、客户
   - 新增了多少专利、技术突破、产品
   - 增量部分给予更高激励权重

2. **增量效率**：
   - 人均营收增长率
   - 人均利润增长率
   - 费用率下降幅度

**增量绩效的障碍**：
1. 管理者习惯加人解决问题，不习惯提效
2. 部门壁垒导致重复劳动
3. 缺乏增量激励机制，干多干少一个样
4. 预算编制按人头而非按任务

**增量绩效的方法**：
1. **工资包管理**：部门工资包与增量产出挂钩，增人不增包
2. **编制管控**：编制与增量效益挂钩，效益增长才能增编
3. **及时激励**：对增量突破给予即时奖励
4. **赛马机制**：同层级竞争，增量突出者重奖

**STOP检查点**：
- [ ] 绩效管理是否关注了增量产出而非仅关注绝对值？
- [ ] 是否建立了"增人不增包"的工资包管理机制？
- [ ] 激励是否向增量突破者倾斜？

### 第三步：工资包管理

**三级工资包体系**：

1. **公司级工资包**：
   - 与公司整体效益挂钩
   - 公式：工资包 = 基线工资包 × 效益增长系数
   - 效益好则总包大，效益差则总包小

2. **部门级工资包**：
   - 与部门组织绩效挂钩
   - 部门绩效好则部门工资包大
   - 部门增员不自动增包，需从部门总包中调剂

3. **个人工资**：
   - 与个人绩效挂钩
   - 在部门工资包内分配
   - A类员工拿高比例，C/D类员工不增薪甚至降薪

**工资包管理原则**：
- **弹性原则**：工资包不是固定数，随效益波动
- **增量原则**：工资包增长来自效益增长，不是自然增长
- **约束原则**：部门不能突破工资包总额，除非效益超额

**STOP检查点**：
- [ ] 工资包是否与公司/部门效益直接挂钩？
- [ ] 部门增员是否必须自行在工资包内调剂？
- [ ] 个人薪酬调整是否在部门工资包约束下进行？

### 第四步：预算管理与编制管控

**预算管理原则**：

1. **战略导向**：
   - 预算编制从战略目标出发
   - 资源向战略重点倾斜
   - 不是按历史惯性分配

2. **绩效挂钩**：
   - 预算执行与绩效达成挂钩
   - 绩效好的部门预算有保障
   - 绩效差的部门预算压缩

3. **滚动调整**：
   - 季度回顾预算执行情况
   - 根据市场变化动态调整
   - 不是年初定了就不变

**编制管控原则**：

1. **编制与战略任务匹配**：
   - 需要做什么任务 → 需要什么人 → 定编制
   - 不是部门要多少人就给多少人

2. **编制与效益挂钩**：
   - 人均效益是核心指标
   - 效益增长才能增编
   - 效益下降要缩编

3. **编制刚性**：
   - 编制上限严格控制
   - 超编需特批
   - 鼓励内部挖潜、流程优化

**STOP检查点**：
- [ ] 预算编制是否从战略目标出发而非历史惯性？
- [ ] 编制增长是否与人均效益挂钩？
- [ ] 是否有预算滚动调整机制？

### 第五步：绩效管理是为了赚钱还是分钱？

**核心区别**：

| 维度 | 赚钱导向 | 分钱导向 |
|------|----------|----------|
| 目的 | 提升组织绩效，实现战略目标 | 分配奖金，完成考核任务 |
| 管理者角色 | 战略推动者 | 打分统计员 |
| 员工感受 | 被激发，愿意多干 | 被考核，担心被扣钱 |
| 结果 | 组织效益增长 | 内部矛盾增加 |

**华为观点**：
- 绩效管理是管理者的"家庭作业"，不是HR的"家庭作业"
- 绩效管理的最终目的不是让员工达到期望绩效，而是让员工出于意愿也愿意付出超越职责的努力
- 如果只是为了分钱，不需要复杂绩效管理，打分汇总就够了
- 先赚钱，再分钱；钱是分不完的，但赚钱的逻辑可以持续

**实践建议**：
1. 把绩效管理纳入管理者任职资格认证
2. 管理者绩效与其团队的组织绩效挂钩
3. 绩效结果必须刚性应用，但应用是为了激励而非惩罚
4. 让员工看到：绩效好→收入多→成长快→有尊严

**STOP检查点**：
- [ ] 管理者是否把绩效管理当成自己的核心职责？
- [ ] 绩效管理的沟通重点是在"如何做得更好"还是"为什么扣你分"？
- [ ] 员工是否能清晰看到绩效与回报的正向关系？

## 反模式警告

⚠️ **以下做法会破坏增量绩效管理**：
1. 按人头平均分配预算和工资包，不与效益挂钩
2. 增人自然增预算，导致人浮于事
3. 只关注分钱公平，不关注赚钱能力
4. 绩效目标年年相同，没有增量要求
5. 预算年初定死，年中不调，脱离实际
6. 编制管理宽松，部门随意要人

## 关键公式

- **人均效益** = 总产出 / 总人数
- **工资包弹性系数** = 实际效益 / 预算效益
- **增量激励系数** = (本期产出 - 基期产出) / 基期产出 × 激励权重
- **3人5活4工资** = 效率提升目标（人均产出提升67%，薪酬提升33%）
