# business-stage-appraiser

## Description
当用户需要为不同成熟度的业务设计差异化绩效目标、避免"一刀切考核"导致新业务被考死或成熟业务失去利润导向时激活。适用于多业务线企业、同时存在成熟/成长/拓展业务的公司、新产品导入期考核、新市场进入期考核、研发/营销跨阶段业务。不适用于：单一业务/单一产品的企业、已经明确的纯成本中心、无法区分业务阶段的组织。

Trigger: 业务阶段 / 三段论 / 成熟业务 / 成长业务 / 拓展业务 / 差异化考核 / 新业务考核 / 新市场考核 / 绩效目标设计 / 考核一刀切 / business stage appraisal

## I (Interpretation)
"一刀切"的绩效考核是扼杀业务多样性的元凶。三段论的核心逻辑：**业务阶段决定考核指标**。

**三段分类**:
1. **成熟业务（奶牛业务）**: 已有稳定收入和利润 → 考核**利润**为核心，兼顾效率
2. **成长业务**: 有收入但尚未规模化盈利 → 考核**市场增量/占有率**，利润权重降低
3. **拓展业务（开创性业务）**: 无收入无利润，处于0→1阶段 → 考核**关键成长节点**，而非财务结果

**关键成长节点设计**（以拓展业务为例）:
- 新市场进入: 准入指标（是否进入）> 客户关系指标（关键决策人是否到访/见面）> 收入指标
- 新产品研发: 技术里程碑 > 原型验证 > 客户试用 > 量产
- 新渠道建设: 渠道签约数 > 首批铺货 > 动销率

**激励原则**:
- 成熟业务：奖金与利润强挂钩，强调"挤奶"
- 成长业务：奖金与规模/增量挂钩，允许战略性亏损
- 拓展业务：用"节点奖"替代业绩奖，解决0和1的问题

## A1 (Past Application)
- **华为国际市场早期**: 西欧市场从0开始，进入英国/德国只有几百万销售额，但设"市场准入大奖"，按500万甚至更高考核，解决0和1的问题
- **内蒙空白产品**: 某产品在整个内蒙是空白，做进去后50万销售额按500万考核，获得市场准入大奖
- **刚果客户关系**: 年轻国家代表不懂销售，但把刚果电信负责采购的副总请到华为，即完成客户关系指标。他甚至把总统请到了华为，超额完成
- **华为三BG差异**: 运营商BG（成熟）利润权重高；企业BG（成长）收入利润对等；消费者BG早期收入规模优先

## E (Execution)

### Step 1: 业务阶段诊断
对每个业务单元/产品线/区域，回答：
- 是否有稳定的收入流？（有→成熟或成长，无→拓展）
- 是否已实现盈利？（是→成熟，否→成长或拓展）
- 是否已完成市场验证？（是→成长，否→拓展）

分类矩阵:
| 特征 | 成熟业务 | 成长业务 | 拓展业务 |
|------|---------|---------|---------|
| 收入 | 稳定 | 增长中 | 无或极少 |
| 利润 | 已盈利 | 可能亏损 | 亏损 |
| 目标 | 利润最大化 | 规模最大化 | 验证可行性 |

### Step 2: 按阶段设计核心指标与权重

**成熟业务**:
- 核心指标: 利润（50-60%）、收入（20-30%）、回款/现金流（10-20%）
- 辅助指标: 人均效率、客户满意度、成本控制
- 奖金逻辑: 从打的粮食里按比例分享

**成长业务**:
- 核心指标: 收入增量/市场占有率（40-50%）、收入规模（30-40%）、利润（10-20%）
- 辅助指标: 渠道建设数、客户数增长
- 奖金逻辑: 规模优先，允许战略性亏损，但需监控单位经济模型

**拓展业务**:
- 核心指标: 关键节点达成（100%）
- 节点示例:
  - 新市场: 准入（是否进入）→ 客户关系（关键决策人互动）→ 首单
  - 新产品: 技术可行性验证 → 原型测试 → 种子客户试用 → 小批量
  - 新渠道: 签约 → 首批进货 → 终端覆盖 → 首销
- 奖金逻辑: 节点奖/里程碑奖，不按收入利润考核

### Step 3: 设计节点指标（拓展业务专用）
节点指标设计原则：
1. **可验证**: 必须有明确的是/否或量化标准（如"客户CTO到访公司"、"完成3家种子客户试用"）
2. **前置性**: 节点必须是后续收入的必要前提（如"准入"是"收入"的前提）
3. **阶梯性**: 节点之间有先后依赖，完成前一节点才能解锁后一节点奖励
4. **放大系数**: 解决0和1问题的节点，考核价值可放大10倍甚至100倍（如50万首单按500万考核价值）

操作模板：
```
拓展业务考核表 = {
  "节点1_准入": {"权重": 40%, "标准": "进入X市场/签下Y客户", "奖金系数": 10x},
  "节点2_关系": {"权重": 30%, "标准": "关键决策人到访/高管互访", "奖金系数": 5x},
  "节点3_首单": {"权重": 30%, "标准": "完成首笔订单", "奖金系数": 2x}
}
```

## B (Boundary)
- 不适用于：单一业务企业（无阶段差异）、成本中心（无收入利润概念）、极度成熟且萎缩的业务（需考虑退出而非考核）
- 风险：节点设计不当可能导致"为了完成节点而完成节点"（如请客户来访但无实质进展），需配套质量评估
- 注意：同一人在不同阶段业务间切换时，考核标准需及时调整，避免用成熟业务标准要求拓展期行为
