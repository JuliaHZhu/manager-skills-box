# 瓶颈物料分配与ATP供应能力分析

## R — 原文 (Reading)

> 公用瓶颈物料在分配前，首先应根据该器件的采购计划提前期满足货期要求的那一期计划量的比例确定初步分配方案，然后根据如下分配原则进行调整：第一原则：合同/产品重要优先原则。根据物料所涉及合同/产品的重要程度先满足重要合同/产品的发货需求。第二原则：可启动生产原则。如果将该瓶颈器件分配给某产品，但由于其它器件欠料不能启动加工，则考虑将拟分配给该产品的数量转分给其它产品。第三原则：兼顾现实与将来。本次瓶颈物料分配后，提出下一批到货初步分配方案。
>
> — 华为计划手册, 3.1 供应能力分析

> ATP（Available To Promise）功能通过将客户需求与当前库存、计划供应及计划需求进行匹配，推算出订单的可承诺日期，从而回答了销售和订单履行过程中的一个最基本的问题："订单什么时候能交付？"
>
> — 华为计划手册, 3.1.3 ATP供应能力分析

---

## I — 方法论骨架 (Interpretation)

瓶颈物料分配是在供应约束下优化资源利用的决策方法。当多个产品/合同共享同一紧缺物料时，不能按"先到先得"简单分配，而需要基于业务规则进行战略性分配。

分配三原则构成决策优先级：
1. **重要优先**: 战略产品、重要合同、新产品开发实验优先
2. **可启动生产**: 避免"有瓶颈料但缺其他料导致无法开工"的资源浪费
3. **兼顾将来**: 本次分配要考虑后续到货的连续性，避免本次分配过度导致后续断档

ATP分析提供量化工具：通过MRP正向模拟或FOXPRO程序模拟，计算当前库存+在途PO-已确认需求=可承诺量，从而确定订单交付能力。灵敏度分析则通过绘制"再投入金额-配套量"曲线，直观展示不同供应能力下的投入产出关系。

## A1 — 书中的应用 (Past Application)

### 案例 1: MC68160配额物料分配（2000年8月）
- **问题**: MC68160（43070001）配额物料一直缺货，各组织产品均受影响，8月需求12823PCS，供应仅10960PCS
- **方法论的使用**: 
  - 按需求比例初步分配（HWCC 17.87%、HWTC 10.26%、SDH 40.31%、DDC 31.56%）
  - 应用三原则调整：GSM需求少直接满足；HWTC需求主要在下半月，协商将前期到货让给DDC先用
  - 考虑可启动生产原则：DDC可满足90%需求，SDH满足8月但9月初断档
- **结论**: 分配需兼顾比例、时间分布和生产影响
- **结果**: 形成具体周度分配方案，各组织按方案执行

### 案例 2: 无线产品ATP模拟（1999年6月）
- **问题**: 需要确定当月及未来ATP能力，评估订单可承诺量
- **方法论的使用**: MRP正向模拟法——取MAX(A4-Q4-Q5, A5-Q5)作为ATP模拟量，综合考虑中试进度、版本切换、市场特殊要求等人工调整，以确认后的ATP模拟量作为MDS排产MRP
- **结论**: ATP不能纯自动化，必须结合人工判断
- **结果**: 确定各产品当月ATP及未来预测ATP，识别瓶颈物料解决时间

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 多个产品/项目争夺同一紧缺物料，需要决定优先满足谁
2. 销售签订新订单前，需要评估当前库存和供应能否支持交付承诺
3. 发现某物料将成为瓶颈，需要提前制定多期分配方案
4. 大批量订单涌入，需要快速评估对现有排产和物料计划的影响
5. 供应链中断（如配额、停产、自然灾害）后，需要重新分配有限资源

### 语言信号 (用户的话里出现这些就应激活)

- "瓶颈物料怎么分"
- "这个订单能不能接"
- "ATP是多少"
- "齐套性检查"
- "缺料了优先保证谁"
- "供应能力分析"
- "可承诺量"

### 与相邻 skill 的区分

- 与 `inventory-health-diagnoser` 的区别: 本 skill 处理物料短缺时的分配决策，而非库存过剩时的健康诊断
- 与 `tom-order-manager` 的区别: tom-order-manager 是TOM模型全局框架，本 skill 聚焦其中的ATP计算和瓶颈分配操作层
- 与 `production-control-operator` 的区别: production-control-operator 处理车间排产和缺料处理操作，本 skill 处理计划层面的资源分配

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **识别瓶颈物料与需求汇总**
   - 完成标准: 明确瓶颈物料编码、当前库存、在途量、未来到货计划；汇总所有涉及产品的需求量和需求时间
   - 数据来源: MRPII系统、采购反馈、生产计划

2. **初步分配方案计算**
   - 完成标准: 按采购提前期满足货期要求的计划量比例，计算各产品/组织的基准分配量
   - 公式: 某组织分配比例 = 该组织当期需求 / 所有组织当期总需求

3. **应用三原则调整**
   - 完成标准: 对基准分配进行调整并记录理由
   - 调整检查清单:
     - [ ] 重要优先: 是否将战略产品/重要合同/研发实验局排在前列？
     - [ ] 可启动生产: 分配后该产品是否其他物料也齐套？若不齐套，是否转分？
     - [ ] 兼顾将来: 本次分配是否导致某组织后续完全断档？是否需要预留缓冲？

4. **ATP能力计算（如适用）**
   - 完成标准: 输出当前可承诺量和最早可交付日期
   - 方法选择:
     - **MRP正向模拟**: 以ATP模拟量为MDS，排产MRP，检查专用/关键物料缺口，反推整机ATP
     - **FOXPRO程序模拟**: 准备基础数据→输入模拟产品编码和数量→按MRP算法分解冲减→核实瓶颈物料后续到货→确定整机ATP
   - 判停条件: 若仅为单一物料分配（非整机ATP），可跳过此步

5. **灵敏度分析（如需要）**
   - 完成标准: 绘制配套量-再投入金额-剩余金额折线图
   - 用途: 向管理层展示"再投入X万元可多配套Y套"的边际效益，支持投资决策

6. **输出分配方案与影响分析**
   - 完成标准: 包含各产品/组织分配量、分配时间、生产影响评估（是否断档、断档时间）
   - 示例格式: 见MC68160案例中的"生产影响分析"段落

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 物料全面过剩、不存在任何供应约束的场景
- 纯产能瓶颈但物料无约束的情况（需用产能规划工具）
- 单一产品独占专用物料，不存在分配问题

### 作者在书中警告的失败模式

- ATP检查柔性太差："ERP系统是一套计算机软件系统...这些柔性若不去用参数在系统里表示出来，系统是没有任何柔性可言的。"
- 需求预测偏差大导致ATP失效："预测信息通常一月收集汇总一次，市场的变化情况不能及时获取，有些定单谈了几个月，但一敲定就是缺料的急单。"
- 忽视可启动生产原则：单纯按重要性分配，结果某产品分到瓶颈料但缺其他料，生产线无法启动

### 作者的盲点 / 时代局限

- 基于MRPII/Oracle ERP和FOXPRO程序模拟，现代APS（高级计划排程）系统已能自动进行约束优化
- 案例中配额物料管理主要依赖人工会议分配，现代供应链可通过算法实时优化
- 未涉及多级供应链瓶颈（供应商的供应商）传递效应

### 容易混淆的邻近方法论

- S&OP（销售与运作计划）vs 瓶颈分配: S&OP是月度高层资源匹配，瓶颈分配是执行层面的物料分配；S&OP决定"产多少"，瓶颈分配决定"给谁"
- 安全库存 vs 瓶颈分配: 安全库存是预防性储备，瓶颈分配是约束条件下的分配决策
